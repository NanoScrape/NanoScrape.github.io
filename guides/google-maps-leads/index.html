RECIPE 1

Dentists in London (Google Maps)

Actor: Google Maps Scraper on Apify · our page

What you get

One row per place. Main fields: title, category, address, phone, website, rating, review_count, latitude, longitude, open_hours, link, place_id. The schema has more (price range, status, owner, images, and social links when add-ons are on).

In the source run: 98 rows. All 98 had title, phone, address, category and rating. 97 had a website.

Input (paste this)

{
  "searchStrings": ["dentists in London"],
  "maxResultsPerQuery": 100,
  "language": "en"
}

Change the text in searchStrings to any "business type in city". Add more strings to search several cities in one run.

Measured cost and time

Run tNDZZvDvw0339ft06 (2026-10-14):

  • 98 places at $0.00097 each = $0.0951
  • 1 start event at $0.00005
  • Total events: about $0.095, plus $0.0008 platform usage
  • Run time: 13 seconds

Steps

  1. Open the actor.
  2. Switch the input to JSON and paste the block above.
  3. Press Start.
  4. When it finishes, open the Output tab and export as CSV or Excel.

What next

  • Find emails: feed the website column into Website Email Scraper (our page).
  • Import the CSV into your CRM or a spreadsheet.
  • Schedule the actor to run monthly in Apify (Schedules tab).
RECIPE 2

Zahnärzte in Hamburg (Das Telefonbuch)

Actor: Das Telefonbuch Scraper on Apify · our page

What you get

One row per business. With includeDetails on: name, description, address, street, postal_code, city, phone, fax, mobile, email, website, category, opening_hours, rating, review_count, recent_reviews, source_url.

In the source run: 100 rows. 94 had a phone, 77 a website, 77 an email, 96 an address, 64 opening hours. mobile was empty in all 100.

Input (paste this)

{
  "searchQuery": "Zahnarzt",
  "location": "Hamburg",
  "maxResults": 100,
  "searchType": "business",
  "includeDetails": true
}

Keep searchType on business. The other value, person, searches private people.

Measured cost and time

Run pdvNyJcfcWnxtHdKS (2026-10-14):

  • 100 full profiles at $0.005 each = $0.50
  • 1 start event at $0.001; search-result events charged: 0
  • Total events: $0.501, plus $0.0046 platform usage
  • Run time: 3 minutes

Steps

  1. Open the actor.
  2. Paste the input above.
  3. Press Start.
  4. Export the dataset as CSV or Excel.

What next

  • Emails are already in 77 of 100 rows. For the rest, run the website column through Website Email Scraper.
  • Import to your CRM.
  • Schedule it monthly to catch new practices.
RECIPE 3

Installateure in Österreich (Herold)

Actor: Herold.at Scraper on Apify · our page

What you get

One row per business: name, phone, email, address, city, postal_code, category, website, opening_hours, description, latitude, longitude, social_links, rating_score, rating_count, founding_year, company_register_id, source_url.

In the source run: 300 rows. 300 had phone and name, 299 email, 299 address, 293 website, 274 opening hours.

Input (paste this)

{
  "keyword": "Installateur",
  "maxResults": 300,
  "includeDetails": true,
  "outputLanguage": "en"
}

No location means all of Austria. Add "location": "Wien" (or any city) to narrow it.

For a cheap first test, set "maxResults": 50. At the same prices that is 50 × $0.005 + $0.05 start = about $0.30 (an estimate, not a measured run).

Using it with Claude and other AI agents

Apify has an MCP server at https://mcp.apify.com. According to Apify's docs, it lets AI apps find and run Actors from the Apify Store and read their results. Sign-in is by OAuth (recommended) or an API token. Running Actors needs an Apify account.

From the docs: call-actor runs an Actor and returns the run status and storage IDs, not the output. To read the rows, the agent uses get-dataset-items on the run's dataset. You can limit what the agent sees with a tools query parameter on the URL.

See Apify's MCP documentation for setup. We have not tested these three actors through MCP ourselves.

FAQ

Can I do another city or trade?

Yes. Change the search text or location. The fields stay the same. How many rows you get depends on the city and the site.

Can I get emails?

Telefonbuch and Herold return an email when the listing has one (77 of 100 and 299 of 300 in these runs). Google Maps does not list emails, so take the website column and run Website Email Scraper.

How often should I re-run?

Business listings change slowly. Monthly is a reasonable start. You can set it up under Schedules in Apify. Each run is billed again.

What does the free plan cover?

New Apify accounts get a monthly free credit; check Apify's pricing page for the current amount. At about $5, using the measured costs above and including platform usage: roughly 50 runs like recipe 1 ($0.096 each), about 9 like recipe 2 ($0.51 each), about 3 like recipe 3 ($1.61 each). This is arithmetic on our three runs, not a guarantee.

Is this legal?

It depends on what you do with the data. See the note below.

Compliance note

These actors collect business listings that are publicly shown on the source sites. Personal data (for example a sole trader's name or private number) is your responsibility. You must comply with GDPR (UK GDPR for London), national data-protection and marketing laws, and each site's terms of use. For cold outreach, check the rules for your country first, and ask a qualified lawyer if you are unsure.
