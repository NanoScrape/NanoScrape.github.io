Industry crosswalk — data-quality matrix

Every industry above rolls up different mechanics on each platform: some use the platform’s native industry filter, some are derived from occupation tags. This matrix states, per cell, what mechanism produced the value and how well it represents the canonical industry.

exact
1:1 mapping to a native platform category. Cross-platform comparable.
merged
Several canonical industries share one platform bucket — value inflated relative to a same-name industry elsewhere.
partial
Platform bucket covers only part of the canonical industry — value under-counts relative to elsewhere.
derived
No native industry filter; value aggregated from occupation-tagged rows via primary_industry_code. Coverage varies (arbeit.swiss ~0.99, jobscout24 ~0.25 aggregate).

Method changelog

v3.1 (2026-09-09 — precision-at-depth)
Reviewer round 4 blocker: newest-first SERP is also relevance-ranked for keyword-in-title, so top-100 precision is clean by construction. Re-sampled every keyword with total > 300 at result position 500-600. jobs.ch median top-100 precision 0.90+ collapses to 0.16 at depth (broad-stem overflow); arbeit.swiss holds at 0.78 (stricter matcher); jobscout24 pagination truncates before depth 500 (deep sample not available). Section-2 tables now publish effective count = raw × precision_deep alongside raw. This does not change any published headline but makes the tail-noise floor visible per (platform, keyword).
v3 (2026-09-07 — current)
Precision-first Swiss-title taxonomy. Every keyword was sampled against the platform SERP and only titles where at least 70% of returned postings actually contain the term are shown. Broad-match keywords excluded (jobs.ch was reporting 411 identical results for three unrelated judge titles; Software Developer matched 2/100 real titles). Series reset.
v2 (2026-09-07 — deprecated same day)
Dedupe of gender variants (Koch/Köchin no longer double-counted), Swiss-standard terms (Fleischer → Metzger), removal of bucket-floor artefacts. Failed reviewer's precision gate (jobs.ch median 0.11, arbeit.swiss 0.25). Superseded by v3.
v1 (2026-09-03 — archived)
Initial ESCO-based candidate set of ~115 titles per industry. Not intended as a shipping taxonomy.
