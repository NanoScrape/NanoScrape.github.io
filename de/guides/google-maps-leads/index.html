REZEPT 1

Zahnärzte in Hamburg (Das Telefonbuch)

Actor: Das Telefonbuch Scraper auf Apify · unsere Seite

Was Sie bekommen

Ein Eintrag pro Betrieb. Mit includeDetails : name, description, address, street, postal_code, city, phone, fax, mobile, email, website, category, opening_hours, rating, review_count, recent_reviews, source_url.

Im Quell-Lauf: 100 Einträge. 94 mit Telefon, 77 mit Webseite, 77 mit E-Mail, 96 mit Adresse, 64 mit Öffnungszeiten. Das Feld mobile war in allen 100 leer.

Eingabe (zum Einfügen)

{
  "searchQuery": "Zahnarzt",
  "location": "Hamburg",
  "maxResults": 100,
  "searchType": "business",
  "includeDetails": true
}

Lassen Sie searchType auf business. Der andere Wert, person, sucht Privatpersonen.

Gemessene Kosten und Zeit

Lauf pdvNyJcfcWnxtHdKS (14.10.2026):

  • 100 vollständige Profile zu je 0,005 $ = 0,50 $
  • 1 Start-Event zu 0,001 $; berechnete Suchergebnis-Events: 0
  • Events gesamt: 0,501 $, plus 0,0046 $ Plattformnutzung
  • Laufzeit: 3 Minuten

Schritte

  1. Öffnen Sie den Actor.
  2. Fügen Sie die Eingabe oben ein.
  3. Drücken Sie Start.
  4. Exportieren Sie den Datensatz als CSV oder Excel.

Wie weiter

  • E-Mails sind schon in 77 von 100 Einträgen. Für den Rest geben Sie die Spalte website in den Website Email Scraper (unsere Seite).
  • Importieren Sie die Liste in Ihr CRM.
  • Planen Sie einen monatlichen Lauf, um neue Praxen zu finden.
REZEPT 2

Installateure in Österreich (Herold)

Actor: Herold.at Scraper auf Apify · unsere Seite

Was Sie bekommen

Ein Eintrag pro Betrieb: name, phone, email, address, city, postal_code, category, website, opening_hours, description, latitude, longitude, social_links, rating_score, rating_count, founding_year, company_register_id, source_url.

Im Quell-Lauf: 300 Einträge. 300 mit Telefon und Name, 299 mit E-Mail, 299 mit Adresse, 293 mit Webseite, 274 mit Öffnungszeiten.

Eingabe (zum Einfügen)

{
  "keyword": "Installateur",
  "maxResults": 300,
  "includeDetails": true,
  "outputLanguage": "en"
}

Ohne location sucht der Actor in ganz Österreich. Mit "location": "Wien" (oder einer anderen Stadt) grenzen Sie ein.

Für einen günstigen ersten Test setzen Sie "maxResults": 50. Zu denselben Preisen sind das 50 × 0,005 $ + 0,05 $ Start = etwa 0,30 $ (Schätzung, kein gemessener Lauf).

Gemessene Kosten und Zeit

  • Events gesamt: 1,55 $, plus 0,065 $ Plattformnutzung

Schritte

  1. Öffnen Sie den Actor.

REZEPT 3

Zahnärzte in London (Google Maps)

Actor: Google Maps Scraper auf Apify · unsere Seite

Was Sie bekommen

Ein Eintrag pro Ort. Wichtige Felder: title, category, address, phone, website, rating, review_count, latitude, longitude, open_hours, link, place_id. Das Schema hat noch mehr (Preisklasse, Status, Inhaber, Bilder, Social-Links mit Zusatzoptionen).

Im Quell-Lauf: 98 Einträge. Alle 98 mit Titel, Telefon, Adresse, Kategorie und Bewertung, 97 mit Webseite.

Eingabe (zum Einfügen)

{
  "searchStrings": ["dentists in London"],
  "maxResultsPerQuery": 100,
  "language": "en"
}

Ändern Sie den Text in searchStrings auf „Branche in Stadt“, zum Beispiel "Zahnarzt in München" mit "language": "de". Mehrere Texte durchsuchen mehrere Städte in einem Lauf.

Gemessene Kosten und Zeit

Schritte

Mit Claude und KI-Agenten nutzen

Apify hat einen MCP-Server unter https://mcp.apify.com. Laut Apify-Dokumentation können KI-Apps damit Actors aus dem Apify Store finden, starten und die Ergebnisse lesen. Die Anmeldung läuft über OAuth (empfohlen) oder einen API-Token. Für Läufe brauchen Sie ein Apify-Konto.

Aus der Dokumentation: call-actor startet einen Actor und gibt Status und Speicher-IDs zurück, nicht die Daten selbst. Die Einträge liest der Agent mit get-dataset-items aus dem Datensatz des Laufs. Mit dem Parameter tools in der URL begrenzen Sie, welche Werkzeuge der Agent sieht.

Zur Einrichtung siehe Apifys MCP-Dokumentation. Diese drei Actors haben wir selbst noch nicht über MCP getestet.

FAQ

Geht das auch für eine andere Stadt oder Branche?

Ja. Ändern Sie den Suchtext oder location. Die Felder bleiben gleich. Wie viele Einträge Sie bekommen, hängt von Stadt und Quelle ab.

Bekomme ich E-Mails?

Das Telefonbuch und Herold liefern eine E-Mail, wenn der Eintrag eine hat (77 von 100 und 299 von 300 in diesen Läufen). Google Maps zeigt keine E-Mails. Nehmen Sie dort die Spalte website und den Website Email Scraper.

Wie oft sollte ich neu laufen lassen?

Branchen-Einträge ändern sich langsam. Monatlich ist ein guter Start. Das richten Sie unter Schedules in Apify ein. Jeder Lauf wird neu berechnet.

Was deckt das kostenlose Konto ab?

Neue Apify-Konten bekommen ein monatliches Gratis-Guthaben; den aktuellen Betrag finden Sie auf Apifys Preisseite. Bei etwa 5 $ und den gemessenen Kosten inklusive Plattformnutzung: ungefähr 9 Läufe wie Rezept 1 (0,51 $), etwa 3 wie Rezept 2 (1,61 $), etwa 50 wie Rezept 3 (0,096 $). Das ist Rechnung auf Basis unserer drei Läufe, keine Garantie.

Ist das legal?

Es kommt darauf an, was Sie mit den Daten machen. Siehe den Hinweis unten.

Hinweis zu Datenschutz und Recht

Diese Actors sammeln Branchen-Einträge, die auf den Quellseiten öffentlich angezeigt werden. Für personenbezogene Daten (zum Beispiel den Namen eines Einzelunternehmers oder eine private Nummer) sind Sie verantwortlich. Sie müssen die DSGVO, nationale Datenschutz- und Werbegesetze (in Deutschland zum Beispiel das UWG) und die Nutzungsbedingungen jeder Seite einhalten. Prüfen Sie vor Kaltakquise die Regeln in Ihrem Land und fragen Sie im Zweifel eine Anwältin oder einen Anwalt.
