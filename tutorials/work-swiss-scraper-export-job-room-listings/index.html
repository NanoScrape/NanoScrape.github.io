work.swiss Scraper: Export Swiss Jobs to CSV

Need job listings from the official Swiss Job-Room (work.swiss, also known as arbeit.swiss) in Excel or in your own analysis? The Arbeit.Swiss Scraper collects the jobs for your keywords and cantons and returns them as a table: title, employer, place, canton, workload percentage, date and a link to the listing. No code, a few minutes.

What you get

The Job-Room, run by SECO (the Swiss State Secretariat for Economic Affairs), has no export function for jobs. Employers and the regional employment centres (RAV) post vacancies there, including some that may not appear on private job boards. The same data is served under four addresses: work.swiss (English), arbeit.swiss (German), travail.swiss (French) and lavoro.swiss (Italian). The Actor collects it in one run and stores it as a table you can download as CSV, Excel or JSON.

The Actor reads only publicly visible listings. You do not need a Job-Room account or an API key.

Two Swiss terms appear in the data. A canton (Kanton) is one of the 26 Swiss states, given as a two-letter code such as BE for Bern or ZH for Zürich. Workload (Pensum) is the job's share of a full-time position, in percent.

All fields at a glance

This is the field list from the Actor's output schema. Without includeJobDetails, the full listing text is missing and you only get the short snippet.

apply_url / apply_emailTextApplication link and, if given, application email

Example: logistics in the canton of Bern

We ran the Actor once locally (21 Oct 2026): keyword “Logistik” (German for logistics, since most listings are in German), canton of Bern, newest first, at most 30 jobs, with full listing text. This was the input:

{
  "searchQueries": ["Logistik"],
  "cantonCodes": ["BE"],
  "sortBy": "newest",
  "maxResults": 30,
  "includeJobDetails": true
}

The run returned 30 jobs and finished after a few seconds (measured locally; times on Apify can differ). The Job-Room reported 345 matches for this search in the last 60 days. How many of the 30 jobs had each field filled:

  • Always (30 of 30): title, employer, place, postal code, canton, workload, contract type, publication and expiry date, link, listing text (plain and Markdown).

STEP 1

Create an Apify account

  1. Open the Arbeit.Swiss Scraper page on Apify.
  2. Click Try for free and sign up with Google or email.
  3. You land in the Apify Console on the Actor's Input tab. The monthly free credit of the Free plan is enough for small runs.
STEP 2

Enter keyword and canton

In searchQueries, enter one or more keywords. Each keyword runs as its own search, and duplicate jobs are removed across all keywords. In cantonCodes, enter the canton as a code, for example ["BE"] or ["ZH", "SG"]. Empty means all of Switzerland.

  • sortBy: newest sorts by date, newest first (default). oldest reverses the order. The Job-Room has no relevance sorting.
  • maxResultsPerQuery: cap per keyword (default 100, 0 means unlimited).
  • maxResults: cap across all keywords together (0 means unlimited).
  • includeJobDetails: true also fetches the full listing text (default).
Start small. For your first run, set maxResults to 10 to 30. You see quickly whether the matches fit your keyword, and you pay only a few cents.
Default: last 60 days only. Without further settings, the Job-Room returns jobs that went online in the last 60 days. Use postedWithinDays to choose a shorter period.
STEP 3

Run the Actor and check the result

Click Save and Run at the bottom. On the run page, the Log tab shows progress and the Dataset tab shows the results as a table. Several keywords and cantons in one run look like this (“Pflege” is nursing care, “Lagerist” warehouse worker, “Buchhaltung” bookkeeping):

{
  "searchQueries": ["Pflege", "Lagerist", "Buchhaltung"],
  "cantonCodes": ["ZH", "BE"],
  "maxResultsPerQuery": 50,
  "includeJobDetails": false
}
STEP 4

Export the data

  1. In the run, open the Dataset tab.
  2. Click Export.
  3. Choose the format: CSV, Excel, JSON and more. With the field selection you export only the columns you need, for example title, company, location, workload_min, posted_at and source_url.

Available filters

The Actor filters the search by these settings:

  • Keyword (searchQueries) and canton (cantonCodes, several allowed).
  • Workload (workloadMin and workloadMax, in percent, default 10 to 100).
  • Age of the listing (postedWithinDays): 1 means 24 hours, 7 means one week. The filter runs at the Job-Room, so you pay only for the matches. The older setting onlineSinceDays defaults to 60.
  • Title (titleFilter): a comma-separated list of terms, for example Laborant, Chemiker, QC. Only jobs with one of these terms in the title are kept. The filter applies before the details are fetched, so filtered-out jobs cost nothing.
  • Sorting (sortBy): newest or oldest first.
  • Volume: maxResultsPerQuery and maxResults.

There is no filter for industry, salary or contract type. You do that afterwards in the table, for example with contract_type and employment_type.

Fetch by API and on a schedule

You can also call the Actor from your own scripts, n8n or Make. This call starts a run and returns the results directly (Apify endpoint run-sync-get-dataset-items):

curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~arbeit-swiss-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchQueries": ["Logistik"], "cantonCodes": ["BE"], "sortBy": "newest", "maxResults": 50}'

You find your API token in the Apify Console under Settings → API & Integrations. For recurring exports, create a schedule in the Console under Schedules. Set postedWithinDays to 1 for daily runs and compare the results with your last export (field id) so you only process new jobs.

What it costs

The Actor charges per result (prices from the Apify Store, Free plan, as of 21 Oct 2026):

  • Start: $0.00005 per run.
  • Job in the result: $0.003 per job.

Each job is charged once, when it is saved to the result. The full listing text (includeJobDetails) costs nothing extra. Worked example: 30 jobs = $0.00005 + 30 x $0.003 = $0.09005, about $0.09. All 345 matches of the example (logistics, canton of Bern, 60 days) would cost about $1.04. You can always find the current prices on the Actor's Apify page.

What people use the data for

Track the Swiss labour market by canton

Run the newest jobs for an occupation and a canton on a schedule and count how many appear per week, or which employers advertise most. The data comes from the official SECO platform.

Source roles for candidates and relocation clients

Recruiters and relocation firms can filter by canton and workload and open the original listing through source_url. Use expires_at and job_status to drop expired listings from your list.

Find employers that are hiring

The company column shows who is hiring in your region. Note that recruitment agencies can appear there too.

Analyse workload and fixed-term jobs

With workload_min, workload_max and contract_type you can see how many jobs are part-time or temporary.

Frequently asked questions

Do I need to code to scrape work.swiss?

No. In the Apify Console you fill in a form, click Save and Run and download the table. You only need code if you want to call the Actor from your own system through the API.

Is work.swiss the same as arbeit.swiss and the SECO Job-Room?

Yes. work.swiss (English), arbeit.swiss (German), travail.swiss (French) and lavoro.swiss (Italian) are the four language versions of the Job-Room run by SECO, the Swiss State Secretariat for Economic Affairs (job-room.ch). The Actor reads the shared data, so you get the same jobs whichever language the site uses.

Does the data include salaries?

Usually not. The fields salary_min, salary_max, salary_currency and salary_period exist in the schema, but the Job-Room does not publish salaries. In the example run, none of the 30 jobs had a salary.

How many jobs do I get per search?

By default at most 100 per keyword (maxResultsPerQuery). Set both maxResultsPerQuery and maxResults to 0 to get every match; the Actor then fetches 100 jobs per page until the list ends. For scale: in the example, the Job-Room reported 345 matches for logistics in the canton of Bern.

How do I get only new jobs?

Set postedWithinDays to 1 for the last 24 hours or 7 for the last week. The filter runs on the Job-Room side. Without it, the default is 60 days. For recurring runs, also compare the id field with your previous export.

How much does the work.swiss scraper cost?

$0.003 per job plus $0.00005 per run start. The detail page is included. 30 jobs with full text cost about $0.09.

Am I allowed to use this data?

That depends on your use case, especially for personal contact details. Some listings name a contact person with email or phone. Check data protection rules (the Swiss FADP, and the GDPR if EU residents are involved) before you store or reuse such data.
