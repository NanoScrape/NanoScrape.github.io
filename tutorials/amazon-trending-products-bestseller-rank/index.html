How to Track Amazon Trending Products and Bestseller Rankings

Amazon's bestseller lists update every hour and cover thousands of categories across 20 marketplaces. Manually checking them by hand is impractical at any meaningful scale. The NanoScrape Amazon Bestsellers Scraper pulls the full top-100 for any category, including Best Sellers, Movers & Shakers, New Releases, Most Wished For, and Most Gifted rankings, and returns rank, ASIN, price, stars, review count, and deal badges as structured JSON at $0.001 per result. This guide walks through setup, category selection, and scheduling a recurring monitor.

What data you get

Each run returns one dataset row per ranked product. The actor walks all pages of a bestseller list to collect the full top-100 ranking, handling both Amazon layouts (50 products per page x 2, and 20 per page x 5) automatically.

{
  "asin": "B0GJTFXNRX",
  "url": "https://www.amazon.com/dp/B0GJTFXNRX",
  "marketplace": "US",
  "categoryUrl": "https://www.amazon.com/Best-Sellers-Electronics/zgbs/electronics/",
  "categoryName": "Best Sellers in Electronics",
  "listType": "bestseller",
  "position": 3,
  "title": "Apple AirTag (2nd Generation): Tracker for Keychain, Wallet, and More",
  "brand": null,
  "price": { "value": 27.00, "currency": "$", "raw": "$27.00" },
  "listPrice": null,
  "stars": 4.6,
  "reviewsCount": 46,
  "isAmazonChoice": false,
  "isPrime": false,
  "isLimitedDeal": false,
  "dealText": null,
  "scrapedAt": "2026-08-13T06:14:21Z"
}

Core output fields

  • position: the product's true rank within the category, 1-100, tracked across paginated pages.
  • asin, title, url: product identity and direct link.
  • marketplace: the Amazon marketplace code (US, DE, UK, JP, etc.).
  • listType: bestseller, movers, new-releases, most-wished, or most-gifted.
  • price and listPrice: current price and original strikethrough price when on sale.
  • stars and reviewsCount: rating and review count from the bestseller card.
  • isAmazonChoice, isPrime, isLimitedDeal: badge flags.
  • categoryName and categoryBreadCrumbs: the list heading and breadcrumb trail from the page.
  • brand: shown when Amazon includes it on the bestseller card (often null on standard cards).
Amazon caps every list at 100 products. That is Amazon's own limit, not the actor's. Running one category returns at most 100 rows. To cover a market segment, add multiple sub-category URLs to one run.

Five list types

The actor supports all five of Amazon's public product ranking lists. You can mix list types within a single run by providing different URLs, or use the toggle fields with browse-node IDs to select a specific list.

  • Best Sellers (default): the top-100 ranked by cumulative sales. Updated hourly. Best for understanding what is consistently popular in a category.
  • Movers & Shakers: the 100 products with the biggest rank gain in the past 24 hours. Use this to catch products trending upward before they reach the main Best Sellers list.
  • New Releases: recently launched products sorted by sales velocity. Useful for spotting emerging competitors or new launches in a niche.
  • Most Wished For: items added most often to Amazon wishlists. Signals latent demand, sometimes for products that are temporarily out of stock or have not yet dropped in price.
  • Most Gifted: items purchased and sent as gifts. Strong signal for seasonal intent and gift-buying research.
Mix list types in one run. Pass Best Sellers URLs alongside Movers & Shakers URLs in the same run. Use the listType field in each result to tell them apart in your analysis.

STEP 1

Open the actor on Apify

  1. Go to the NanoScrape Amazon Bestsellers Scraper on Apify.
  2. Click Try for free. Create an account with Google or email in about a minute.
  3. Once signed in, the actor opens in Apify Console with the Input tab active.
STEP 2

Add category URLs

In the Input tab, click JSON editor at the top right and paste the input below. To find the right URL, browse to any Amazon bestseller page in your browser and copy the URL from the address bar.

{
  "startUrls": [
    { "url": "https://www.amazon.com/Best-Sellers-Electronics/zgbs/electronics/" },
    { "url": "https://www.amazon.com/gp/new-releases/electronics/" },
    { "url": "https://www.amazon.de/gp/bestsellers/electronics/" }
  ],
  "maxResultsPerCategory": 100
}

Key input parameters

  • startUrls: array of bestseller list URLs. Any /gp/bestsellers/, /zgbs/, /gp/movers-and-shakers/, /gp/new-releases/, /gp/most-wished-for/, or /gp/most-gifted/ URL works. The marketplace and list type are auto-detected from the URL.
  • maxResultsPerCategory: cap per category, up to Amazon's 100-product limit. Leave at 100 to get the full ranking.
  • maxResults: total result cap across all categories in one run. Set to 0 for unlimited.
  • concurrency: how many categories to scrape in parallel (default 5). Increase for large runs, or lower to reduce memory use.
  • browseNodeIds: alternative to URLs. Pass a numeric browse-node ID and use the country field to pick the marketplace.
  • newReleases, movers, mostWished, mostGifted: boolean toggles for list type when using browse-node IDs. Default is Best Sellers.
Any marketplace URL works. Drop in a URL from amazon.de, amazon.co.uk, amazon.co.jp, or any of the 20 supported marketplaces. The actor routes each request through a marketplace-matched proxy so prices and currency come back correctly.
STEP 3

Run and review results

Click Start at the top right. The run log shows each category as it is processed. A single top-100 category walk typically completes in under two minutes. Adding multiple categories runs them in parallel up to the concurrency limit.

When the status changes to Succeeded, click Results (or the Dataset tab) to preview the ranked product table. Sort by position to read the list top-to-bottom. The listType column tells you which list each row came from when you mix multiple URLs in a single run.

Comparing ranks over time. Add a scrapedAt timestamp and a runId column in your downstream spreadsheet or database. Each daily run gives you a fresh snapshot, and comparing position across runs shows rising and falling products.
STEP 4

Export and schedule

From the Results tab, click Export to download as JSON, CSV, or Excel. For recurring runs:

  • Scheduler: in the actor's Schedules tab, set up a daily or weekly cron trigger. The actor runs automatically and appends results to the same dataset.
  • Google Sheets: open Integrations from the run page, choose Google Sheets, and authorize once. Each new run appends rows to your sheet.
  • Webhook: paste your endpoint in Integrations › Webhook. Apify posts the full dataset when each run finishes.
  • n8n / Make / Zapier: call the actor from an HTTP Request node or the Apify node and retrieve results from the dataset API. See the n8n section below for a step-by-step.

Automate with n8n

To run a bestseller monitor on a schedule and push new results to a spreadsheet or Slack channel, connect the actor to n8n using the verified Apify n8n node.

  1. Open n8n and create a new workflow.
  2. Add a Schedule Trigger node. Set the interval to daily or weekly, depending on how often Amazon's rankings matter for your use case.
  3. Add an Apify node. Set Operation to Run an Actor and get dataset. Set Actor ID to santamaria-automations/amazon-bestsellers-scraper.
  4. In the Input JSON field, paste your category URLs and result cap.
  5. Add a Google Sheets node to write new rows, a Slack node to post a summary, or any destination node your team uses.
  6. Save and activate the workflow.
{
  "startUrls": [
    { "url": "https://www.amazon.com/Best-Sellers-Electronics/zgbs/electronics/" },

Common use cases

Market trend monitoring

Track which products hold or lose rank in a category week over week. Compare daily snapshots of the top-100 Best Sellers list to build a rank-history chart for any niche. Products climbing consistently are gaining sales velocity; products dropping are losing ground. This gives you a signal on category dynamics without needing Amazon's own seller analytics tools.

New product discovery

Run the New Releases list daily for your target category. Any ASIN appearing for the first time is a recently launched product gaining early traction. Filter for items that appear on both New Releases and Movers & Shakers lists simultaneously, which usually means strong launch momentum.

Competitor and pricing intelligence

Scrape the top-100 Best Sellers in your competitor's category and compare prices, deal frequency, and rating scores. Track which competitors carry the Amazon's Choice badge or run Lightning Deals, and note where your pricing sits relative to theirs. The isLimitedDeal and dealText fields flag active promotions on each card.

Gift and seasonal trend research

The Most Wished For and Most Gifted lists surface buyer intent that the main Best Sellers list can lag behind. Run both lists in October and November to see which products are trending as gift picks before they appear on the Best Sellers ranking, giving you early positioning for ad spend or inventory decisions.

Multi-marketplace price comparison

Pass bestseller URLs from multiple Amazon marketplaces in one run. The marketplace field on each row identifies the source. Compare rank and price for the same ASIN across US, UK, Germany, and Japan to spot arbitrage opportunities or regional pricing patterns.

FAQ

Do I need an Amazon account to use this?

No. The actor scrapes Amazon's public bestseller pages, which are visible to any visitor without signing in. No Amazon account, cookies, or credentials are required.

How often do Amazon's bestseller rankings update?

Amazon updates its bestseller lists roughly hourly. Scraping more frequently than once per hour returns the same data. For most monitoring use cases, daily or weekly runs are sufficient to track meaningful rank changes.

Can I get more than 100 products per category?

Amazon's own lists are capped at 100 products per category. The actor cannot return more than that, regardless of the result cap you set. To cover a broader market, add multiple sub-category URLs. For example, scraping Electronics top-level and several sub-categories (Headphones, Tablets, Smart Home) gives you several hundred ranked products.

Which Amazon marketplaces are supported?

Twenty marketplaces: US, Canada, Mexico, Brazil, UK, Germany, France, Italy, Spain, Netherlands, Sweden, Poland, Turkey, Japan, India, Australia, Singapore, Saudi Arabia, UAE, and Egypt. Mix marketplaces in one run by including URLs from different Amazon domains.

How do I track my own ASIN's bestseller rank?

Run the actor on the bestseller URL for your product's category. After the run, filter the dataset by your ASIN. The position field gives your rank in that category's top-100. To monitor it daily, schedule the run and join your ASIN against each day's dataset in a spreadsheet or database.

Why is the brand field often null?

Amazon's bestseller cards frequently omit the brand line, even for brand-name products. This is Amazon's own design choice on the card layout, not a scraping limitation. To get guaranteed brand data, feed the returned ASINs into the Amazon Product Scraper actor, which pulls the full product detail page.
