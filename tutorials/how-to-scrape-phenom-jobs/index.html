What is Phenom People and who uses it

By the NanoScrape team - Published 2026-10-15 - Updated 2026-10-15

Phenom People is one of the top Applicant Tracking Systems (ATS) used by large enterprises. Our 2026 audit of the Fortune 500 (see the ATS market share study) identified 41 companies (8.2% of the F500) running Phenom People as their primary careers-page platform: the second-largest commercial ATS in the F500 audit, behind Workday.

The NanoScrape Career Site Jobs Scraper reads the job data Phenom embeds as JSON in the career site's own HTML (HTTP only, no browser) and returns structured job records at $0.001 per job ($1 per 1,000 jobs) plus $0.001 per run start. This tutorial gives you the list of F500 Phenom People companies plus a ready-to-run actor input to scrape their jobs.

Phenom People URL and API pattern

Phenom People careers pages follow this URL pattern:

URL pattern:  the employer's own domain, e.g. https://jobs.{company}.com/us/en
Data source:  job data embedded as JSON in the career site's HTML (eagerLoadRefineSearch)
How to pass it: Phenom career sites use the employer's own domain, usually ending in a locale path such as /us/en (https://jobs.cvshealth.com/us/en). Because the domain says nothing about the ATS, pass each site as {"platform": "phenom", "company": URL}. The keywords, location, postedWithinDays and sortBy inputs work on this platform too; add includeSummaryRows: true to get one summary row per company explaining a zero result.

STEP 1

Example actor run: first 5 Phenom People F500 companies

Copy this input into the actor's Input tab (JSON editor mode) to scrape jobs from the first 5 F500 companies in the list above, capped at 100 jobs each:

{
  "queries": [
    {
      "platform": "phenom",
      "company": "https://jobs.cvshealth.com/us/en"
    },
    {
      "platform": "phenom",
      "company": "https://careers.cencora.com/us/en"
    },
    {
      "platform": "phenom",
      "company": "https://careers.humana.com/us/en"
    },
    {
      "platform": "phenom",
      "company": "https://careers.freddiemac.com/us/en"
    },
    {
      "platform": "phenom",
      "company": "https://www.pgcareers.com/eu/en"
    }
  ],
  "maxJobsPerCompany": 100,
  "includeDescription": false
}
Cost and scale: this input costs at most 5 x 100 = 500 jobs, so at most $0.50 plus $0.001 for the run start. The actor charges $0.001 per job returned; a company with fewer jobs costs less. Running all 34 listed companies with maxJobsPerCompany: 100 would be at most 34 x 100 = 3400 jobs, about $3.40. Set maxJobsPerCompany to 0 for all jobs (hard limit 5,000 per company). Use keywords, location and postedWithinDays to pay only for matching jobs; filters run before charging.

Output schema for Phenom People

The actor emits the same field names for every ATS (more than 30 are supported). What Phenom fills in:

  • title: always
  • company: the career site's name
  • ats_platform: always phenom
  • location: available, with city and country where the site gives them
  • department: available
  • employment_type: available
  • description: per the actor README read from the listing; it is null when includeDescription is false
  • apply_url and job_url: always
  • created_at: the site's posted date

Known limitations

Phenom career sites sit on each company's own domain, so the actor cannot recognise them from the URL alone: always pass the object form {"platform": "phenom", "company": "https://careers-url"}. Some apply links point to the employer's own Workday or other ATS (Chewy's rows link to myworkdaysite.com).

Blocked sites: the actor goes direct first and, if a site refuses it, can retry through residential proxies for up to 2 different hosts per run (maxResidentialHosts, default 2; residentialFallback: "off" disables it). A company that is still blocked ends with a reason such as blocked or blocked_residential_cap and is not charged for jobs it did not return. Set includeSummaryRows to see the reason per company.

FAQ

How many Fortune 500 companies use Phenom People?

Our 2026 audit identified 41 F500 companies running Phenom, 8.2% of the Fortune 500 (see the market share study). Companies migrate between ATS platforms, so the numbers move over time.

Do I need a login or API key to scrape Phenom People?

No. The actor reads the public job list of the career site and needs no login or API key of the employer. You only need an Apify account to run it.

Can I scrape non-F500 companies that use Phenom People?

Yes. The F500 list is only a starting point; any Phenom career site works. Pass the career-site URL as {"platform": "phenom", "company": URL}.

Can the same run mix Phenom with other ATS platforms?

Yes. The Career Site Jobs Scraper supports more than 30 ATS platforms and sites, and one run can contain URLs of different systems. Every row carries ats_platform so you can tell them apart.

What does it cost?

$0.001 per job returned plus $0.001 per run start (pay per event, no monthly fee). Filters such as keywords, location and postedWithinDays run before charging, so you only pay for matching jobs.
