How to build a weekly events list for one city from Eventbrite

You run a newsletter or a community calendar and want a fresh list of what is on in your city this week, for example tech events in Berlin, without opening Eventbrite every Monday and copying details by hand? The Eventbrite Scraper runs one search for your topic and city and returns each event as a row: date, venue, price, category and the ticket link. This guide shows how to set that up once and cut the result to the next seven days in Google Sheets, then put it on a weekly schedule. No code.

Difficulty: Beginner
Time: 15 minutes
Cost: 100 events ≈ $0.30
Tools: Apify Console, Google Sheets
Open the Actor on Apify → See the cost
STEP 1

Open the Actor

  1. Open the Eventbrite Scraper on Apify.
  2. Click Try for free and sign up with Google or email. Apify's free plan includes monthly platform credit, which covers many weekly runs of this size.
  3. On the Input tab, switch to JSON view.
STEP 2

Paste this input

One city, one topic, up to 50 events, with the detail pages so you also get price and organizer:

{
  "searchQuery": "tech",
  "location": "germany--berlin",
  "maxResults": 50,
  "includeDetails": true
}
  • searchQuery: the topic. Use the word you would type into Eventbrite, such as tech, networking or startup.
  • location: an Eventbrite location slug. Cities look like germany--berlin or united-kingdom--london; a whole country is just germany.
  • maxResults: the cap. A weekly list rarely needs more than 50 to 100.
  • includeDetails: true fetches each event page for price, free flag and organizer. Without it those fields are empty.

If you already have a search page you like on eventbrite.com, with filters applied, copy its URL into searchUrls instead of using searchQuery and location.

STEP 3

Run it and read the output

Click Save and Run and open the Dataset tab when the run ends. Each row is one event. This is a real item from a Berlin tech search, shortened (the long descriptions and some organizer fields are left out):

  "sales_status": "on_sale",

  "source_platform": "eventbrite.com",
  "scraped_at": "2026-11-11T07:08:06Z"
}

For a newsletter or calendar these are the fields that matter:

  • title and url: the headline and the link readers click.
  • start_date and end_date: local time with the UTC offset, in timezone. The first ten characters are the date.
  • venue_name, venue_address, venue_city: where it happens. is_online marks online events.
  • is_free, price and currency: entry cost. Some events publish no price, so keep a blank-friendly layout.
  • category, subcategory and tags: to split a long list into sections.
  • is_cancelled, is_sold_out and sales_status: to drop events your readers cannot attend.
Read before you list. This sample is a gala with limited access. The description field says so, which is why it pays to skim description for anything unusual before an event goes into your newsletter.
STEP 4

Turn it into a weekly list

The Actor has no date filter, so it returns upcoming events in Eventbrite's order and you cut the list to your week in the spreadsheet.

  1. In the Dataset tab click Export, choose CSV and keep: start_date, title, venue_name, is_free, price, currency, category, is_cancelled, url. Import the file into Google Sheets.
  2. Add a helper column with the date: =DATEVALUE(LEFT(A2,10)) if start_date is in column A.
  3. Filter the helper column to the next seven days and is_cancelled to FALSE. In one formula: =SORT(FILTER(A2:I, J2:J>=TODAY(), J2:J<TODAY()+7, H2:H=FALSE), 1, TRUE) with the helper in column J.
  4. Write the newsletter line per event in another column: =TEXT(J2,"ddd d mmm")&" | "&B2&" | "&C2&" | "&IF(D2=TRUE,"Free","from "&E2&" "&F2)&" | "&I2. Copy the column into your newsletter tool or calendar page.

Run it every week without clicking

  1. In the Apify Console open Schedules, create a schedule that runs weekly (for example Monday 06:00) and attach this Actor with the input above.
  2. In the Actor's Integrations tab connect Google Sheets so each run is added to a sheet. Or build it in n8n or Make: Schedule trigger, Apify “Run Actor” step, Google Sheets step.
  3. Events stay on Eventbrite for weeks, so the same event shows up in several runs. Use id as the key and remove duplicates (Data → Data cleanup → Remove duplicates) before you build the week.

Frequently asked questions

Can I filter the list to the next seven days inside the Actor?

No. The input has a keyword, a location and a result cap, but no date range. Export the dataset and cut it to the week in your spreadsheet with the start_date field, as shown in step 4.

How do I get another city or topic?

Change location to another Eventbrite slug (for example united-kingdom--london or ca--san-francisco) and searchQuery to your topic. You can also paste an Eventbrite search URL into searchUrls to reuse filters you set on the site.

Why do some events have no price?

price, currency and is_free come from each event page, so they need includeDetails set to true. Even then some events publish no price, so leave room for a blank in your layout.

How much does a weekly list cost?

On the actor page the price is $3.00 / 1,000 event found. A run of 50 events is about $0.15 and 100 events about $0.30.
