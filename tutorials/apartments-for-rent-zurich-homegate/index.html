Why use filters instead of a browser search

Looking for a flat in Zurich means refreshing the same Homegate search for weeks. With the Actor you set your limits once, get all matching rentals as a table, and run the same input again every day. Sorted by listed_at, the newest rows are the listings that appeared since your last look. This page covers that search-and-watch use. The German tutorial covers a different job, working out the rent per square metre.

STEP 1

Open the Actor

  1. Open the Homegate.ch Scraper on Apify. The Actor page on NanoScrape lists every output field.
  2. Click Try for free and sign up with Google or email. Apify's free plan includes monthly platform credit, enough for a first test.
  3. You land on the Actor's Input tab. Switch to the JSON view to paste the input below.
STEP 2

Paste this input

Example: apartments for rent in Zürich with at least 2.5 rooms and a maximum monthly price of CHF 2,500. Replace the city and limits with yours.

{
  "listingType": "rent",
  "city": "Zürich",
  "priceMax": 2500,
  "roomsMin": 2.5,
  "maxResults": 100,
  "includeDetails": false
}
  • listingType: rent (default) or buy.
  • city: a city name such as Zürich, Bern, Basel or Genf. Use canton with a code such as ZH, BE, BS or GE if you want a whole canton instead. The canton is only used when no city is set.
  • priceMax (and priceMin): monthly rent in CHF.
  • roomsMin: minimum number of rooms, for example 2, 2.5 or 3. It is a minimum, so you also get larger flats.
  • maxResults: start at 20 for a test.
  • includeDetails: leave it false. The search results already carry price, rooms, area, address, GPS, features and description. Details add agent contact and are billed separately.
Already have a search on homegate.ch? Paste its URL into searchUrls instead, for example https://www.homegate.ch/mieten/immobilien/ort-zuerich/trefferliste. The URL then replaces the city and price fields.
STEP 3

Run it and read the output

Click Save and Run, then open the Dataset tab. Each row is one listing. This is the sample item from the Actor's README, shortened to the fields that matter for a flat search:

{
  "id": "4002927362",
  "title": "2.5-Zimmer-Wohnung mit Wintergarten",
  "price": 2225,
  "currency": "CHF",
  "price_type": "rent",
  "rooms": 2.5,
  "area_sqm": 60,
  "floor": 4,
  "property_type": "apartment",
  "listing_type": "rent",
  "address": "Im Isengrind, 8046 Zürich",
  "city": "Zürich",
  "postal_code": "8046",
  "canton": "ZH",
  "latitude": 47.42223,
  "longitude": 8.51208,
  "features": ["balcony", "parking", "elevator", "washing_machine", "nice_view", "quiet", "pets_allowed"],
  "source_url": "https://www.homegate.ch/rent/4002927362",
  "source_platform": "homegate.ch",
  "listed_at": "2026-02-13T12:45:58.392Z"
}
  • price: gross monthly rent in CHF. price_net and price_extra (net rent and extra costs) are often empty without detail pages.
  • rooms, area_sqm and floor: size and floor.
  • address, postal_code, city, canton, latitude and longitude: where it is. Use postal_code to keep the districts you like.
  • features: for example balcony, parking, elevator, washing_machine or pets_allowed.
  • listed_at and source_url: when it was listed and the link to the ad.

The sample row is an example of the structure and of the price range, not a current offer.

STEP 4

Shortlist and watch for new listings

  1. In the Dataset tab click Export, choose CSV and import it into Google Sheets.
  2. Filter features for what you need, for example text containing pets_allowed or balcony, and postal_code for your districts.
  3. Add a column with price divided by area_sqm to compare flats of different size.
  4. In the Apify Console open Schedules and run the same input once a day. Paste each export below the last one, drop duplicates by id, and sort by listed_at. The new ids are the new listings.

Each run reads Homegate live, so the table shows what is listed at run time. Listings that have been taken down will no longer appear.

What it costs

Pay per result: $0.003 per listing from the search results, so 100 rentals in Zurich are $0.30 and 500 listings are $1.50. Detail pages (agent contact and price breakdown) are a separate event at $8.00 per 1,000 detail pages, which is why this guide keeps includeDetails off. The Pricing tab of the Actor's Apify page lists every event and any upcoming change.

Who uses a rental search like this

  • Flat hunters keep a daily list of new rentals within budget and room count, and open the new ads first.
  • Relocation and expat services check what is available at which price in a city before advising a client.
  • Property analysts collect rents by district, size and features over time.

The data is public listing data. Listings can carry agency contact information, so check data-protection rules before you store or use it.

Frequently asked questions

Can I search a whole canton instead of one city?

Yes. Leave city empty and set canton to a code such as ZH or BE. You can also paste a canton search URL into searchUrls.

Is roomsMin an exact room count?

No, it is a minimum. roomsMin 2.5 returns flats with 2.5 rooms or more. Filter the rooms column in the sheet for an exact count.

Can I get the agent contact?

Yes, with includeDetails on. Detail pages are billed separately, so this guide leaves them off.

Does it cover apartments for sale?

Yes. Set listingType to buy or paste a /kaufen/ search URL.

How much does it cost?

Pay per result: $0.003 per listing from the search results, so 100 rentals are $0.30. Detail pages are $8.00 per 1,000.
