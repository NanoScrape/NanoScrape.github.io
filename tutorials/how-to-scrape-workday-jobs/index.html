What is Workday and who uses it

By the NanoScrape team - Published 2026-10-15 - Updated 2026-10-15

Workday is one of the top Applicant Tracking Systems (ATS) used by large enterprises. Our 2026 audit of the Fortune 500 (see the ATS market share study) identified 118 companies (23.6% of the F500) running Workday as their primary careers-page platform: the largest ATS in the F500 by count, ahead of every other commercial system and of the 103 companies that build their own custom careers site.

The NanoScrape Career Site Jobs Scraper reads the same public job-search endpoint the Workday career page itself calls (HTTP only, no browser) and returns structured job records at $0.001 per job ($1 per 1,000 jobs) plus $0.001 per run start. This tutorial gives you the list of F500 Workday companies plus a ready-to-run actor input to scrape their jobs.

Workday URL and API pattern

Workday careers pages follow this URL pattern:

URL pattern:  https://{tenant}.wd{N}.myworkdayjobs.com/{site}
Data source:  /wday/cxs/{tenant}/{site}/jobs (public job-search JSON)
How to pass it: Workday board URLs look like https://{tenant}.wd{N}.myworkdayjobs.com/{site}; the actor reads it directly from the string. The keywords, location, postedWithinDays and sortBy inputs work on this platform too; add includeSummaryRows: true to get one summary row per company explaining a zero result.

STEP 1

Example actor run: first 5 Workday F500 companies

Copy this input into the actor's Input tab (JSON editor mode) to scrape jobs from the first 5 F500 companies in the list above, capped at 100 jobs each:

{
  "queries": [
    "https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite",
    "https://centene.wd5.myworkdayjobs.com/centene_external",
    "https://verizon.wd12.myworkdayjobs.com/verizon-careers",
    "https://mpc.wd1.myworkdayjobs.com/MPCCareers",
    "https://target.wd5.myworkdayjobs.com/targetcareers"
  ],
  "maxJobsPerCompany": 100,
  "includeDescription": true
}
Cost and scale: this input costs at most 5 x 100 = 500 jobs, so at most $0.50 plus $0.001 for the run start. The actor charges $0.001 per job returned; a company with fewer jobs costs less. Running all 104 listed companies with maxJobsPerCompany: 100 would be at most 104 x 100 = 10400 jobs, about $10.40. Set maxJobsPerCompany to 0 for all jobs (hard limit 5,000 per company). Use keywords, location and postedWithinDays to pay only for matching jobs; filters run before charging.

Output schema for Workday

The actor emits the same field names for every ATS (more than 30 are supported). What Workday fills in:

  • title: always
  • company: the board or employer name
  • ats_platform: always workday
  • location: available; multi-location postings also fill additional_locations
  • employment_type: available
  • remote: available
  • description: HTML, only when includeDescription is true (one extra request per job, so runs are slower)
  • apply_url and job_url: always
  • created_at: ISO 8601; Workday's relative texts such as "Posted 3 Days Ago" are converted, "Posted 30+ Days Ago" gives null and keeps the text in posted_at_text

Known limitations

Workday returns at most 2,000 results per search; the actor splits larger tenants by facet automatically. Large tenants can throttle detail requests (the README mentions NVIDIA after about 450); the actor slows down and retries, and rows whose description still fails are pushed without one.

Blocked sites: the actor goes direct first and, if a site refuses it, can retry through residential proxies for up to 2 different hosts per run (maxResidentialHosts, default 2; residentialFallback: "off" disables it). A company that is still blocked ends with a reason such as blocked or blocked_residential_cap and is not charged for jobs it did not return. Set includeSummaryRows to see the reason per company.

FAQ

How many Fortune 500 companies use Workday?

Our 2026 audit identified 118 F500 companies running Workday, 23.6% of the Fortune 500 (see the market share study). Companies migrate between ATS platforms, so the numbers move over time.

Do I need a login or API key to scrape Workday?

No. The actor reads the public job list of the career site and needs no login or API key of the employer. You only need an Apify account to run it.

Can I scrape non-F500 companies that use Workday?

Yes. The F500 list is only a starting point; any Workday career site works. Pass the board URL as a string in the queries array.

Can the same run mix Workday with other ATS platforms?

Yes. The Career Site Jobs Scraper supports more than 30 ATS platforms and sites, and one run can contain URLs of different systems. Every row carries ats_platform so you can tell them apart.

What does it cost?

$0.001 per job returned plus $0.001 per run start (pay per event, no monthly fee). Filters such as keywords, location and postedWithinDays run before charging, so you only pay for matching jobs.
