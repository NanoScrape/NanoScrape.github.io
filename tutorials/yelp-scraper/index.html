How to Scrape Yelp Business Listings: Names, Addresses, Ratings, and More

What you get

The Yelp Scraper returns one record per business listing. Each record has 17 fields: the Yelp business ID, name, full Yelp URL, phone number, street address broken into city, state, and ZIP, GPS coordinates, star rating, review count, price range ($, $$, $$$, $$$$), a list of business categories, the search term and location that produced the result, and a timestamp.

You give it a list of business types (like dentists or pizza restaurants) and a list of cities or ZIP codes. The actor searches every combination, paginates through the results, removes duplicates, and hands back a clean dataset.

Prerequisites

  • A free Apify account. Sign up at the actor page. The free tier gives you $5 of usage credit each month, which covers roughly 4,750 Yelp listings after the per-run fee.
  • A list of the business categories and locations you want to search. Examples: categories like plumbers or hair salons, locations like Austin, TX or 90210.
STEP 1

Create a free Apify account

  1. Open the NanoScrape Yelp Scraper on Apify.
  2. Click Try for free. If you already have an account, click Sign in.
  3. Sign up with Google or email. It takes about a minute.
Tip: the $5 free credit resets every month. You do not need to enter a payment method to start scraping.
STEP 2

Configure your search

After clicking Try for free, Apify opens the actor's Input tab. The two required fields are:

  • Search Terms: one or more business types to search. Examples: restaurants, plumbers, hair salon, dentists.
  • Locations: one or more US cities or ZIP codes. Examples: New York, NY, Chicago, IL, 90210.

The actor searches every combination of search term and location. Three search terms and four cities means 12 individual Yelp searches, all running in parallel.

Max results per query

The Max Results Per Query field controls how many listings you get per search term and location pair. It defaults to 50. Set it to 0 if you want every listing Yelp returns for that combination, with no cap.

Deduplication is automatic. If the same business appears across multiple search combinations, the actor keeps it once. You never have to clean duplicates yourself.
STEP 3

Run the scraper

Click Save & Run in the top right. The actor starts immediately. You will see a live log in the Run tab.

When the run finishes, the Results tab shows a count of collected listings. If Yelp presents a challenge page the actor cannot handle automatically, the run exits cleanly with an escalation notice in the log rather than returning partial or empty data.

Challenge pages are rare. The actor uses browser fingerprint emulation to handle Cloudflare protection automatically. The escalation notice is a safety net, not a common occurrence.
STEP 4

Download your results

Open the Results tab in the run view. Click Export and pick your format:

  • JSON: one object per listing, all 17 fields. Best for piping into code or a database.
  • CSV: flat spreadsheet, one row per listing. Import directly into Excel, Google Sheets, or Airtable.
  • Excel (.xlsx): formatted spreadsheet ready to open.

Output fields reference

Every listing in the dataset includes these fields:

  • business_id: Yelp's unique business slug. Stable even if the business renames or moves.
  • name: business name.
  • yelp_url: full URL to the Yelp listing.
  • phone: primary phone number.
  • address: street address.
  • city, state, zip: parsed address components.
  • latitude and longitude: GPS coordinates.
  • rating: Yelp star rating from 1 to 5.
  • review_count: total number of Yelp reviews.
  • price_range: $, $$, $$$, or $$$$. Empty if Yelp has not set one for this listing.
  • categories: array of business categories.
  • search_term and search_location: the input values that produced this listing.
  • scraped_at: ISO 8601 UTC timestamp.

Run via API or code

You can trigger the actor from any language using the Apify REST API or the Model Context Protocol. Both use the same input fields as the console.

REST API

Replace YOUR_APIFY_TOKEN with the Personal API token from Apify Console › Settings › Integrations:

curl -X POST \
  "https://api.apify.com/v2/acts/santamaria-automations~yelp-scraper/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "searchTerms": ["dentists", "orthodontists"],
    "locations": ["Phoenix, AZ", "Scottsdale, AZ"],
    "maxResultsPerQuery": 50
  }'

The endpoint starts the run, waits for it to finish, and returns the full dataset as a JSON array. For searches that take more than a few minutes, use the async run endpoint instead and poll for completion.

MCP integration

If you use an AI assistant that supports the Model Context Protocol, invoke the actor with a plain English prompt. The MCP server address is:

apify/santamaria-automations/yelp-scraper

Example prompt: "Use the Yelp Scraper to find Italian restaurants in Chicago, IL with a max of 100 results per query."

FAQ

Do I need a Yelp API key?

No. The Yelp Scraper works directly on Yelp's public web interface. You do not need a Yelp API key or a Yelp developer account.

Does it work outside the US?

The actor is designed for US cities and ZIP codes. Yelp has some listings in other countries, but coverage and data quality vary significantly outside the US. Test with a specific city first if you need international data.

How many results can I get per search?

Set maxResultsPerQuery to however many listings you want per search term and location pair. Set it to 0 for no cap. The actor paginates automatically and deduplicates results across all your searches.

Can I scrape Yelp reviews?

The current version extracts the review count shown on each listing, not the individual review text. Check the actor page on Apify for the latest feature list, as new fields are added over time.

What happens if Yelp shows a bot-detection challenge?

The actor handles Cloudflare protection automatically via browser fingerprint emulation. If it encounters a challenge it cannot solve (such as a Turnstile puzzle), it exits cleanly with an escalation notice rather than returning empty or partial data. Unsolvable challenges are rare in practice.

Can I run this on a schedule?

Yes. In Apify Console, open the Schedules section and create a new schedule for this actor. Set the frequency and pre-fill the input. The actor will run automatically and save results to a fresh dataset on each run.

Is scraping Yelp legal?

Scraping publicly available data is generally permitted in most jurisdictions. The US Ninth Circuit ruling in hiQ Labs v. LinkedIn established that scraping public data does not violate the Computer Fraud and Abuse Act. Yelp's terms of service restrict automated access, so review them and any applicable local laws before running large-scale commercial collections. Consult a lawyer if you have specific compliance questions.
