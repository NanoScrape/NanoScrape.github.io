Why a weekly new-jobs list

If you look for work in a field, or you track a labour market, the question is not “what is online” but “what is new since last week”. A search on the website can sort by date, but you still page through it by hand and cannot compare weeks. With the Stellenanzeigen.de Scraper you set a keyword, a city and a time window of 7 days, newest first, and get one clean table of the ads that appeared in that window. The German export tutorial covers the plain CSV export. This page is about the weekly “what is new” routine.

STEP 1

Open the Stellenanzeigen.de Actor

  1. Open the Stellenanzeigen.de Scraper on Apify. The Actor page on NanoScrape lists every output field.
  2. Click Try for free and sign up with Google or email. Apify's free plan includes monthly platform credit, enough for a first test.
  3. You land on the Actor's Input tab. Switch to the JSON view to paste the input below.
STEP 2

Paste this input

Example: software engineer jobs in and around Berlin that went online in the last 7 days, newest first. Replace the keyword and the city with yours.

{
  "searchQueries": [
    "Software Engineer"
  ],
  "location": "Berlin",
  "radius": 30,
  "postedWithinDays": 7,
  "sortBy": "newest",
  "maxResultsPerQuery": 100,
  "includeJobDetails": true
}
  • searchQueries: the role, as the ads are written. Add more keywords, for example “Softwareentwickler”; duplicates are removed across keywords.
  • location and radius: city and radius in km. The radius is rounded to 10 km steps; 0 uses the platform default of 30 km.
  • postedWithinDays: the time window. Enforced on the platform side. Supported values are 1, 7 and 30; 7 gives the weekly list.
  • sortBy: newest puts the newest ads first, which is what you want for a scheduled run.
  • includeJobDetails: keep it true to get dates, salary and the address in each row. Off returns the basic data from the result list only.
  • maxResultsPerQuery: start at 20 for a test, then raise it.
Several roles in one run? Put each role in searchQueries. The Actor searches each keyword on its own and removes duplicates, so one ad is never delivered twice.

The fields you need for a new-jobs list:

  • title, company and location: the ad, the employer and the place.
  • posted_at, originally_posted_at and expires_at: the dates, so you can confirm the ad is from your window and see when it expires.
  • salary_text, salary_min, salary_max and remote_option: salary where the ad states it, and the remote option.
  • source_url and apply_url: the link to the ad and the link to apply.
  • id: a stable ID for removing duplicates between weekly runs.

This tutorial does not use any contact-person fields. Apply through the link in the ad, and check the data-protection rules for your use before you store personal data.

STEP 4

Turn the export into a weekly list

  1. In the Dataset tab click Export, choose CSV and select id, title, company, location, posted_at, salary_text, remote_option, source_url.
  2. Import the file into Google Sheets (File → Import) as a sheet called jobs. With the order above, the ID is column A, the title B, the company C and the town D.
  3. On a sheet called seen, keep the IDs you already know in column A. In a new column on jobs, mark the ads that are really new this week:
=IF(COUNTIF(seen!A:A, A2)=0, "NEW", "")
  1. Filter the new column for NEW and sort by posted_at, newest first. Copy the IDs of the new ads into seen when you are done.

Run it every week

In the Apify Console, open Schedules and run the same input once a week, for example on Monday morning, with postedWithinDays set to 7. Each run then delivers the ads of the past week, newest first.

Frequently asked questions

What does posted within 7 days really cover?

The platform filters by how long an ad has been online. The Actor sends your value as onlyAdsOnlineForDays. Supported values are 1, 7 and 30; other numbers are accepted but may round to the nearest of these.

Can I filter by profession category?

This Actor has no category field. Use the keyword in searchQueries, for example Software Engineer or Pflegefachkraft, and add several keywords to cover a profession.

Why is posted_at empty in some rows?

In the sample for search-only mode posted_at is null. With includeJobDetails on, the detail rows carry posted_at, originally_posted_at and expires_at.

How much does it cost to check one week of new jobs?

Pay per event. A job with full details is $7.50 per 1,000 results, so 100 jobs with details are about $0.75. The price for rows without details is on the Pricing tab of the Actor page on Apify.
