What is TalentBrew (TMP Worldwide) and who uses it

By the NanoScrape team - Published 2026-10-15 - Updated 2026-10-15

TalentBrew (TMP Worldwide) is one of the top Applicant Tracking Systems (ATS) used by large enterprises. Our 2026 audit of the Fortune 500 (see the ATS market share study) identified 22 companies (4.4% of the F500) running TalentBrew (TMP Worldwide) as their primary careers-page platform: used by 22 F500 companies, mostly large corporates that run a branded career site on Radancy (TMP Worldwide) technology.

The NanoScrape Career Site Jobs Scraper pages through the career site's own search-results endpoint, which returns JSON with HTML fragments (HTTP only, no browser) and returns structured job records at $0.001 per job ($1 per 1,000 jobs) plus $0.001 per run start. This tutorial gives you the list of F500 TalentBrew (TMP Worldwide) companies plus a ready-to-run actor input to scrape their jobs.

TalentBrew (TMP Worldwide) URL and API pattern

TalentBrew (TMP Worldwide) careers pages follow this URL pattern:

URL pattern:  the employer's own domain, e.g. https://jobs.{company}.com/en
Data source:  the site's /search-jobs/results endpoint (JSON containing HTML fragments), paged by the actor
How to pass it: TalentBrew career sites use the employer's own domain (https://jobs.walgreens.com/en). Because the domain says nothing about the ATS, pass each site as {"platform": "talentbrew", "company": URL}. The keywords, location, postedWithinDays and sortBy inputs work on this platform too; add includeSummaryRows: true to get one summary row per company explaining a zero result.

STEP 1

Example actor run: first 5 TalentBrew (TMP Worldwide) F500 companies

Copy this input into the actor's Input tab (JSON editor mode) to scrape jobs from the first 5 F500 companies in the list above, capped at 100 jobs each:

{
  "queries": [
    {
      "platform": "talentbrew",
      "company": "https://careers.mckesson.com/en"
    },
    {
      "platform": "talentbrew",
      "company": "https://www.careers.ford.com"
    },
    {
      "platform": "talentbrew",
      "company": "https://careers.chevron.com"
    },
    {
      "platform": "talentbrew",
      "company": "https://jobs.walgreens.com/en"
    },
    {
      "platform": "talentbrew",
      "company": "https://www.att.jobs"
    }
  ],
  "maxJobsPerCompany": 100,
  "includeDescription": false
}
Cost and scale: this input costs at most 5 x 100 = 500 jobs, so at most $0.50 plus $0.001 for the run start. The actor charges $0.001 per job returned; a company with fewer jobs costs less. Running all 21 listed companies with maxJobsPerCompany: 100 would be at most 21 x 100 = 2100 jobs, about $2.10. Set maxJobsPerCompany to 0 for all jobs (hard limit 5,000 per company). Use keywords, location and postedWithinDays to pay only for matching jobs; filters run before charging.

Output schema for TalentBrew (TMP Worldwide)

The actor emits the same field names for every ATS (more than 30 are supported). What TalentBrew fills in:

  • title: always
  • company: derived from the career-site host
  • ats_platform: always talentbrew
  • location: available
  • apply_url and job_url: always
  • created_at: posting date, parsed from MM/DD/YYYY on US sites and DD/MM/YYYY on European ones
  • description, department, employment_type: not confirmed by the actor README for TalentBrew; treat as best effort

Known limitations

TalentBrew career sites sit on each company's own domain, so pass the object form {"platform": "talentbrew", "company": "https://careers-url"}. The platform names talentbrew and radancy are the same. Descriptions are not confirmed for TalentBrew.

Blocked sites: the actor goes direct first and, if a site refuses it, can retry through residential proxies for up to 2 different hosts per run (maxResidentialHosts, default 2; residentialFallback: "off" disables it). A company that is still blocked ends with a reason such as blocked or blocked_residential_cap and is not charged for jobs it did not return. Set includeSummaryRows to see the reason per company.

FAQ

How many Fortune 500 companies use TalentBrew (TMP Worldwide)?

Our 2026 audit identified 22 F500 companies running TalentBrew, 4.4% of the Fortune 500 (see the market share study). Companies migrate between ATS platforms, so the numbers move over time.

Do I need a login or API key to scrape TalentBrew (TMP Worldwide)?

No. The actor reads the public job list of the career site and needs no login or API key of the employer. You only need an Apify account to run it.

Can I scrape non-F500 companies that use TalentBrew (TMP Worldwide)?

Yes. The F500 list is only a starting point; any TalentBrew career site works. Pass the career-site URL as {"platform": "talentbrew", "company": URL}.

Can the same run mix TalentBrew with other ATS platforms?

Yes. The Career Site Jobs Scraper supports more than 30 ATS platforms and sites, and one run can contain URLs of different systems. Every row carries ats_platform so you can tell them apart.

What does it cost?

$0.001 per job returned plus $0.001 per run start (pay per event, no monthly fee). Filters such as keywords, location and postedWithinDays run before charging, so you only pay for matching jobs.
