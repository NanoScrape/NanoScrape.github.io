How to Scrape TikTok Videos and Extract Engagement Metrics

TikTok does not offer a public data API. The Research API exists but requires a formal application, is limited to US content, and caps you at 1,000 requests per day. This tutorial shows a faster path: a pay-per-result scraper on Apify that returns about 30 fields per video -- play counts, likes, comments, shares, saves, hashtags, mentions, music metadata, and embedded author data -- from any public TikTok profile. No login, no API key, no monthly subscription. A run covering one profile costs about five cents.

What you get

The NanoScrape TikTok Video Scraper runs on Apify. You give it a list of TikTok usernames or profile URLs; it returns one JSON item per video with roughly 30 fields. Results are downloadable as JSON, CSV, or Excel. No TikTok account or API key required.

  • Engagement metrics: play count, like count, comment count, share count, and save count for each video.
  • Content metadata: caption text, detected language, duration in seconds, pinned flag, slideshow flag, and ad flag.
  • Hashtags and mentions: parsed directly from the caption and TikTok's internal markers, deduplicated automatically.
  • Music metadata: track ID, title, artist name, whether it is the original sound, and the audio stream URL.
  • Media URLs: MP4 video stream URL, cover image URL, and video dimensions (width and height in pixels).
  • Author block: username, user ID, display name, verified badge, follower count, and sec UID embedded in every video row.
The signed URLs for video streams and cover images rotate regularly. If you need to store the actual media files, download them within a few hours of the run completing.

Already have an account? Click the actor link above and you land directly on the input form.
STEP 2

Open the TikTok Video Scraper

After signing in, you are on the actor's page. Click Information in the left sidebar to read the full documentation and field reference, or click Input to go straight to the configuration form.

STEP 3

Add profiles and configure limits

The input form has two main fields:

  • profiles (required): an array of TikTok usernames, @handles, or full profile URLs. Add one per line. mrbeast, @mrbeast, and https://www.tiktok.com/@mrbeast are all equivalent.
  • maxVideosPerProfile: how many recent videos to return per profile. Default is 30. Set higher to paginate further back in the profile history.
{
 "profiles": ["mrbeast", "nike", "nasa"],
 "maxVideosPerProfile": 50
}

That input returns up to 150 videos (3 profiles x 50 videos). Each profile is fetched in parallel.

Prefer JSON? Click JSON editor in the top right of the input form and paste the snippet above. This is faster when you have a long list of profiles.
STEP 4

Run the actor

Click Save and Run at the bottom of the input form. Apify starts the actor and you see the live log in the Log tab. A run covering one profile of 30 videos typically finishes in under 30 seconds.

If the run shows FAILED, the most common causes are:

  • Private profile: the account is set to private on TikTok. Only public profiles return results.
  • Username not found: double-check the handle. TikTok usernames are case-insensitive but spelling must be exact.
  • Insufficient credits: your Apify balance is below $0.02. Top up in Apify Console billing.
STEP 5

Export your results

Once the run succeeds, click Results in the run detail page. You see a table with one row per video, all 30 fields visible as columns. Click Export and choose a format:

  • JSON: full nested objects, best for programmatic processing. The engagement, music, media, and author fields keep their nested structure.
  • CSV: flat rows, opens directly in Excel or Google Sheets. Nested fields are flattened with dot notation.
  • Excel: formatted workbook with a TikTok Videos sheet.

You can also access the dataset via the Apify API using the dataset ID shown in the run URL, or connect it from n8n, Make, or Zapier using their Apify integrations.

Common use cases

  • Brand monitoring: scrape your brand's TikTok account weekly to track how each video performs and identify which content formats get the most shares and saves.
  • Competitor analysis: pull the last 100 videos from a competitor's profile, sort by play count, and find which topics are driving the most views for them.
  • Influencer vetting: before a partnership, extract average engagement rates (likes plus comments divided by plays) across recent videos to validate claimed performance numbers.
  • Hashtag research: collect videos from creators in your niche and aggregate the hashtags field to find which tags appear consistently on high-performing content.
  • Content calendar inspiration: filter the results by created_at to see what days and times top creators post, and compare that to engagement counts.
  • Music trend tracking: count which tracks appear most often across a set of profiles to spot trending audio before it peaks.

Field reference

  • id: TikTok video ID string.
  • url: full URL to the video page.
  • text: caption text as written by the creator.
  • language: TikTok's auto-detected caption language code (e.g. en).
  • created_at: ISO 8601 publish timestamp.
  • created_at_unix: publish timestamp as a Unix integer.
  • duration_sec: video length in seconds.
  • is_pinned: true if the creator pinned this video to the top of their profile.
  • is_slideshow: true if the video is a photo slideshow rather than a video clip.
  • is_ad: true if TikTok flagged this as a paid partnership post.
  • engagement.play_count: total view count.
  • engagement.like_count: total likes.
  • engagement.comment_count: total comments.
  • engagement.share_count: total shares.
  • engagement.save_count: total saves (bookmarks).
  • hashtags: array of hashtag strings parsed from the caption.
  • mentions: array of mentioned username strings.
  • music.id, music.title, music.author_name, music.original: audio track metadata.
  • media.video_url: signed MP4 stream URL (short-lived).
  • media.cover_url: signed cover image URL (short-lived).
  • media.width, media.height: video dimensions in pixels.
  • author.username, author.display_name, author.verified, author.follower_count: creator identity fields.
  • source_profile: the input username that produced this result.
  • scraped_at: ISO 8601 timestamp of when the record was collected.
If you need richer author data -- bio, link in bio, account creation date, or TikTok Shop seller status -- feed those usernames into the TikTok Profile Scraper. The two actors pair naturally: use this one to find which creators post the best content, then enrich those profiles.

Schedule recurring runs

From the actor page in Apify Console, click Schedules in the left sidebar and then Create schedule. Set a cron expression -- for example, 0 9 * * 1 for every Monday at 9 AM UTC -- and attach this actor with the same input JSON you tested manually.

Each scheduled run writes to a fresh dataset. To process results automatically, add a webhook in the schedule settings: Apify sends a POST request to your endpoint when the run finishes, with the dataset ID in the payload. Pull the results into a Google Sheet, a database, or a Slack channel from there.

If you prefer a no-code automation layer, the n8n Apify node starts the actor and waits for the dataset in a single workflow step. Useful if you want to filter results or push them to another service without writing code.

FAQ

Do I need a TikTok account or API key to use this scraper?

No. The scraper works without any TikTok login or API credentials. It fetches data from public profiles via TikTok's signed web API, the same mechanism a browser uses.

Can I scrape private TikTok accounts?

No. Only public profiles return results. If a profile is set to private on TikTok, the scraper will not be able to access its videos.

How many videos can I get per run?

There is no hard run cap. Set maxVideosPerProfile to however many you need and the scraper paginates automatically. For very large archives (500+ videos per profile), run times will be longer.

How current is the engagement data?

Engagement counts are snapshots taken at the moment of scraping. Play counts, likes, shares, and saves on popular videos can grow by thousands per hour. Re-run the actor on the same profiles to get fresh numbers.

The video URLs expire. Can I get stable links?

The url field contains the stable TikTok video page URL (e.g. tiktok.com/@username/video/ID). The media.video_url and media.cover_url fields are signed CDN links that TikTok rotates every few hours. Download those files promptly if you need them.

Can I scrape hashtag pages or the For You feed?

This actor scrapes by profile, not by hashtag or feed. For hashtag-based discovery, the actor supports passing profile URLs directly. You would need to identify the profiles first, then feed them in.

Is scraping TikTok legal?

Scraping publicly available data is generally permitted in most jurisdictions. The hiQ Labs v. LinkedIn ruling in the US confirmed that scraping public data does not violate the Computer Fraud and Abuse Act. TikTok's Terms of Service prohibit automated data collection, which creates civil risk (account suspension, cease-and-desist), but not criminal risk for public data. For GDPR purposes, any personal data in the output is subject to data protection rules. Consult a lawyer for your specific situation.

Can I connect the output to Google Sheets or a database?

Yes. Download CSV or JSON from the dataset page and import manually, or use the Apify API with the dataset ID to pull results programmatically. For automation, add a webhook to your schedule so a downstream workflow in n8n, Make, or Zapier is triggered when each run finishes.
