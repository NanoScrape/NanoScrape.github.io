Export engineering jobs in Germany from Jobware into a spreadsheet

You want a list of engineering jobs in Germany with company and location, narrowed to one discipline such as mechanical or electrical engineering, in a spreadsheet you can sort and share. The Jobware.de Scraper collects the listings from Jobware, and a filter in Google Sheets keeps only your discipline. No code needed.

Time: 10 minutes
Difficulty: Beginner
Tools: Apify, Google Sheets
Open the Actor on Apify → See the cost

What you will have at the end

One Google Sheet with one row per engineering listing from Jobware: title, company, city, German state, discipline category, employment type, remote option, posting date and the link to the ad. Jobware is a German job portal for professional roles, and its listings carry a category field that names the discipline, which is what lets you keep one discipline and drop the rest. The Jobware.de Scraper collects the rows; Sheets does the filtering.

Step 1: Open the Actor

  1. Open the Jobware.de Scraper on Apify and click Try for free. Apify's free plan includes monthly platform credit, enough for a first test.
  2. On the Input tab, switch the editor to JSON.

Step 2: Paste this input

The example searches for mechanical engineers (“Maschinenbauingenieur”) across all of Germany. There is no city, so the search covers the whole country; add city and radius (in km) later if you want one region. Replace the term with your discipline, in German as the ads are written, for example “Elektroingenieur” or “Bauingenieur”.

{
  "searchQueries": ["Maschinenbauingenieur"],
  "includeDetails": true,
  "sortBy": "date",
  "maxResultsPerQuery": 100
}
  • searchQueries: your discipline. Add several terms to cover synonyms; duplicates are removed by listing ID.
  • includeDetails: true fetches each ad's detail page, which is where fields such as category, experience_level and the full description come from. Turn it off for a faster, cheaper title-and-company list.
  • sortBy: date puts the newest first inside each keyword's results.
  • maxResultsPerQuery: the ceiling per keyword. Start at 100; the default is also 100.

The fields that matter for an engineering export:

  • title, company, location: the role, the employer and the city. Many ads come from recruiting firms; the company value is whoever placed the ad.
  • canton: for Germany this is the state code (BW, BY, HB and so on). The sample shows HB for Bremen. It is filled on every row in the Actor's field table, so it works for a regional split without matching city names.
  • category: the discipline classification from the ad, a comma-separated text. This is your filter column. It is filled on about 80% of rows (detail pages only), so keep the title as a second filter.
  • employment_type and remote_option: full-time or part-time, and remote, hybrid or onsite. remote_option is filled on about 40% of rows.
  • salary_min and salary_max: only when the ad states a salary, about 8% of rows. Treat them as a bonus, not a column to rely on.
  • posted_at and source_url: the posting date and the link back to the ad.

Step 4: Turn it into a filtered spreadsheet

  1. In the Dataset tab click Export, choose CSV and select these fields in this order: title, company, location, canton, category, employment_type, remote_option, posted_at, source_url. Contact fields are left out on purpose.
  2. In Google Sheets choose File → Import → Upload and replace the current sheet, so the headers are in row 1 and category is column E.
  3. Select the data and choose Data → Create a filter. On the category column choose Filter by condition → Text contains and enter your discipline word, for example Maschinenbau. Do the same on title with Ingenieur if you want to drop non-engineering roles that matched the search.
  4. Sort by posted_at descending so the newest ads come first.

If you prefer a separate clean tab that updates when you paste new data, use a formula on a second sheet:

=FILTER(A2:I, REGEXMATCH(LOWER(E2:E), "maschinenbau|konstruktion"))

To see which states hire most for the discipline, a count by the state column works as well:

=QUERY(A:I,"select D, count(A) where D is not null group by D order by count(A) desc label D 'State', count(A) 'Listings'",1)

Open the link in source_url to read the ad itself. Always check the ad before you contact an employer; the table is a shortlist, not a final answer.

Start with 100 rows. Look at the first export before you raise maxResultsPerQuery. If the category column is not what you expected for your term, adjust the term, not the filter.

Keep the sheet current

Create a Schedule in the Apify Console to run the same input weekly. With sortBy set to date, add maxAgeHours (for example 192 for a weekly run with a day of overlap) and the Actor stops when it reaches older listings, so each run only collects what is new. Apify's integrations, or an n8n or Make scenario that calls the dataset, can append the rows to the sheet; dedupe on id if you export it.

Frequently asked questions

How do I keep only one engineering discipline?

Use a specific search term (for example Maschinenbauingenieur) and then filter the category column in Google Sheets with Text contains. Add a second filter on the title, because the category field is filled on about 80% of rows.

Can I limit the export to one German region?

Yes. Add city and radius to the input to search around a city, or filter the canton column in Sheets afterwards. For Germany that column holds the state code, such as BW or BY.

Why are some columns empty?

Salary, remote option and category are only present when the ad or its detail page provides them. In the Actor's field table salary is filled on about 8% of rows and remote option on about 40%.

How much does the export cost?

The price is $8.75 / 1,000 job detail result, so 100 results ≈ $0.88. Set maxResultsPerQuery to cap each run.
