Why look for apprenticeships here

Apprenticeships in Germany are filed under their own offer type at the Bundesagentur fuer Arbeit. That makes it possible to ask for Ausbildung offers only, in one city, for one occupation, and nothing else. The Arbeitsagentur Scraper sends this filter for you and returns each offer as one row. You can then see which employers near you train in an occupation, and how many places they list. The German export tutorial covers the general export with state and time filters. This page is only about Ausbildung.

STEP 1

Open the Arbeitsagentur Actor

  1. Open the Arbeitsagentur Scraper on Apify. The Actor page on NanoScrape lists every output field.
  2. Click Try for free and sign up with Google or email. Apify's free plan includes monthly platform credit, enough for a first test.
  3. You land on the Actor's Input tab. Switch to the JSON view to paste the input below.
STEP 2

Paste this input

Example: nursing apprenticeships (Pflege) in and around Berlin, published in the last 28 days, newest first. Replace the keyword, the title words and the city with yours.

{
  "searchQueries": [
    "Pflege"
  ],
  "titleFilter": "Ausbildung, Auszubildende, Pflegefachmann, Pflegefachfrau",
  "location": "Berlin",
  "radius": 25,
  "offerType": "training",
  "postedWithinDays": 28,
  "sortBy": "newest",
  "maxResultsPerQuery": 100,
  "includeJobDetails": false
}
  • searchQueries: the occupation, in German. Add more, for example “Mechatroniker”; duplicates are removed across keywords.
  • offerType: the apprenticeship filter. The value training asks for Apprenticeship / dual study (Ausbildung) offers only. The other values are work, self_employed and internship_trainee.
  • location and radius: city and radius in km. The radius needs a location.
  • postedWithinDays: only offers published in the last N days. Any whole number works, for example 7, 14 or 28.
  • titleFilter: keeps only offers whose title contains one of your words. It is applied before details are loaded.
  • sortBy: newest puts the newest offers first.
  • includeJobDetails: off keeps the run fast. Turn it on only if you need the full description and company website.
Prefer a whole state? Leave location empty and set bundesland to a state code such as BY (Bayern) or NW (Nordrhein-Westfalen).
STEP 3

Run it and read the output

Click Save and Run. When the run ends, open the Dataset tab. Each row is one offer. This is the sample item from the Actor documentation, shortened to the list fields (the contact, salary and company-profile fields are left out). It shows a regular job ad to illustrate the fields; apprenticeship offers have the same structure:

{
  "id": "12345-10000000000-S",
  "title": "Pflegeassistent /in",
  "company": "Beispiel Pflege GmbH",
  "location": "10179, Berlin",
  "country": "DE",
  "employment_type": "full-time",
  "description_snippet": "Fur [mehrere] Standorte des Grossraums Berlin...",
  "posted_at": "2026-02-26T00:00:00.000Z",
  "modified_at": "2026-02-26T14:51:45.062Z",
  "source_url": "https://www.arbeitsagentur.de/jobsuche/jobdetail/12345-10000000000-S",
  "source_platform": "arbeitsagentur.de",
  "search_query": "Pflege",
  "scraped_at": "2026-03-04T15:36:48.707Z"
}

The fields you need for an Ausbildung list:

  • title and company: the offer and the training employer.
  • location: postal code and place.
  • posted_at and modified_at: when the offer was published and last changed.
  • source_url: the link to the offer on arbeitsagentur.de, where you apply.
  • description_snippet: a short text from the offer. With includeJobDetails on you also get the full description and the company website where the employer provides one.

This tutorial does not use any contact fields. Apply through the link in the offer, and check the data-protection rules for your use before you store personal data.

STEP 4

Turn the offers into an Ausbildung list

  1. In the Dataset tab click Export, choose CSV and select title, company, location, posted_at, source_url.
  2. Import the file into Google Sheets (File → Import) as a sheet called jobs. With the order above, the title is column A, the employer B and the place C.
  3. On a new sheet, count the open offers per training employer:
=QUERY(jobs!A:E, "select B, count(A) where A is not null group by B order by count(A) desc", 1)
  1. Sort by the count, largest first. Employers with several offers are the ones that train in your occupation at scale. Open source_url to read an offer and apply.

Only see what is new

Set onlyNewSinceLastRun to true and schedule the same input in the Apify Console under Schedules. The Actor then skips every offer it delivered in an earlier run with the same search settings, so each run returns only new offers.

Frequently asked questions

What is the difference between offerType training and employmentType APPRENTICESHIP?

Both ask the Bundesagentur for apprenticeship offers (angebotsart 4). If you set offerType, it replaces the offer type that employmentType would set, so use offerType training when you want to be explicit.

Does offerType training include dual study programs?

The label of the offer type is Apprenticeship / dual study (Ausbildung / duales Studium), so the search covers what the Bundesagentur files under this type. Use titleFilter if you want only certain job titles.

What does onlyNewSinceLastRun do?

It remembers the job IDs the Actor delivered in earlier runs with the same search settings and skips them before details are fetched and before you are charged. It keeps the last 50,000 IDs and is off by default.

What does it cost?

The Actor is pay per event. See the current price on the Actor page. The price on NanoScrape's Actor page is always the current one.
