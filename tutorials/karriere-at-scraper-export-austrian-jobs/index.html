How to export Austrian jobs from karriere.at to a spreadsheet

You need the current job ads from Austria for one keyword, for example “Pflege” (nursing and care), in a spreadsheet you can sort, filter and share? karriere.at shows the ads one search page at a time and has no export button. The Karriere.at Scraper runs your search, opens every ad and returns one row per job with title, employer, city, salary, posting date and the link to apply. This guide is for recruiters, career coaches and analysts who want a clean list in Google Sheets or Excel in about ten minutes, without code.

Difficulty: Beginner
Time: 10 minutes
Cost: 100 jobs ≈ $0.50
Tools: Apify Console, Google Sheets

STEP 1

Open the Actor

  1. Open the Karriere.at Scraper on Apify.
  2. Click Try for free and sign up with Google or email. Apify's free plan includes monthly platform credit, enough for a first test.
  3. You land on the Actor's Input tab. Switch to JSON view so you can paste the input below.
STEP 2

Paste this input

This searches karriere.at for “Pflege” (nursing and care), keeps ads from the last 30 days, puts the newest first and fetches the detail page of each ad, so you get salary, description and apply link:

{
  "searchQueries": ["Pflege"],
  "datePosted": "30",
  "sortBy": "date",
  "maxResultsPerQuery": 100,
  "includeJobDetails": true
}
  • searchQueries: one or more keywords. Each runs as its own search and duplicate ads are removed. Add “Krankenpfleger” or “Altenpflege” to widen the list.
  • datePosted: age of the ads in days (1, 7 or 30).
  • sortBy: date puts the newest ads first.
  • maxResultsPerQuery: upper limit per keyword. Keep it at 10 for a first test.
  • includeJobDetails: true adds the detail page. false is faster and cheaper but returns fewer fields.

To narrow the list by place, add location (for example "Graz") or bundesland, and employmentType (Vollzeit, Teilzeit, Geringfuegig, Lehrstelle or Praktikum). German keywords work best because the ads are written in German.

Start small. Set maxResultsPerQuery to 10 on the first run, check that the rows fit your keyword, then raise it.
STEP 3

Run it and read the output

Click Save and Run. When the run finishes, open the Dataset tab. Every row is one ad. This is a real item from a run with the keyword “Pflege”, shortened: the full ad text (description_md) and the contact fields are left out here.

  "detail_status": "ok"
}

The fields you will use in the spreadsheet:

  • title, company and location: what the job is, who offers it, and the city.
  • employment_type: part-time here (Teilzeit in the ad). Use it to filter full-time against part-time.
  • salary_text, salary_min, salary_max, salary_period: the salary exactly as the ad states it, and as numbers you can sort. In this ad only a minimum is given, so salary_max is empty. Ads without a stated salary leave these cells empty.
  • posted_at: publication date as YYYY-MM-DD, which sorts correctly as text.
  • source_url, apply_url and company_url: the ad, the application link and the employer profile on karriere.at.
  • remote_option: remote, hybrid or onsite, when the ad says so.
Contact fields. When an ad names a contact person, the Actor can return the name, email and phone in contact_* fields. That is personal data, so leave those columns out of the export unless you have a reason to keep them.
STEP 4

Turn it into a spreadsheet you can sort

  1. In the Dataset tab click Export, choose CSV and pick only these fields: title, company, location, employment_type, salary_text, salary_min, posted_at, source_url, apply_url. Fewer columns keep the sheet readable.
  2. In Google Sheets choose File → Import → Upload and replace the current sheet. In Excel use Data → From Text/CSV and select UTF-8 if the umlauts look wrong.
  3. Sort by posted_at (Z to A) so the newest ads are on top.
  4. Turn on Data → Create a filter. Filter employment_type to part-time or full-time, and salary_min to “not empty” to see only ads that state a salary.
  5. Add a clickable link column: =HYPERLINK(H2,"Open ad") if source_url is in column H.
  6. See who hires the most: Insert → Pivot table, rows = company, values = count of title.

To keep the list fresh, create a Schedule in the Apify Console (weekly), set datePosted to "7" and add each new export below the old rows. The ad number in id lets you remove duplicates with Data → Data cleanup → Remove duplicates. If you prefer automation, an n8n or Make scenario with an Apify step and a Google Sheets step does the same without manual uploads.

Frequently asked questions

Can I search several keywords in one run?

Yes. Put several terms in searchQueries, for example Pflege, Krankenpfleger and Altenpflege. Each term runs as its own search, and an ad that appears under more than one term is returned once. The search_query column tells you which term found each ad.

How do I limit the export to one city or state?

Add location (for example Graz or Wien) or bundesland to the input. You can combine them with employmentType (Vollzeit, Teilzeit, Geringfuegig, Lehrstelle or Praktikum) and datePosted (1, 7 or 30 days).

Why are some salary cells empty?

Many ads do not state a salary. salary_min, salary_max and salary_text are filled only when the ad gives one. Some ads give just a minimum, as in the sample row, so salary_max stays empty.

How much does an export of 100 jobs cost?

On the actor page the price is $5.00 / 1,000 job with detail-page enrichment, so 100 jobs are about $0.50. With includeJobDetails off the per-job price is lower and some fields are missing.
