Available fields

  • id: unique Eventbrite event identifier.
  • title: event display name.
  • description: short event summary from Eventbrite (at most 140 characters in our 100-event test run, not the full text of the event page).
  • start_date / end_date: ISO 8601 timestamps with timezone offset.
  • timezone: IANA timezone string, for example Europe/Berlin.
  • url: direct Eventbrite link to the event.
  • image_url: event banner image URL.
  • is_free: boolean, true when the event has no ticket price.
  • is_online: boolean, true for virtual events.
  • price: ticket price as a string, or a range such as 99.0 - 199.0 when an event has several ticket types.
  • currency: ISO 4217 currency code.
  • venue_name: name of the physical venue.
  • venue_address: street address of the venue.
  • venue_city / venue_country: city and country for filtering.
  • latitude / longitude: GPS coordinates of the venue.
  • organizer_name: name of the event organizer.
  • organizer_url: Eventbrite organizer profile URL.
  • category: Eventbrite category, for example Science & Technology or Music.
  • tags: array of event tags set by the organizer.
  • attendee_count: part of the output schema, but the actor does not fill it today (empty in every row we tested).
  • source_url: the Eventbrite search page this event was found on.
  • scraped_at: ISO 8601 timestamp of the scrape.
Speed vs. detail: Set includeDetails: false to skip each event's detail page. You then get no price, currency, is_free or organizer_* fields, but the run is much faster. With details on, our 100-event test run took about 7 minutes.

STEP 1

Open the actor

  1. Go to the Eventbrite Scraper on Apify.
  2. Click Try for free and sign in with Google or email. No credit card required.
  3. You land on the Input tab, ready to configure your search.
STEP 2

Set your search

There are two ways to define what to scrape. The simplest is to paste a search URL directly from Eventbrite.

Option 1: Paste a search URL

Copy a search page URL from Eventbrite and paste it into Search URLs. You can add multiple URLs and the actor splits the result budget evenly across them.

{
  "searchUrls": [
    "https://www.eventbrite.com/d/germany--berlin/tech/",
    "https://www.eventbrite.com/d/united-kingdom--london/conferences/"
  ],
  "maxResults": 100
}

Option 2: Search by keyword and location

Leave Search URLs empty and set a Search Query and Location instead. The actor builds the URL for you.

{
  "searchQuery": "tech",
  "location": "united-states--new-york",
  "maxResults": 50
}
Location format: Use Eventbrite's URL slug format. Countries: germany, france. Regions: united-states--new-york, germany--berlin. Cities: ca--san-francisco, united-kingdom--london. For online events: online.

Key input parameters

  • Search URLs: one or more Eventbrite search page URLs.
  • Search Query: keyword or category slug such as conferences or networking.
  • Location: Eventbrite location slug. Default: germany.
  • Max Results: maximum events to return (1 to 5,000). Default: 100. The budget is shared evenly across all search URLs, with unused results rolling over to the next URL.
  • Include Details: when true (the default), fetches each event's detail page for price, currency, and organizer_* fields. Set to false for faster runs when you only need basic listing data.
STEP 3

Run and watch the results

Click Start at the top right. Events appear in the Results tab as the actor pages through the search. Each search page holds up to 20 events (often fewer once promoted duplicates are removed), so a 100-event run reads 5 or more pages. With includeDetails: true, the actor also fetches each event's detail page for ticket price and organizer data.

Search depth: Eventbrite caps its own search results at 49 pages, which is about 1,000 events per search URL. For more results from a single market, split your search across several cities or categories by providing multiple search URLs.
STEP 4

Export your results

From the Results tab, click Export to download in JSON, CSV, Excel, or HTML. For automated pipelines, use the Apify API or connect to Google Sheets, Airtable, or a webhook via the Integrations panel.

Google Sheets integration: In the Integrations panel, click Google Sheets and connect your account. After each run, results append automatically to a sheet you choose -- useful for building an event-tracking dashboard without writing any code.

Common use cases

Event discovery and monitoring

Run the same search on a schedule to track what is happening in a city or category over time. The start_date, venue_city, and category fields let you filter and sort programmatically -- useful for building an internal events calendar or alerting system.

Conference and networking lead generation

Find events where your target audience gathers. Filter by category and venue_city, then use the organizer_name and organizer_url fields to reach out to conference organizers about sponsorships or speaking slots. The tags field gives you niche sub-topics beyond the main category.

Competitive event tracking

Monitor events in your industry to see when and where competitors or complementary products sponsor or exhibit. The category and tags fields narrow a broad search down to your niche, and organizer_name shows who runs each event.

Geo-mapping and market research

Events with a physical venue include latitude and longitude (every row in our 100-event test run had them). Feed these into a mapping tool to visualize event density by city, identify under-served markets, or find clusters of activity around a specific date range.

Automate with n8n

To track upcoming events on a weekly schedule and push results to a spreadsheet or CRM, connect the actor to n8n using the Apify node.

  1. In n8n, add a Schedule trigger set to weekly.
  2. Add an Apify node, select Run Actor, and enter santamaria-automations/eventbrite-scraper as the actor ID.
  3. Set the input JSON with your search URL or location and category.
  4. Add a Google Sheets or Airtable node to append each week's results to a tracking spreadsheet.
  5. Optionally add a Filter node to pass only events where is_free is false and start_date is within the next 30 days, then send a summary to Slack or email.
n8n's Apify node handles polling automatically -- it starts the actor run and waits for completion before passing results to the next node. No custom API calls needed.

FAQ

Do I need an Eventbrite account or API key?

No. The actor scrapes Eventbrite's public search and event pages without authentication. No account, no API key, and no session cookies are required.

How many events can I scrape at once?

Set maxResults to any number between 1 and 5,000. Eventbrite caps its own search results at about 1,000 events (49 pages) per search URL. For more, provide multiple search URLs for different cities or categories -- the actor splits the budget evenly across them.

Why are some price or organizer fields empty?

price, currency, is_free and the organizer_* fields come from each event's detail page, which the actor fetches only when includeDetails is true (the default). If you turned it off for speed, those fields are null. Even with details on, some events publish no price: in our 100-event test run, 9 had none.

Can I scrape online or virtual events?

Yes. Set location to online or include an Eventbrite search URL filtered to online events. The is_online field in the output confirms whether each event is virtual.

How do I get only free events?

The actor returns all events from your search URL regardless of price. After the run, filter the dataset by is_free: true. The actor keeps the query parameters of your search URL, so you can also set filters on Eventbrite in your browser first and paste the filtered URL into Search URLs.

What does the free Apify tier cover?

The free tier includes $5 of credit per month. At $0.003 per event, that covers roughly 1,600 events before any charges apply.

Does the actor work for all countries?

The actor works with any Eventbrite location slug, for example france, japan or australia--sydney. Our own test runs covered Germany and the United States.
