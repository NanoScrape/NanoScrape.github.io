# Shared tutorial assets

Screenshots and other static assets that are **identical across every tutorial** and shouldn't be re-taken per tutorial. Currently empty; hand-take these once when we're ready to enable the shared-assets pattern in the writer agent.

## What belongs here

Anything that is genuinely universal — the exact same screenshot regardless of which actor or automation tool the tutorial targets.

Good candidates:
- `assets/apify-personal-api-token.png` — Apify Console Settings → Integrations tab (works for every actor)
- `assets/n8n-import-menu.png` — n8n workflows list three-dot menu with "Import from File" highlighted (works for every n8n tutorial)
- `assets/apify-credential-in-n8n-dropdown.png` — the "Create new credential" dropdown state of the Apify n8n node
- `assets/google-sheets-oauth-consent.png` — Google OAuth consent screen for n8n Google Sheets credential

Bad candidates (never put these here):
- Anything actor-specific (belongs in the tutorial's own `assets/` folder, auto-generated by the screenshot pipeline)
- Anything tutorial-specific (URL bar with a specific sheet ID, canvas showing a specific workflow)

## Referencing shared assets from a tutorial

In the tutorial JSON, use an absolute-from-site-root path in a Figure's `src`:

```json
{
  "type": "figure",
  "figure": {
    "src": "/tutorials/_shared/assets/apify-personal-api-token.png",
    "alt": "Apify Console Settings page with the Personal API token field visible",
    "width": 3200,
    "height": 1846
  }
}
```

Tutorial-specific screenshots stay with the relative `assets/xxx.png` pattern so they're colocated with the tutorial folder.

## How the writer agent decides

The writer agent (PR 4) will:
1. Consult a mapping of "these tutorial types need these shared shots" (e.g., every n8n+Apify tutorial gets the apify-credential shared shot in Step 3).
2. Reference the shared shot by absolute path in the tutorial JSON.
3. Only auto-generate tutorial-specific shots via the screenshot pipeline.
4. List anything still missing in the PR's `## Manual TODOs` block for you to add.
