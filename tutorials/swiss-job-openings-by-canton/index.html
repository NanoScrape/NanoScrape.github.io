Count Swiss job openings by canton and compare them in Google Sheets

Which Swiss cantons hire the most nurses, electricians or accountants right now? The Arbeit.Swiss Scraper pulls the listings of one occupation from the official Swiss job platform, and a pivot table in Google Sheets turns them into a canton-by-canton count. Every number comes from your own run. This tutorial covers the comparison; if you only want a plain export, see the export tutorial.

Time: 10 minutes
Difficulty: Beginner
Tools: Apify, Google Sheets
Open the Actor on Apify → See the cost

Why a pivot table, and what the data is

The Swiss federal job platform (job-room.ch, shown as arbeit.swiss, travail.swiss, lavoro.swiss and work.swiss) lets you search by canton, but it does not give you a table that compares cantons side by side. The Arbeit.Swiss Scraper returns every matching listing as one row, and each row carries a two-letter canton code. Count the rows per canton and you have a regional demand comparison for one occupation.

Two limits to keep in mind. First, you count the listings on this platform, not every vacancy in Switzerland, so use the numbers to compare cantons with each other rather than as a total for the labour market. Second, only count what your table contains: the counts come from your run, never from an estimate.

Step 1: Open the Actor

  1. Open the Arbeit.Swiss Scraper on Apify and click Try for free. Apify's free plan includes monthly platform credit, which is enough for a first count.
  2. You land on the Input tab. Switch the input editor to JSON so you can paste the settings below.

Step 2: Paste this input

One occupation, all cantons. Leave cantonCodes out: an empty list means all cantons, which is what a comparison needs. This example counts nursing (“Pflege”); swap in your own term, in German, French or Italian.

{
  "searchQueries": ["Pflege"],
  "titleFilter": "Pflege",
  "onlineSinceDays": 60,
  "maxResultsPerQuery": 1000,
  "sortBy": "newest"
}
  • searchQueries: the occupation. Use one term per run, so every row belongs to the same question.
  • titleFilter: keeps only ads whose title contains the term, applied before the details are fetched and before you are charged. The search also matches ads that only mention the word in the text, and those would inflate some cantons.
  • onlineSinceDays: only listings posted in the last 60 days (also the default). Use the same value every time you repeat the count.
  • maxResultsPerQuery: the ceiling per term. If your table ends up with exactly this many rows, the cap was hit: raise it and run again, otherwise the cantons are cut off unevenly.

Step 3: Run it and read the output

Click Save and Run. When the run finishes, the Dataset tab holds one row per listing. This is one real row from the Actor (shortened to the fields that matter here; values unchanged). It came from a “Pflege” search and is a good reminder of why titleFilter exists: the word only appears in the ad text, in “Wartung und Pflege der Maschinen”.

}

The fields for this task:

  • canton: the two-letter canton code (ZH, BE, AG and so on). This is your pivot row. In the Actor's field table it is filled for about 92% of rows, so expect a blank group in the pivot.
  • id: unique per listing, so counting it counts positions.
  • company, city: use them to see which employers or cities sit behind a canton's number.
  • workload_min and workload_max: the Pensum, the workload in percent. 100 is full-time.
  • posted_at: the posting date, handy for a week-by-week count.

Step 4: Build the pivot table in Google Sheets

  1. In the Dataset tab click Export, choose CSV, and select only these fields in this order: id, title, canton, company, workload_min. Download the file.
  2. In Google Sheets choose File → Import → Upload and replace the current sheet, so the data starts in A1 with id in column A and canton in column C.
  3. Select the data and choose Insert → Pivot table (new sheet).
  4. Under Rows add canton. Under Values add id and set it to COUNTA (or COUNTUNIQUE if you ran several overlapping terms). Set Sort by to the count, descending.
  5. Add a second value, workload_min, summarised by AVERAGE, to see whether a canton's positions skew part-time.

Prefer a formula to the pivot editor? This one returns the same canton ranking and refreshes when you paste new data into the sheet:

=QUERY(A:E,"select C, count(A) where C is not null group by C order by count(A) desc label C 'Canton', count(A) 'Open positions'",1)

To compare the cantons fairly, also read the counts next to each canton's size. A big canton has more listings simply because it has more people, so divide by population or by the number of employers if your question is about intensity rather than volume. The population figures are yours to add from an official statistics table; the Actor does not provide them.

Check one canton cheaply. If you want to verify a single canton against the platform's own total, set cantonCodes to that canton and statsMode to only. The Actor then returns the platform-reported total for the query instead of the listings, with no per-result charge.

Repeat it every month

A single count is a snapshot. To see whether demand moves, run the same input on a monthly Schedule in the Apify Console, import each result as a new tab, and put the monthly pivots side by side. Keep the term, onlineSinceDays and cap identical, or the months are not comparable.

Frequently asked questions

Can I count open positions per canton without scraping every listing?

For a single canton, yes: set statsMode to only and cantonCodes to that canton. You get the platform-reported total for the query, and no per-result charge. For a full comparison across all cantons you need the listings, because the pivot groups them by the canton field.

Why does my pivot have a blank canton row?

Not every listing states a canton. In the Actor's field table canton is filled for about 92% of rows. Keep the blank group visible in the pivot instead of hiding it, so your totals stay honest.

Why use titleFilter for a count?

The search also returns ads where your term appears only in the description. A welding job that mentions “Pflege der Maschinen” would count as a nursing position. With titleFilter, only ads whose title contains the term are kept, and you are not charged for the rest.
