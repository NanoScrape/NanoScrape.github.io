What is Oracle Recruiting Cloud (ORC) and who uses it

By the NanoScrape team - Published 2026-10-15 - Updated 2026-10-15

Oracle Recruiting Cloud (ORC) is one of the top Applicant Tracking Systems (ATS) used by large enterprises. Our 2026 audit of the Fortune 500 (see the ATS market share study) identified 32 companies (6.4% of the F500) running Oracle Recruiting Cloud (ORC) as their primary careers-page platform: the third-largest commercial ATS in the F500 audit, behind Workday and Phenom.

The NanoScrape Career Site Jobs Scraper calls the public REST requisition endpoint behind the Oracle Recruiting Cloud career site (HTTP only, no browser) and returns structured job records at $0.001 per job ($1 per 1,000 jobs) plus $0.001 per run start. This tutorial gives you the list of F500 Oracle Recruiting Cloud (ORC) companies plus a ready-to-run actor input to scrape their jobs.

Oracle Recruiting Cloud (ORC) URL and API pattern

Oracle Recruiting Cloud (ORC) careers pages follow this URL pattern:

URL pattern:  https://{code}.fa.{region}.oraclecloud.com/hcmUI/CandidateExperience/en/sites/{site}
API endpoint: /hcmRestApi/resources/latest/recruitingCEJobRequisitions (with finder parameter)
How to pass it: Oracle Recruiting Cloud career sites look like https://{code}.fa.{region}.oraclecloud.com/hcmUI/CandidateExperience/en/sites/{site}; the actor reads host and site code from the string. Without a site code it falls back to CX_1, which many tenants do not use, so always include it. The keywords, location, postedWithinDays and sortBy inputs work on this platform too; add includeSummaryRows: true to get one summary row per company explaining a zero result.

STEP 1

Example actor run: first 5 Oracle Recruiting Cloud (ORC) F500 companies

Copy this input into the actor's Input tab (JSON editor mode) to scrape jobs from the first 5 F500 companies in the list above, capped at 100 jobs each:

{
  "queries": [
    "https://jpmc.fa.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1001",
    "https://eluq.fa.us2.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_2001",
    "https://iawmqy.fa.ocs.oraclecloud.com/hcmUI/CandidateExperience/en/sites/careers",
    "https://eofd.fa.us6.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1001",
    "https://ibqbjb.fa.ocs.oraclecloud.com/hcmUI/CandidateExperience/en/sites/Honeywell"
  ],
  "maxJobsPerCompany": 100,
  "includeDescription": true
}
Cost and scale: this input costs at most 5 x 100 = 500 jobs, so at most $0.50 plus $0.001 for the run start. The actor charges $0.001 per job returned; a company with fewer jobs costs less. Running all 23 listed companies with maxJobsPerCompany: 100 would be at most 23 x 100 = 2,300 jobs, about $2.30. Set maxJobsPerCompany to 0 for all jobs (hard limit 5,000 per company). Use keywords, location and postedWithinDays to pay only for matching jobs; filters run before charging.

Output schema for Oracle Recruiting Cloud (ORC)

The actor emits the same field names for every ATS (more than 30 are supported). What Oracle Recruiting Cloud fills in:

  • title: always
  • company: the board name
  • ats_platform: always oracle_recruiting
  • location: available
  • department: available
  • employment_type: available
  • description: HTML, one extra request per job when includeDescription is true
  • apply_url and job_url: always
  • created_at: posting date when the tenant provides it

Known limitations

Tenant hosts are random-looking codes (jpmc.fa.oraclecloud.com, eluq.fa.us2.oraclecloud.com), and one company can run several career sites with different site codes (CX_1001, CX_2001). Pass the URL of the site you want.

Blocked sites: the actor goes direct first and, if a site refuses it, can retry through residential proxies for up to 2 different hosts per run (maxResidentialHosts, default 2; residentialFallback: "off" disables it). A company that is still blocked ends with a reason such as blocked or blocked_residential_cap and is not charged for jobs it did not return. Set includeSummaryRows to see the reason per company.

FAQ

How many Fortune 500 companies use Oracle Recruiting Cloud (ORC)?

Our 2026 audit identified 32 F500 companies running Oracle Recruiting Cloud, 6.4% of the Fortune 500 (see the market share study). Companies migrate between ATS platforms, so the numbers move over time.

Do I need a login or API key to scrape Oracle Recruiting Cloud (ORC)?

No. The actor reads the public job list of the career site and needs no login or API key of the employer. You only need an Apify account to run it.

Can I scrape non-F500 companies that use Oracle Recruiting Cloud (ORC)?

Yes. The F500 list is only a starting point; any Oracle Recruiting Cloud career site works. Pass the career-site URL as a string in the queries array.

Can the same run mix Oracle Recruiting Cloud with other ATS platforms?

Yes. The Career Site Jobs Scraper supports more than 30 ATS platforms and sites, and one run can contain URLs of different systems. Every row carries ats_platform so you can tell them apart.

What does it cost?

$0.001 per job returned plus $0.001 per run start (pay per event, no monthly fee). Filters such as keywords, location and postedWithinDays run before charging, so you only pay for matching jobs.
