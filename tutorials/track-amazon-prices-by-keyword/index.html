How to track Amazon prices for a keyword over time

You sell, source or resell in a niche and want to know how the first results for a keyword move: which products get cheaper, whose ratings climb, who drops out of the top. The Amazon Product Search Scraper reads the Amazon search results page for a keyword on one marketplace. Run it on a schedule with the same input and a short Google Sheets pivot shows price, stars and position per product from week to week. No code needed.

Why track one keyword

A single price check tells you little. What helps in product research is the movement: a product that drops from $59.99 to $49.99, a competitor that gains a few thousand reviews in a month, a newcomer that shows up in the first 20 products. A keyword search is a good unit for this, because the results page is what a shopper sees when they type that phrase. The Actor returns every product on the page with its price, rating, review count, badges and position, so the same search repeated each week becomes a time series. For the top lists Amazon itself publishes, see the Best Sellers product research tutorial. This page is about search results for a phrase you choose.

STEP 1

Open the Amazon search Actor

  1. Open the Amazon Product Search Scraper on Apify. The Actor page on NanoScrape lists every input and output field.
  2. Click Try for free and sign up with Google or email. Apify's free plan includes monthly platform credit, enough for a first test.
  3. You land on the Actor's Input tab. Switch to the JSON view to paste the input below.
STEP 2

Paste this input

Example: the first 50 products for “echo dot” on amazon.com, in Amazon's default relevance order, without paid placements. Replace the keyword and marketplace with yours.

{
  "searchQueries": [
    "echo dot"
  ],
  "country": "US",
  "maxResultsPerQuery": 50,
  "maxPages": 4,
  "sortBy": "relevance",
  "includeSponsored": false,
  "concurrency": 3
}
  • searchQueries: the phrase a shopper types. Each keyword runs as its own search. Use one keyword per tracker so the history stays clean.
  • country: the marketplace for your keywords, for example US, UK, DE, FR or JP (20 are supported). Keep it the same in every run, because prices and currencies differ per marketplace.
  • sortBy: relevance is Amazon's default order and the one that matches what most shoppers see. Do not change it between runs, or positions are no longer comparable.
  • maxResultsPerQuery and maxPages: a results page holds around 16 organic products, so 4 pages cover 50 products. Both caps stop the run; the smaller one wins.
  • includeSponsored: false drops paid placements from the output. They are still counted in the position numbers, so positionOverall matches what a shopper sees.
  • minPrice, maxPrice and minStars are optional filters if you only care about a price band or well-rated products. Add them from the first run on and never change them later.
Prefer to paste an Amazon address? Use startUrls with a search page such as https://www.amazon.de/s?k=kaffeemaschine. The marketplace is read from the address, so country is not needed for it.
STEP 3

Run it and read the output

Click Save and Run. When the run ends, open the Dataset tab. Each row is one product on the results page. This is the example row from the Actor's documentation, shortened to the fields that matter for tracking:

{
  "asin": "B09B8V1LZ3",
  "title": "Amazon Echo Dot (5th Gen, 2022 release) | With bigger vibrant sound",
  "url": "https://www.amazon.com/dp/B09B8V1LZ3",
  "marketplace": "US",
  "searchQuery": "echo dot",
  "sortBy": "relevance",
  "page": 1,
  "positionOnPage": 1,
  "positionOverall": 1,
  "isSponsored": false,
  "isAmazonChoice": true,
  "isBestSeller": false,
  "isPrime": true,
  "price": {
    "value": 49.99,
    "currency": "$",
    "raw": "$49.99"
  },
  "listPrice": {
    "value": 59.99,
    "currency": "$",
    "raw": "$59.99"
  },
  "stars": 4.7,
  "reviewsCount": 193736,
  "deliveryText": "FREE delivery Mon, Jun 16",
  "couponText": "Save $5 with coupon",
  "purchaseVolumeText": "10K+ bought in past month"
}

The fields you need for a tracker:

  • asin: Amazon's product ID, your key for matching a product from one run to the next.
  • price and listPrice: the shown price, and the struck-through price when the product is on sale. couponText shows a coupon if there is one.
  • stars and reviewsCount: rating and number of reviews. purchaseVolumeText is the “bought in past month” text Amazon shows, when it shows one.
  • positionOverall (and page, positionOnPage): where the product sits in the results for this keyword.
  • isSponsored, isAmazonChoice, isBestSeller: the badges on the card.
  • scrapedAt: when the row was read. You need it to tell the weeks apart.

Some fields are empty when Amazon does not show them: listPrice only when the product is on sale, stars and reviewsCount not for products without reviews. That is expected, not an error.

STEP 4

Schedule it and compare weeks

  1. In the Apify Console open Schedules, create a schedule, and add this Actor with the saved input. Weekly is a good start for price movement.
  2. After each run, in the Dataset tab click Export, choose CSV and select asin, title, price, stars, reviewsCount, positionOverall and scrapedAt. Nested fields such as price are flattened into columns; check the header names in the file.
  3. Import the first file into Google Sheets as a sheet called log. For every later run, import the file and append its rows under the old ones (File → Import → Append to current sheet).
  4. Add a date column that cuts the day out of scrapedAt. If scrapedAt is in column G and the data starts in row 2, put this in H2 and drag it down:
=LEFT(G2,10)
  1. Select the log, choose Insert → Pivot table, put asin (and title) in Rows, the date column in Columns and the price value in Values with the summary MAX. You now see every product as a row and every run as a column.
  2. Build a second pivot with positionOverall in Values to see who moves up or down. Add a column to the right of the price pivot that divides the last week by the first week minus 1 to get the change in percent.

Two things to keep in mind when you read the table. A product that leaves the first 50 products simply has no value for that week, which is itself a signal. And the results page is Amazon's ranking for that moment, so small rank changes between two runs are normal; look for products that move over several weeks.

What it costs

The Actor is pay per result, and you are charged for the products it returns, not for failed fetches. Because a tracker runs the same input again and again, check the current price before you schedule it: see the current price on the Actor page or on the Pricing tab of the Actor's Apify page. To keep a tracker small, use one keyword, a low maxResultsPerQuery and a weekly schedule.

Who uses a keyword tracker like this

  • Sellers and brand owners watch how competing products in their niche are priced and rated, and whether coupons or sale prices appear.
  • Product researchers check whether a niche is dominated by a few established products or whether new ones enter the first results.
  • Resellers and deal hunters follow the price of a product group on one marketplace and spot the weeks it is cheaper.

Need the full product page for the products you found, such as description, variants and reviews? Use the Amazon Product Scraper with the asin values from your log. Comparing this Actor with another search crawler? See the comparison with Junglee Amazon Crawler.

Frequently asked questions

Does this show the real best seller rank of a product?

No. It reads the search results page for your keyword. You get the position of each product on that page, plus the Best Seller badge when Amazon shows it. Amazon's category ranks come from its Best Sellers lists, which are a different data source.

Why do I get one row per product and keyword?

Each row is one product on one search. If the same product appears under two keywords, you get two rows, each tagged with its searchQuery. That lets you compare the position of one product across keyword variants.

Can I track several marketplaces?

Yes. Use one run per marketplace with the country input, or mix search addresses from different Amazon domains in startUrls. Keep each marketplace in its own sheet so currencies are not mixed.

Why is listPrice or stars empty for some products?

Amazon shows a struck-through price only when the product is on sale, and ratings only when a product has reviews. When the card does not show a field, it stays empty.

How much does it cost to track one keyword?

The Actor is pay per result. The current price is on the Actor page on NanoScrape and on the Pricing tab on Apify. A tracker with one keyword and a small maxResultsPerQuery keeps the number of products per run low.
