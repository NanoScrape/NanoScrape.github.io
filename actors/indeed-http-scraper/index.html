Indeed HTTP Scraper

The NanoScrape Indeed Http Scraper is an Apify actor that extracts job listings from Indeed Http. It returns 59 fields per result including title, company, location, city, company_name, priced at $5/1k company, with no API key or monthly subscription required.

Scrape Indeed job listings from 60+ countries. Returns title, company, location, salary range, employment type, benefits, skills, posted date and full descriptions (text, HTML, Markdown). Optional company enrichment adds website, industry, size, revenue and CEO. Pay per event.
