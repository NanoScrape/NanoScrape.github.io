Who Should Use This

Oil and gas recruitment agencies and staffing firms need Rigzone-specific fields because a generalist job scraper returns no rotation pattern, no rig type, and no certification list, making it impossible to match candidates automatically. This actor extracts those fields as first-class structured data. Salary benchmark tools for the O&G sector use the day-rate salary period field because contract oilfield roles quote per day, not per year, and most scrapers collapse both into one ambiguous number. Employer outreach teams use includeCompanyDetails: true to get each employer's website and full list of currently open roles, turning a job feed into an E&P company lead list. Renewable energy transition researchers filter industry_segment: renewables to find the subset of Rigzone listings that cross offshore-oil experience with wind and hydrogen, a talent pool that is hard to surface any other way.

  1. Add the n8n Apify node (installed by default on n8n Cloud; on self-hosted install @apify/n8n-nodes-apify).
  2. Set Actor to santamaria-automations/rigzone-us-scraper.
  3. Choose operation Run Actor and get dataset, paste your input JSON, and connect a downstream node (Google Sheets, Postgres, webhook, ...).
  1. Create a new Zap with any trigger.
  2. Add a Webhooks by Zapier POST action to https://api.apify.com/v2/acts/santamaria-automations~rigzone-us-scraper/run-sync-get-dataset-items?token=YOUR_TOKEN.
  3. Body: your input JSON. Content-Type: application/json.
  1. Create a new scenario.
  2. Add an HTTP module: URL https://api.apify.com/v2/acts/santamaria-automations~rigzone-us-scraper/run-sync-get-dataset-items?token=YOUR_TOKEN, method POST, body raw JSON.
  3. Parse the response with a JSON module to iterate items downstream.
  1. Create a new workflow.
  2. Add an HTTP Request step: POST to https://api.apify.com/v2/acts/santamaria-automations~rigzone-us-scraper/run-sync-get-dataset-items?token=YOUR_TOKEN.
  3. Access steps.http.$return_value in subsequent steps.
  1. Install the API Connector plugin.
  2. Add a new API: POST https://api.apify.com/v2/acts/santamaria-automations~rigzone-us-scraper/run-sync-get-dataset-items?token=YOUR_TOKEN, body type JSON.
  3. Initialize the call with your input, then reference the response array in workflow actions.
