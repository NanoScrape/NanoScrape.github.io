您可以抓取的内容

  • 标识：id、video_url、title、type（video、channel、short）、is_short、is_live、is_premiere
  • 互动数据：view_count、like_count、comment_count、engagement_rate（计算所得百分比）
  • 频道上下文：channel_id、channel_name、channel_subscribers、channel_url
  • 内容：description、tags、category、language、duration、duration_seconds、thumbnail_url
  • 时间：published_at（ISO 时间戳）
  • 来源：search_query（搜索模式下）、source_url、scraped_at

主要使用场景

  • 垂类关键词调研。在 YouTube 上按观看量排序搜索 "python 教程"，看哪些标题主宰该垂类
  • 频道表现审计。抓取某创作者频道下的全部视频，对最近 100 条计算中位 engagement_rate
  • Shorts 趋势挖掘。对 50 个频道使用 shorts 模式，找到某垂类内势头上升的 Shorts 形式
  • 赞助内容识别。从标签与标题模式识别创作者目录中的品牌赞助视频
  • SEO 竞品追踪。每日快照竞品上传的 view_count，追踪排名变化与爆款时刻

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~youtube-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "channel",
    "urls": ["https://www.youtube.com/@MrBeast"],
    "maxResults": 100,
    "sortBy": "views",
    "includeDetails": true
  }'

# 或通过 MCP 与 AI 代理配合使用：
# https://mcp.apify.com?tools=santamaria-automations/youtube-scraper
