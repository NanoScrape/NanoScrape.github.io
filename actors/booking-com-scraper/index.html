What you can extract

  • Identity: hotel name, star_rating (1 to 5), photo_url, direct booking.com URL
  • Location: city, district, full location, distance_from_center
  • Reviews: review_score (out of 10), review_count, review_label (Wonderful, Very Good, etc.)
  • Pricing: price, original_price (for discount calculation), currency
  • Booking policy: free_cancellation flag, no_prepayment flag
  • Search context: destination, checkin and checkout dates, adults, rooms

Primary use cases

  • Rate parity monitoring. Compare your hotel's Booking.com price against your direct site daily
  • Hotelier pricing intelligence. Track competitor rates by star tier, neighborhood and date range
  • OTA comparison. Combine with Airbnb, Expedia or Trivago feeds for full-market visibility
  • Travel meta-search. Build your own price-comparison site or affiliate widget
  • Event-driven surge analysis. Measure how prices move around conferences, festivals or sports events
  • Honest about the approach: we hit Booking.com's GraphQL API directly. Clean data, no browser overhead

API example

# Scrape Booking.com hotel listings
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~booking-com-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "destination": "Berlin",
    "checkin": "2026-09-15",
    "checkout": "2026-09-17",
    "adults": 2,
    "currency": "EUR",
    "maxResults": 50
  }'

# Or sort by price for cheapest first:
# {"destination":"Rome","checkin":"2026-05-01","checkout":"2026-05-03","sortBy":"PRICE"}
