What You Get

  • salary_min / salary_max / salary_currency / salary_period — structured PLN salary (or B2B hourly) parsed from Pracuj's native salary display, e.g. '110-140 zl netto (+ VAT) / godz.'
  • requirements — array of mandatory and optional skills/technologies extracted from the structured job form
  • responsibilities — array of day-to-day duties extracted as clean strings, ready for NLP or model features
  • company_benefits — perks array: health insurance, sports card, remote work, pension, and more
  • work_mode / employment_type — Praca zdalna / Hybrid / Stacjonarna + Kontrakt B2B / Umowa o prace normalized
  • company_url / company_about — optional employer Pracuj.pl profile with About text and other open roles (set includeCompanyDetails: true)
  • apply_url — direct application link from the detail page
  • region / city — Polish voivodeship and city for geo-routing

Who Should Use This

Polish and Central European job aggregators need Pracuj.pl because it is Poland's largest job board by volume (80,000+ listings, 20,000+ employers) and the only source where structured requirements, responsibilities, and benefits arrive as clean arrays rather than free-form HTML. Compensation research platforms value the B2B hourly rate field, which captures the PLN contractor market that is invisible on most European job boards. Recruitment data vendors use includeCompanyDetails to pull the employer's Pracuj.pl About text and all other open roles at that company, turning a job feed into a full employer intelligence dataset. Remote work analytics teams use the remote: true filter to isolate the growing Polish remote market without any post-processing.
