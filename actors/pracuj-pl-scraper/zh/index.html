您可以抓取的内容

  • 基础信息： title、company、城市、省份 (波兰 16 个 Voivodeship)、posted_at
  • 薪资 (PLN)： salary_min、salary_max、salary_currency (PLN)、salary_period (月薪/时薪)、salary_text
  • 工作模式： Stacjonarna (现场) / Hybrydowa / Zdalna (远程)、workload_min 与 workload_max
  • 完整内容： description_full、requirements、benefits、technologies 数组
  • 公司情报： company_logo_url、company_url、company_website

主要使用场景

  • 波兰技术招聘。 在华沙、克拉科夫、弗罗茨瓦夫物色波兰开发者，按 technologies 数组过滤
  • 近岸外包线索。 跟踪正在扩张技术团队的波兰公司，作为近岸合作信号
  • PLN 薪资基准。 按省份聚合 salary_min 与 salary_max，绘制波兰各地区薪酬地图
  • 远程友好的波兰雇主。 按 work_mode = Zdalna 过滤，物色对全远程开放的波兰公司
