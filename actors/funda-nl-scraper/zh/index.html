您可以抓取的内容

  • 价格：price（EUR）、price_original（检测降价）、price_per_m2、price_currency、listing_type（koop 或 huur）
  • 户型：bedrooms、rooms、bathrooms、living_area_m2、plot_size_m2（独立屋）、year_built、property_type（公寓、独立屋、别墅、平房、停车位、土地）
  • 位置：address、street、postal_code（荷兰格式带空格，如 1015 BS）、city、neighborhood、province（Noord-Holland、Zuid-Holland 等）、latitude、longitude
  • 荷兰能源：energy_label（A+++++ 至 G，正确处理所有加号等级）、heating_type、construction_type
  • 描述：完整荷兰语 omschrijving 纯文本，通常 3,000-6,000 字符
  • 设施：标签（Balkon、Tuin、Lift、Monumentaal pand、Vrijstaand、隔热等级）
  • 媒体：property_image_url、photos（30+ 张原 CDN 分辨率）
  • 中介：agent_name（makelaar）、agent_url、agent_phone 与 agent_email（公开时）

主要使用场景

  • 荷兰市场分析。追踪每个荷兰城市的挂牌价、挂牌时长与库存趋势
  • 阿姆斯特丹/鹿特丹/乌得勒支投资研究。通过 price_per_m2 差值在高增长街区识别被低估的房源
  • 租金回报（koop vs huur）。把同一条街上的售卖和出租房源匹配，计算净资本化率
  • energielabel 感知估值。量化 A+++++ 至 G 各能源等级的价格溢价，是荷兰绿色房贷研究的关键
  • 每日价格变动追踪。每日执行，按 listing ID 与 price_original 与昨日做差，识别困境出售
  • makelaar 拓客。按挂牌量、街区占比与价格段定位荷兰中介
