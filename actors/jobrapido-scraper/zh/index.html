您可以抓取的内容

  • 50+ 国家覆盖： DE、IT、FR、ES、UK、US、BR、IN、AU 以及其他多个本地 Jobrapido 域
  • 薪资数据： salary_min、salary_max、salary_currency、salary_period、salary_text
  • 聚合器优势： source URL 解析到原始雇主招聘页或 ATS
  • 基础信息： title、company、城市、地区、country、employment_type、work_mode
  • 工时： workload_min、workload_max、posted_at、scraped_at

主要使用场景

  • 跨国市场扫描。 一次运行覆盖 50+ Jobrapido 国家域，得到全球招聘热度图
  • ATS 深链发现。 通过解析后的 source URL 识别雇主使用的 ATS (Lever、Greenhouse、Workday)
  • 意大利市场进入。 Jobrapido 诞生于意大利，IT 覆盖在所有聚合器中最强，适合意大利专项招聘
  • 数据补全。 当 Indeed、LinkedIn 等更精准抓取器遗漏某国家或地区时，使用 Jobrapido 作为兜底

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~jobrapido-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "searchQueries": ["software engineer"],
    "country": "de",
    "location": "Berlin",
    "maxResultsPerQuery": 100
  }'

# 或通过 MCP 与 AI 代理配合使用：
# https://mcp.apify.com?tools=santamaria-automations/jobrapido-scraper
