What you get

  • url: the resolved original source URL - follows the Jobrapido redirect to the real employer or job board page (xing.com, monster.de, stepstone.de, indeed.com, and hundreds more)
  • country: ISO country code - single actor covers 50+ country subdomains with one consistent output schema
  • salary_min / salary_max / salary_currency: structured salary when the originating listing publishes it
  • city / region: parsed location components extracted from the card metadata
  • description_snippet: short description teaser extracted from each result card
  • posted_at: normalized ISO-8601 posting date
  • source_platform: always "jobrapido.com" for feed attribution
  • search_query: which keyword found each job across multi-keyword deduplicated runs
