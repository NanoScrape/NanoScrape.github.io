Ce que vous pouvez extraire

  • Identité : username, display_name, profile_url (URL canonique web.snapchat.com)
  • Bloc bio : texte bio (jusqu'à 500 caractères), URL de site web extraite de la bio
  • Audience : subscriber_count (null si Snapchat le masque)
  • Confiance : indicateur is_verified (badge Official Story)
  • Médias : avatar_url (Bitmoji ou image téléversée), horodatage scraped_at

Cas d'usage principaux

  • Prospection de créateurs. Extraire l'URL du site web depuis une liste de créateurs Snapchat pour trouver landing pages et emails d'outreach
  • Rafraîchissement de base influenceurs. Re-snapshotter subscriber_count et statut vérifié pour tenir à jour les bases agence
  • Audit de comptes de marque. Récupérer display_name et bio pour votre roster de handles de marque afin de vérifier un positionnement cohérent
  • Sourcing lookalike. Croiser les handles Snapchat avec les profils TikTok et Twitter de la même personne
  • Filtre badge vérifié. Filtrer is_verified=true pour constituer une liste curated de créateurs Official Story dans une niche
