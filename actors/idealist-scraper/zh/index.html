您可以抓取的内容

  • 基础信息： title、company、城市、州、country、location_type、posted_at
  • 使命领域： areas_of_focus 标签 (教育、气候、人权、医疗可及性等)
  • 远程标记： remote_ok (true / false)、location_type
  • 完整内容： description、薪资范围、tags
  • 组织情报： company_website、company_address、company_phone、company_email、加入 Idealist 时间、组织总职位数

主要使用场景

  • 非营利人才招聘。 通过 areas_of_focus 标签 (气候、教育、医疗) 过滤，物色使命驱动的候选人
  • 基金会拨款研究。 追踪哪些非营利机构正在扩张人员，作为近期拨款信号
  • 远程影响力岗位。 按 remote_ok = true 过滤，物色对使命驱动的分布式工作开放的候选人
  • 直接对接组织。 使用 company_email 与 company_phone 与非营利领导层进行合作外联
