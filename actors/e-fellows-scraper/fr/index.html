Ce que vous pouvez extraire

  • Types de jobs : Praktikum, Traineeprogramm, Werkstudent, Einstiegsposition, Doktorand, Masterarbeit, Bachelorarbeit, Fuehrungsposition
  • Filtres : industrie/fonction (IT, Consulting, Finanzen, Recht, Ingenieurwesen), ville (Munich, Berlin, Francfort, Hambourg, Stuttgart)
  • Signaux spécifiques étudiants : required_degree (Bachelor, Master, PhD), study_field (Informatik, BWL, Maschinenbau, Jura), start_date, duration, languages
  • Salaire : extrait si publié dans le schema markup
  • Contenu du poste : work_mode (Remote / Hybrid / Onsite), description, exigences, responsabilités, company_benefits
  • Employeur : nom, URL profil, logo, industrie
  • Cycle de vie : application_deadline, posted_at, expires_at, apply_url direct vers le portail carrière employeur
