您可以抓取的内容

  • 一个 actor 支持 5 种榜单：bestsellers、movers and shakers、new releases、most wished for、most gifted
  • 排名元数据：position（1 到 100）、categoryName、categoryBreadCrumbs、listType
  • 商品数据：asin、url、title、brand、thumbnailImage、price、listPrice、stars、reviewsCount
  • 徽章：isAmazonChoice、isPrime、isBestSeller、isLimitedDeal、dealText
  • 20 个市场。US、UK、DE、FR、IT、ES、CA、MX、BR、NL、SE、PL、TR、JP、IN、AU、SG、SA、AE、EG

主要使用场景

  • 市场趋势监控。对您关注的每个类目，每日抓取前 100 名快照
  • 新品发现。什么刚刚进入您所在细分领域的畅销榜？
  • 类目排名追踪。您自己的 SKU 在所属类目中处于什么位置？
  • 竞争情报。本周您所在领域的 Movers and Shakers 是哪些商品？

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~amazon-bestsellers-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": [{"url": "https://www.amazon.com/Best-Sellers-Electronics/zgbs/electronics/"}], "maxResultsPerCategory": 100}'
