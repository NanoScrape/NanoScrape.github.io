DBA.dk Scraper: Dänemarks #1 Kleinanzeigen-Marktplatz

Scrapen Sie Kleinanzeigen von DBA.dk, Dänemarks größtem Online-Marktplatz (Schibsted-Gruppe). Liefert Titel, Preis in DKK, Stadt, GPS-Koordinaten, Marke, alle Bild-URLs, Veröffentlichungsdatum und Quell-URL aus einer einfachen Keyword-Suche oder einer kopierten dba.dk-Such-URL. Optionale Detail-Anreicherung ergänzt Zustand (Brugt, Ny, Defekt) und Kategorie. Automatische Paginierung.

Was Sie scrapen können

  • Kategorien: Autos, Elektronik, Mode, Möbel, Kinder, Tiere, Sport, Immobilien, Dienstleistungen
  • Suchmodi: Keyword (searchQuery, searchQueries) oder vollständige dba.dk-URL mit Filtern
  • SERP-Daten: Titel, Preis in DKK, Stadt/Region, GPS-Koordinaten, Marke, Bild-URLs
  • Detail-Anreicherung: Zustand (Brugt, Ny, Defekt), Kategoriepfad
  • Quell-Link: direkte URL zu jeder dba.dk-Anzeige
  • Paginierung: automatischer Lauf bis zur letzten Seite oder maxResults-Limit

Wichtige Anwendungsfälle

  • Gebrauchtelektronik-Arbitrage. iPhone-, MacBook- oder PlayStation-Anzeigen unter einer DKK-Grenze beobachten und auf dba.dk oder eBay weiterverkaufen
  • Second-Hand-Markt-Intelligenz. Durchschnittliche DKK-Preise für eine Marke oder Modell über Wochen verfolgen, um Kaufentscheidungen zu informieren
  • Händler-Konkurrenzbeobachtung. Snapshot der Anzeigen eines Mitbewerbers täglich, um Bestandsumschlag und Preisänderungen zu erkennen
  • Grenzüberschreitendes Einkaufen. Cykel- oder Møbler-Anzeigen in Kopenhagen vs Aarhus für Versandkalkulation filtern
  • Marken-Reputations-Tracking. Zählen, wie oft eine Marke in dba.dk-Anzeigen vs. Neu-Retail-Kanälen erscheint

Direkt auf Apify ausführen (kein Code)

Klicken Sie oben auf Auf Apify öffnen, um dba-dk-scraper im Browser auszuführen – kein Code, keine Installation. In der Apify-Konsole erhalten Sie:

  • Test mit einem Klick – füllen Sie das Eingabeformular aus oder fügen Sie das obige JSON-Beispiel in den JSON-Editor ein und klicken Sie auf Start.
  • Live-Ausgabe – sehen Sie zu, wie Zeilen in eine interaktive Output-Tabelle einfließen, oder wechseln Sie zur rohen JSON- / Log-Ansicht.
  • Export in jedem Format – Datensatz mit einem Klick als JSON, CSV, XML, Excel, HTML-Tabelle, RSS oder JSONL herunterladen.
  • Zeitpläne – Actor täglich, wöchentlich, stündlich oder mit benutzerdefiniertem Cron ausführen. Apify übernimmt das Timing und speichert jeden Datensatz-Lauf.
  • Integrationen & Webhooks – Webhook bei Erfolg/Fehler auslösen oder mit Zapier, n8n, Make, Airbyte, Google Sheets, Slack, S3, Postgres u.v.m. aus dem Actions-Tab verbinden.
  • Transparente Kosten – exakte Nutzung im Rahmen Ihres Gratiskontingents von 5$/Monat sehen, bevor Sie etwas ausgeben.

Ihren Apify API-Token erhalten

Um diesen Actor aus Ihrem eigenen Code auszuführen, benötigen Sie einen Apify API-Token. In etwa einer Minute erledigt:

  1. Kostenlos bei Apify registrieren (Google, GitHub oder E-Mail).
  2. Gehen Sie zu Einstellungen → Integrationen → API-Tokens.
  3. Klicken Sie auf Neuen API-Token erstellen. Kopieren und geheim halten.

Gratiskontingent: Apify schreibt Ihrem Konto 5$ Plattformnutzung pro Monat gut, keine Kreditkarte erforderlich. Genug, um jeden Actor sinnvoll zu testen — bei 0,001$ pro Ergebnis sind das etwa 5.000 Ergebnisse gratis pro Monat.
