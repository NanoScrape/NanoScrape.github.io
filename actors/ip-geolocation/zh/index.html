IP 地理定位 API：批量 IP 到国家、城市、ASN、ISP，每 1,000 IP $0.10

为任意 IPv4 或 IPv6 地址富化国家、城市、邮编、经纬度、时区、ASN、ISP、组织和代理/VPN/Tor 检测。基于 MaxMind GeoLite2。为批量而生：输入 100,000 IP，秒级返回地理富化的数据行。适用于日志分析、欺诈评分、安全审计、流量仪表盘和合规地理围栏。

您能获得什么

  • 位置：country_iso、country_name、region、city、postal_code、latitude、longitude
  • 网络：asn、asn_org、isp、connection_type、network、hostname
  • 时间：timezone、utc_offset、currency_code
  • 风险信号：is_proxy、is_vpn、is_tor、is_hosting、is_anonymous
  • 元数据：ip_version、accuracy_radius_km、scraped_at

主要使用场景

  • 日志分析。对 Web 服务器访问日志做地理富化，绘制全球流量模式
  • 欺诈评分。在注册和结账流程中标记 VPN、Tor 和主机商 IP
  • 安全审计。绘制登录失败、暴力破解尝试和 4xx 突增的来源国家
  • 合规地理围栏。验证用户符合区域许可或受制裁国家规则
  • 营销分析。按城市和 ASN 拆分流量，识别 B2B 潜在客户
