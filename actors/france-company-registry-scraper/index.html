France Company Registry Scraper

The NanoScrape France Company Registry Scraper is an Apify actor that extracts enrichment data from annuaire-entreprises.data.gouv.fr. It returns 44 fields per result including siren, url, siren_conserve, nom_complet, nom_raison_sociale, priced at $2.5/1k french company, with no API key or monthly subscription required.

Search the French business register by keyword, activity code, department, postal code and more (source platform). One row per company with SIREN, SIRET, address, activity, legal form, size band, officers and finances. Pay per company.
