可提取内容

  • 邮箱：页面找到的所有地址，同域邮箱优先列出
  • 电话号码：国际格式，来自 tel: 链接与 HTML 文本
  • 社媒：LinkedIn、Twitter/X、Facebook、Instagram 档案 URL
  • 实体地址：来自 schema.org 结构化数据（如存在）
  • 页面标题：来自 og:title 或 HTML title
  • 状态信号：HTTP 状态码、scraped_at、soft-block 标记

主要用例

  • 百万 URL CRM 扩充。一次运行即可为公司联系页列表添加邮箱与电话
  • 销售勘探。从一份目标公司页清单提取联系方式
  • 潜客列表清洗。实时检查后剔除无联系方式的 URL
  • 批量研究。对网站组合的社媒档案以小时而非天为单位完成映射
  • 冷外联准备。发送活动前先校验邮箱格式
  • 与 Website Email Scraper 的区别：每 URL 单次抓取、不爬取。若已有联系页 URL，此款最佳
