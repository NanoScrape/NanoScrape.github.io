France Travail Scraper : Service public de l'emploi de France, 22 champs

Extrayez les offres de France Travail (anciennement Pôle Emploi), le service public de l'emploi officiel de la France. Retourne 22 champs par offre : titre, entreprise, lieu, pays, employment_type, type de contrat (CDI / CDD / Interim / Stage), salary_min, salary_max, salary_text, remote_option, description complète, posted_at, expires_at, source_url, apply_url, indicateur top_listing et company_url. Couvre les 13 régions françaises (Paris, Lyon, Marseille, Toulouse, Bordeaux + DOM-TOM).

Ce que vous pouvez extraire

  • Données de base : title, company, location, country (FR + DOM-TOM), posted_at, expires_at
  • Types de contrat français : CDI (permanent), CDD (durée déterminée), Interim, Stage, Apprentissage
  • Données salariales : salary_min, salary_max, salary_text (souvent fourchette EUR/an ou EUR/mois)
  • Contenu complet : description_snippet, description_full, remote_option
  • Signaux de confiance : indicateur top_listing, job_status, source_url, apply_url

Cas d'usage principaux

  • Intelligence des recrutements en France. Récupérer chaque annonce CDI d'une région par semaine pour suivre l'activité du marché du travail français
  • Sourcing alternance. Filtrer Apprentissage et Stage pour bâtir des pipelines sur le système d'alternance français
  • Complétion par données publiques. France Travail est la source officielle ; l'utiliser pour valider les données Indeed et Welcome to the Jungle
  • Tendances CDI vs CDD. Agréger le type de contrat par région pour étudier les schémas d'emploi permanent vs temporaire
