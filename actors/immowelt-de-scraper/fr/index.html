Ce que vous pouvez extraire

  • Decomposition du loyer allemand : price, price_label, price_warm (Warmmiete), price_cold (Kaltmiete), price_raw
  • Configuration : rooms, area_sqm, plot_size (terrain pour maisons), floor, property_type (FLAT, HOUSE, ...), property_subtype
  • Localisation : address, neighborhood, city, postcode (PLZ), availability_date
  • Energie : energy_class (Energieausweis A+ a H), type de chauffage via description
  • Agent : publisher_name, publisher_type (AGENT ou PRIVATE), is_premium_partner, agent_company, agent_name, agent_phone, agent_website, agent_address, agent_profile_url, agent_imprint_url
  • Medias : image_url, image_urls (galerie complete), image_tags (scenes par photo comme "living_room" avec descriptions allemandes)
  • Indicateurs : is_new, is_exclusive, has_3d_tour, has_brokerage_fee (Provisionspflichtig), is_private_owner

Cas d'usage courants

  • Recherche Mietspiegel. Construire un Mietspiegel prive par ville et PLZ a partir des donnees live de Warmmiete et Kaltmiete
  • Benchmarking Energieausweis. Calculer le loyer median demande par classe energetique A a H et par Bundesland pour la recherche batiment vert
  • Listes provisionsfrei. Filtrer has_brokerage_fee=false pour trouver les annonces directes de proprietaires
  • Screening d'investissement Berlin / Munich / Hambourg. Comparer le prix au m2 entre quartiers et classer les Kieze sous-evalues
  • Prospection d'agents. Construire une liste CRM de chaque agence allemande active avec nom, telephone, site et mentions legales
