大规模抓取Indeed招聘信息 — 60+个国家，无需浏览器

从Indeed移动端API提取结构化职位数据。返回职位名称、公司、地点、薪资、福利、描述和申请链接。并发详情抓取，每个Worker独立代理会话。纯HTTP — 无Chrome，无Playwright。

可抓取的数据

  • 搜索结果 — 职位名称、公司、地点、薪资预览、发布日期
  • 完整职位详情 — 完整描述、福利、资质要求、雇佣类型
  • 公司信息 — 公司名称、Logo链接、评分
  • 多查询 — 单次运行中执行多个关键词搜索
  • 直接URL — 通过URL抓取指定职位详情
  • 60+个国家 — indeed.com、indeed.de、indeed.co.uk、indeed.fr等

主要使用场景

  • 就业市场研究 — 分析各地区的招聘趋势、薪资分布和技能需求
  • 潜在客户开发 — 发现正在积极招聘的公司（增长信号）
  • 竞争情报 — 监控竞争对手的招聘信息以获取战略洞察
  • HR科技 — 将职位数据导入ATS聚合器、招聘平台或匹配算法
  • 学术研究 — 使用结构化、干净的数据进行劳动力市场分析

API示例

# 通过Apify API启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~indeed-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "searchQueries": ["software engineer"],
    "country": "de",
    "maxResultsPerQuery": 50,
    "includeJobDetails": true
  }'

# 或通过MCP与AI代理配合使用：
# https://mcp.apify.com?tools=santamaria-automations/indeed-scraper

集成方式

  • n8n / Make / Zapier — 通过Webhook触发运行并处理结果
  • AI代理 (MCP) — Claude Desktop、Cursor、VS Code、LangChain、LlamaIndex
  • Python / Node.js — 使用Apify SDK进行编程访问
  • Google Sheets / Airtable — 通过Apify集成导出
