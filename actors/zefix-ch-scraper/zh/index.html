可抓取的数据

  • 公司搜索 -- 按名称、UID或关键词搜索
  • 公司详情 -- 法定名称、UID (CHE-...)、法律形式 (AG、GmbH等)
  • 地址 -- 注册办公地址和所在州
  • 经营目的 -- 登记处的官方公司经营目的
  • 状态 -- 活跃、清算中或已注销
  • 多查询 -- 单次运行中执行多个搜索

主要用例

  • 尽职调查 -- 核实瑞士公司注册信息和法律状态
  • 潜在客户开发 -- 按行业或地区构建瑞士公司列表
  • KYC / AML -- 为合规要求验证公司身份
  • 市场研究 -- 按法律形式和州分析瑞士商业格局
  • CRM数据补充 -- 为公司记录添加官方注册数据

API示例

# 通过Apify API启动一次运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~zefix-ch-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "searchQueries": ["software"],
    "canton": "ZH",
    "maxResultsPerQuery": 100
  }'
