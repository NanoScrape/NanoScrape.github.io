可抓取的数据

  • 频道消息 -- 包含格式的完整文本内容
  • 媒体 -- 照片URL、视频缩略图、文档链接
  • 浏览量 -- 每条消息的互动指标
  • 频道元数据 -- 名称、描述、订阅者数量、头像
  • 转发消息 -- 原始来源频道信息
  • 多频道 -- 单次运行抓取多个频道

主要用例

  • OSINT研究 -- 监控公开频道进行情报收集
  • 市场监控 -- 追踪加密货币、金融或特定行业频道
  • 品牌监控 -- 在公开Telegram频道中发现品牌提及
  • 内容分析 -- 分析消息模式和互动趋势
  • 归档 -- 创建公开频道内容的结构化备份

API示例

# 通过Apify API启动一次运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~telegram-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "channels": ["duaborgin", "techcrunch"],
    "maxMessages": 100
  }'

# 或通过MCP与AI代理一起使用：
# https://mcp.apify.com?tools=santamaria-automations/telegram-scraper
