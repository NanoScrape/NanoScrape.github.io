您可以抓取的内容

  • 基础信息： title、description、company_name、location、municipality、region (län)
  • 瑞典职业分类： occupation、occupation_field、experience_required
  • 工时： working_hours、scope_of_work_min、scope_of_work_max、employment_type
  • 招聘规模： number_of_vacancies (经常显示雇主一次招 5+ 人)
  • 雇主数据： company_logo、employer_name、employer_url、salary_description

主要使用场景

  • 瑞典招聘情报。 官方政府来源，通过 JobTech 免费，适合学术与政策研究
  • 批量招聘识别。 过滤 number_of_vacancies > 5 找到正在大规模扩张团队的瑞典雇主
  • 市级需求分析。 按 municipality 聚合，追踪斯德哥尔摩、哥德堡、马尔默的招聘活跃度
  • 跨北欧补全。 与 Jobindex.dk 抓取器结合，一个工作流覆盖丹麦与瑞典所有公共职位

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~arbetsformedlingen-se-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "searchQuery": "utvecklare",
    "maxResults": 100
  }'

# 或通过 MCP 与 AI 代理配合使用：
# https://mcp.apify.com?tools=santamaria-automations/arbetsformedlingen-se-scraper

集成
