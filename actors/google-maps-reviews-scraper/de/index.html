Google Maps Reviews Scraper: Bewertungen von Google-Maps-Orten

Holen Sie die Bewertungen beliebiger Google-Maps-Orte: Sternebewertung, Bewertungstext, Datum, Autor, Fotos und die Antwort des Inhabers, eine Zeile pro Bewertung. Geben Sie Orts-URLs oder Place IDs an. Kein Login, kein API-Schlüssel.

Was Sie bekommen

  • Bewertung: Bewertungs-ID, Sterne (1 bis 5), Text, Datum, Antwort des Inhabers, Foto-URLs
  • Autor: Name, Profil-Link, Zahl seiner Bewertungen, Local-Guide-Kennzeichen (wenn Google sie liefert)
  • Ort: Place ID, Data ID, Name, URL, Adresse, Gesamtbewertung und Zahl der Bewertungen in jeder Zeile
  • Metadaten: Zeitpunkt des Abrufs; Zeilen ohne Bewertungs-ID werden über ihren Inhalt dedupliziert

Typische Anwendungsfälle

  • Reputations-Monitoring: per Zeitplan nur neue Bewertungen seit einem Startdatum abrufen
  • Wettbewerbsanalyse: Bewertungen mehrerer Standorte oder Mitbewerber vergleichen
  • Sentiment-Analyse: Bewertungstexte für Auswertungen oder KI-Modelle sammeln
  • Lead-Generierung: Betriebe mit schwachen Bewertungen oder ohne Antworten finden

Eingabe

In startUrls geben Sie Google-Maps-Orts-URLs an (die vollständige URL eines Ortes mit !1s0x...:0x..., einen ?ftid=-Link, einen ?q=place_id:-Link oder einen maps.app.goo.gl-Kurzlink), in placeIds Place IDs oder Data IDs, oder beides. Suchergebnis-URLs und Links nur mit CID werden nicht unterstützt. maxReviewsPerPlace (Standard 100, bis 5.000) begrenzt die Bewertungen pro Ort, reviewsSort wählt newest (Standard), relevant, highest oder lowest, und reviewsStartDate (JJJJ-MM-TT) überspringt ältere Bewertungen und beendet das Blättern früh. language (Standard en) setzt die Sprache für Google. Doppelt angegebene Orte werden einmal gelesen.

Beispiel-Eingabe

{
  "startUrls": [
    {
      "url": "https://www.google.com/maps/place/?q=place_id:ChIJOUaXTwcKkEcRoKwC-x6RFew"
    }
  ],
  "placeIds": [
    "0x47900a074f974639:0xec15911efb02aca0"
  ],
  "maxReviewsPerPlace": 500,
  "reviewsSort": "newest",
  "reviewsStartDate": "2026-01-01",
  "language": "en"
}
