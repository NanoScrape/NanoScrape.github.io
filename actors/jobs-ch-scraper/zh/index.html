可抓取的数据

  • 搜索结果 — 职位名称、公司、地点、薪资预览、发布日期，覆盖所有瑞士州
  • 完整职位详情 — 完整描述、要求、福利、雇佣类型、工作模式
  • 公司数据 — 公司名称、Logo链接、行业分类、公司规模
  • 多查询 — 单次运行中执行多个关键词搜索并自动去重
  • 薪资信息 — 可用时提取薪资范围
  • 全语种支持 — 德语、法语、意大利语和英语职位

主要使用场景

  • 瑞士劳动市场分析 — 跟踪各州的招聘趋势、薪资基准和技能需求
  • 招聘情报 — 监控竞争对手招聘活动，识别人才获取模式
  • 招聘平台聚合 — 将瑞士职位数据导入自有平台或聚合服务
  • 经济研究 — 分析瑞士多语言地区的就业模式
  • 销售线索挖掘 — 通过招聘量和职位类型识别快速增长的瑞士公司

API示例

# 通过Apify API启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~jobs-ch-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "searchQueries": ["software engineer"],
    "maxResultsPerQuery": 50,
    "includeJobDetails": true
  }'
