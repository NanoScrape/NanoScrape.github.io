您可以抓取的内容

  • 广告标识：ad_archive_id、ad_id、collation_id、collation_count（同 A/B 测试组下的变体数）、publisher_platform、display_format、is_active
  • 创意：body_text、title、link_url、link_description、cta_text、cta_type、ad_caption、所有图片、所有视频（带水印）、轮播卡片
  • 主页画像：page_name、page_id、page_like_count、page_profile_picture_url、page_categories、品牌内容标记
  • 透明度 (AAA)：payer_beneficiary_data、欧盟目标、location / age / gender 受众、欧盟覆盖、country-age-gender 分布
  • 花费：total_advertiser_spend_lower / upper / currency（累计）、政治广告花费与覆盖区间
  • 时间：start_date、end_date、total_active_time、start_date_formatted (YYYY-MM-DD)
  • 合规标记：contains_digital_created_media、contains_sensitive_content、is_violating_eu_siep、violation_types

主要使用场景

  • 竞品广告审计。跨 7+ 个国家拉取某竞品 Page 的全部在投广告，绘制其漏斗钩子与创意主题
  • 创意灵感库。在某垂类按 total_impressions DESC 排序，找到最高花费的广告作为参考样本
  • 政治广告透明度。拉取某地区 issue 广告的 AAA 数据，呈现付款方 / 受益方链条，供新闻或研究使用
  • 广告主追踪。每日快照某竞品 Page 的 total_advertiser_spend，估算其月度 Meta 预算
  • 欧盟年龄 / 性别定向分析。利用 country-age-gender 分布反向推断竞品的受众定向
