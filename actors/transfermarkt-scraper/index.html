Input

Put list addresses in startUrls: the most valuable players list, a competition list such as https://www.transfermarkt.com/premier-league/marktwerte/wettbewerb/GB1 or a club squad such as https://www.transfermarkt.com/fc-barcelona/kader/verein/131. Other addresses are refused with a message. maxResults (default 100) caps the players across all lists. The most valuable players address also accepts the site filters (for example ?ausrichtung=Mittelfeld) and ?plus=1, which adds statistic columns returned in other_columns. A club squad is read in the detailed view with birth date, height, foot and contract columns; add /saison_id/2025 for an earlier season. An empty input reads the most valuable players list.

Input example — one competition list

{
  "startUrls": [

  ],
  "maxResults": 100
}

Cost math

Priced at $0.00125 per player saved to the dataset ($1.25 per 1,000): 100 players ≈ $0.125, 1,000 players ≈ $1.25. A player found on two lists is charged once, and an interrupted run continues without charging players twice. The run ends cleanly at your maximum total charge. No monthly subscription, you pay only for what you extract.

FAQ

How much does the transfermarkt-scraper cost?

Priced at $0.00125 per player saved to the dataset ($1.25 per 1,000). A player found on two lists is returned and charged once. No monthly subscription, you only pay for what you extract.

What fields does it return?

28 fields per player: ID, name, profile link, portrait, position, age, nationalities, club with ID and link, market value as a number with currency and the text as shown, rank, and on club squads birth date, shirt number, height, foot, signing details and contract end.

Which pages can it read?

Only three kinds of list: the most valuable players list, competition lists (/marktwerte/wettbewerb/) and club squads (/kader/verein/). Search pages, player profile pages, transfer lists and match data are not read.

Is the market value a number?

Yes. market_value is a number, market_value_currency the currency (euros on transfermarkt.com) and market_value_text keeps the text as the site shows it. Market values are the site's estimates, not transaction prices.

How many players can I get from one list?

The site lists at most 20 pages (500 players) per list, 25 per page. A club squad returns the whole squad, about 25 to 35 players. Use filters, competitions or club squads to reach other players.

Does it return market value history or career statistics?

No. The list shows the current market value only, and player profile pages are not opened. The ?plus=1 option adds list statistic columns such as matches, goals and assists in other_columns.

Do I need an API key from the source platform?

No. No Transfermarkt account and no API key. Give the actor list addresses and it does the rest.
