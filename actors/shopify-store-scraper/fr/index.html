Scraper Shopify — Produits, prix et inventaire

Extrayez des catalogues produits complets de n'importe quelle boutique Shopify. Retourne titres, descriptions, prix, variantes, statut d'inventaire, images et collections. Utilise les endpoints JSON publics de Shopify. HTTP-only — sans Chrome, sans Playwright.

Ce que vous pouvez extraire

  • Catalogue produits — titre, description, type de produit, marque, tags
  • Tarification — prix actuel, prix de comparaison, devise
  • Variantes — toutes les variantes taille/couleur/style avec tarification individuelle
  • Inventaire — statut de disponibilité par variante
  • Images — toutes les URLs d'images produits en plusieurs tailles
  • Collections — catégories de produits et appartenance aux collections

Cas d'utilisation

  • Surveillance des prix — suivez les prix concurrents sur les boutiques Shopify
  • Étude de marché — analysez les catalogues produits et stratégies de prix
  • Recherche dropshipping — trouvez les produits tendance et les prix fournisseurs
  • Intelligence concurrentielle — surveillez l'inventaire et les lancements produits concurrents
  • Enrichissement de données — ajoutez des données produits à votre pipeline analytique e-commerce

Exemple API

# Lancer une exécution via l'API Apify
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~shopify-store-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "storeUrls": [
      "https://allbirds.com",
      "https://gymshark.com"
    ],
    "maxProducts": 100
  }'

# Ou utiliser avec des agents IA via MCP :
