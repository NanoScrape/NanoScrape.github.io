抓取Shopify商店 -- 产品、价格与库存

从任何Shopify商店提取完整产品目录。返回产品名称、描述、价格、变体、库存状态、图片和系列。使用Shopify的公开JSON端点。纯HTTP -- 无需Chrome，无需Playwright。

可抓取的数据

  • 产品目录 -- 名称、描述、产品类型、品牌、标签
  • 定价 -- 当前价格、对比价格、货币
  • 变体 -- 所有尺寸/颜色/款式变体及单独定价
  • 库存 -- 每个变体的可用状态
  • 图片 -- 多种尺寸的所有产品图片URL
  • 系列 -- 产品分类和系列归属

主要用例

  • 价格监控 -- 跨Shopify商店追踪竞争对手定价
  • 市场研究 -- 分析产品目录和定价策略
  • 代发货研究 -- 发现热门产品和供应商定价
  • 竞争情报 -- 监控竞争对手库存和新产品发布
  • 数据补充 -- 将产品数据添加到电商分析管道

API示例

# 通过Apify API启动一次运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~shopify-store-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "storeUrls": [
      "https://allbirds.com",
      "https://gymshark.com"
    ],
    "maxProducts": 100
  }'

# 或通过MCP与AI代理一起使用：
# https://mcp.apify.com?tools=santamaria-automations/shopify-store-scraper

集成

  • n8n / Make / Zapier -- 触发运行并通过Webhook处理结果
