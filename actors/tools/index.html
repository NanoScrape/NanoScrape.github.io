Frequently asked

How many web tools does NanoScrape publish?

18 actors as of the latest daily sync. New actors are added continuously and old ones deprecated in place; the full list on this page is regenerated from the live Apify inventory every night.

How much do the web tools cost?

Every actor is priced pay-per-result on Apify — most range from $0.001 to $0.02 per result depending on whether detail-page enrichment is included. Apify's $5/month free tier covers roughly the first 100k SERP results across NanoScrape actors.

Do I need an API key from the source site to use these web tools?

No. Every NanoScrape actor reads public web pages over HTTP with datacenter proxies. No API key, no OAuth, no rate-limit management on your side. You only need an Apify token to trigger the actor and receive the dataset.
