What You Get

  • ats_platform: Auto-detected ATS platform name (lever, greenhouse, workday, etc.) -- paste any career URL and the actor identifies the system automatically
  • title / company / department: Normalised across all 25 platforms with consistent field names regardless of which ATS the employer uses
  • employment_type / remote: Structured employment type and remote flag -- available on 12+ platforms including Lever, Ashby, SmartRecruiters, Recruitee, and Rippling
  • apply_url / job_url: Direct application and listing URLs -- ready to embed in job boards or CRM pipelines without extra fetches
  • created_at / updated_at: Posting and modification timestamps from the ATS APIs -- enables freshness-aware deduplication across your pipeline
  • description: Full HTML job description toggled with includeDescription -- off by default to keep payloads lean, but available on 10+ platforms

To run this actor from your own code you need an Apify API token. Get one in about a minute:

  3. Click Create a new API token. Copy it and keep it secret.
