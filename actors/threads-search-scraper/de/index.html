Threads Search Scraper: Keyword + Profil-Posts, $0,50 pro 1.000 Posts

Threads.net per Keyword durchsuchen oder die aktuellen Posts jedes öffentlichen Profils scrapen. Jeder Post enthält Text, Autor-Benutzernamen, Verifiziert-Badge, like_count, reply_count, repost_count, quote_count, posted_at-Zeitstempel, has_media-Flag und direkten Post-URL. Mischen Sie Keywords und Profil-URLs im selben Lauf, Ergebnisse werden über alle Inputs hinweg dedupliziert. Kein Login erforderlich.

Was Sie scrapen können

  • Post-Identität: post_id, post_url, author_username, author_name, author_verified
  • Inhalt: text (bis 2.000 Zeichen), has_media-Flag, posted_at-Zeitstempel
  • Engagement: like_count, reply_count, repost_count, quote_count
  • Herkunft: search_query (welches Keyword diesen Post lieferte), source_platform, scraped_at
  • Input-Flexibilität: searchQueries und profileUrls im selben Lauf mischen, mit Auto-Deduplikation

Wichtige Anwendungsfälle

  • Trend-Monitoring auf Threads. Keywords wie "AI art" oder "iOS 18" stündlich pollen, um Narrativ-Shifts auf Threads gegenüber anderen Plattformen zu verfolgen
  • Brand-Mention-Surveillance. Markenname und Konkurrenznamen suchen, Ergebnisse per Webhook an Slack routen
  • Verifizierte-Creator-Discovery. Nach author_verified filtern, um Blue-Check-Creator in Ihrer Nische zu finden
  • Engagement-Benchmarking. like_count- und reply_count-Verteilungen über Keywords oder Accounts vergleichen
  • Plattformübergreifender Content-Audit. Mit dem Twitter-Scraper koppeln, um zu sehen, wie derselbe Autor auf X gegenüber Threads performt

API-Beispiel

# Einen Lauf über die Apify-API starten
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~threads-search-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "searchQueries": ["AI art", "travel photography"],
    "profileUrls": ["https://www.threads.net/@zuck"],
    "maxPostsPerQuery": 50,
    "maxResults": 0
  }'

# Oder mit KI-Agenten via MCP verwenden:
# https://mcp.apify.com?tools=santamaria-automations/threads-search-scraper
