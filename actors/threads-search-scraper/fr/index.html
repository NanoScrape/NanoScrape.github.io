Threads Search Scraper : mots-clés + posts de profil, 0,50$ pour 1 000 posts

Recherchez Threads.net par mot-clé ou extrayez les posts récents de tout profil public. Chaque post inclut le texte, le nom d'utilisateur de l'auteur, le badge vérifié, like_count, reply_count, repost_count, quote_count, horodatage posted_at, indicateur has_media et URL directe du post. Mélangez mots-clés et URLs de profil dans la même exécution, avec déduplication des résultats sur toutes les entrées. Sans connexion.

Ce que vous pouvez extraire

  • Identité du post : post_id, post_url, author_username, author_name, author_verified
  • Contenu : text (jusqu'à 2 000 caractères), indicateur has_media, horodatage posted_at
  • Engagement : like_count, reply_count, repost_count, quote_count
  • Provenance : search_query (le mot-clé qui a produit ce post), source_platform, scraped_at
  • Souplesse d'entrée : mélanger searchQueries et profileUrls dans la même exécution, avec déduplication automatique

Cas d'usage principaux

  • Veille de tendances sur Threads. Sonder des mots-clés comme "AI art" ou "iOS 18" toutes les heures pour suivre les bascules de narration sur Threads vs autres plateformes
  • Surveillance de mentions de marque. Rechercher le nom de votre marque et de vos concurrents, router les résultats vers Slack via webhook
  • Découverte de créateurs vérifiés. Filtrer par author_verified pour trouver les créateurs blue-check qui postent dans votre niche
  • Benchmarking d'engagement. Comparer les distributions de like_count et reply_count entre mots-clés ou comptes
  • Audit de contenu multi-plateformes. Coupler avec le scraper Twitter pour voir comment le même auteur performe sur X vs Threads
