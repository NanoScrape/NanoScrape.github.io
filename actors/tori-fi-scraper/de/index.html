Tori.fi Scraper: Finnlands #1 Kleinanzeigen (Schibsted-Gruppe)

Scrapen Sie Kleinanzeigen von tori.fi, Finnlands größtem Online-Marktplatz (Schibsted-Gruppe). Liefert Titel, Preis in EUR, Standort (Stadt, Gebiet oder Region), Marke, Zustand, Verkäufername, alle Bild-URLs, Datum und Quell-URL. Per Keyword suchen (polkupyora, iPhone, MacBook), mehrere Keyword-Queries parallel ausführen und optional mit vollständigen Detail-Seiten-Daten anreichern. Paginierung erfolgt automatisch.

Was Sie scrapen können

  • Vertikale: allgemeine Verkäufe, Elektronik, Fahrzeuge, Mode, Haus und Garten, Sport
  • Suche: beliebiges Keyword auf Finnisch oder Englisch, optional Multi-Query in einem Lauf
  • SERP-Daten: Titel, EUR-Preis, Standort, Marke, alle Bilder, Datum
  • Detail-Anreicherung: Zustand, Verkäufername, vollständige Beschreibung von der Listing-Seite
  • Multi-Search: mehrere Queries gleichzeitig mit Pro-Query-Ergebnislimits
  • Quell-Link: direkte URL zu jeder tori.fi-Anzeige

Wichtige Anwendungsfälle

  • Gebraucht-Fahrrad (polkupyora) Arbitrage. Fahrrad-Anzeigen in Helsinki, Tampere oder Turku unter einer Preisgrenze beobachten und in Minuten auf frische Inventur reagieren
  • Second-Hand-Preisanalyse. Durchschnittliche EUR-Preise für iPhones, MacBooks oder Winterausrüstung im finnischen Markt verfolgen
  • Nordischer Preisvergleich. Tori.fi-Preise mit Blocket.se (Schweden), Finn.no (Norwegen), DBA.dk (Dänemark) für dieselbe Marke vergleichen
  • Händler-Konkurrenzbeobachtung. Snapshot eines Power-Sellers täglich, um Preisänderungen zu erkennen
  • Marken-Reputations-Tracking. Zählen, wie oft eine Marke in Kleinanzeigen vs. Neu-Retail-Kanälen erscheint

# Einen Lauf über die Apify-API starten

  -H "Content-Type: application/json" \
  -d '{
    "searchQueries": ["polkupyora", "iphone", "macbook"],
    "maxResults": 200,
    "maxResultsPerQuery": 80,
    "includeDetails": true
  }'
