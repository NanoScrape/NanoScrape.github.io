可抓取的数据

  • 热门资讯 -- 标题、URL、评分、作者、评论数
  • 招聘信息 -- 来自每月"Who is Hiring"帖子的YC创业公司招聘
  • 评论 -- 包含嵌套和作者信息的完整评论线程
  • 用户资料 -- karma值、注册日期、简介
  • Ask HN / Show HN -- 社区提问和项目展示
  • 搜索 -- 跨所有HN内容的全文搜索

主要用例

  • 技术趋势监控 -- 追踪技术社区正在讨论的话题
  • 创业公司招聘数据 -- 抓取YC创业公司招聘信息进行市场情报分析
  • 情绪分析 -- 分析社区对产品发布或技术新闻的反应
  • 内容研究 -- 发现技术博客的热门内容主题
  • 竞争情报 -- 监控您的公司或竞争对手的提及

API示例

# 通过Apify API启动一次运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~ycombinator-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "top",
    "maxResults": 100,
    "includeComments": true
  }'
