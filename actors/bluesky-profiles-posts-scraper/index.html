Cost math

Priced at $0.001 per post or profile row ($1.00 per 1,000). A run that finds nothing is not charged, and the profile details option has no extra charge. The first runs land inside Apify's $5/mo free-tier credit — pay only for what you extract, no monthly subscription.

Input

searchTerms finds profiles by keyword, one search per term, and returns profile rows; maxProfiles (default 100, up to 50000) is split evenly across the terms. handles names the profiles whose posts you want, as name.bsky.social, @name.bsky.social, a did:plc:… id or a bsky.app profile link, and returns post rows; maxPostsPerProfile (default 50, up to 5000) caps each profile. postFilter is posts_no_replies (default), posts_with_replies, posts_and_author_threads, posts_with_media or posts_with_video. includeProfileDetails (default on) adds counts, banner and pinned post to profile rows at no extra charge, and includeReposts (default on) keeps reposts, marked with isRepost. You can combine search terms and handles in one run; an empty input runs a small sample. There is no keyword search for posts: find profiles by keyword, then collect their posts by handle.
