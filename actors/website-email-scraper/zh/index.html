网站邮箱抓取器：多页邮箱、电话、社媒提取

从任意网站提取邮箱、电话号码、社交媒体 URL 与实体地址。对每个输入 URL，抓取器访问主页、发现所有内部链接、优先访问联系、法律声明与关于页，按站爬取多个页面，并将全部信息去重为一条干净记录。无需 API key、无需登录。

可提取内容

  • 邮箱：所有爬取页面中找到的邮箱地址，去重
  • 电话号码：国际格式，从 tel: 链接与文本中提取
  • 社媒 URL：LinkedIn、Facebook、Instagram、Twitter/X、YouTube、TikTok
  • 实体地址：来自 schema.org 结构化数据（如存在）
  • 联系页 URL：爬取过程中发现的最深联系页
  • 爬取元数据：pages_crawled 计数与域名

主要用例

  • 列表扩充。输入公司域名列表，按公司输出邮箱和电话
  • CRM 卫生。重新爬取客户或潜在客户站点以捕获联系方式更新
  • 大规模潜客扩充。百万 URL 列表，$1/1000 页
  • 销售勘探。与我们的目录抓取器结合，为外联收集联系方式
  • 列表清洗。多页爬取后剔除无联系方式的条目
  • 合规审计。验证每个站点都有可达的联系页

API 示例

# Crawl websites for email, phone and social
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~website-email-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://www.example-company.ch",
      "https://www.another-business.de"
    ],
    "maxPagesPerSite": 10
  }'
