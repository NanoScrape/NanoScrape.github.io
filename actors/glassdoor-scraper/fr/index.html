Glassdoor Scraper : avis, emplois, salaires, entretiens

Extraire les données employeur depuis Glassdoor, la plus grande plateforme d'avis employeurs au monde avec une portée globale aux États-Unis, en Europe et au-delà. Nous extrayons uniquement les pages Glassdoor publiquement visibles, sans contournement de connexion.

Ce que vous pouvez extraire

  • Avis : review_title, rating, pros, cons, job_title, employment_status, review_date, recommend, ceo_approval
  • Emplois : title, location, salary_estimate, description, posted_date
  • Salaires : job_title, base_pay, total_pay, count
  • Entretiens : questions, difficulté, résultat, processus
  • Vue d'ensemble : rating, taille, secteur, CEO, headquarters, année de création
  • Avantages : nom de l'avantage, note, description

Principaux cas d'usage

  • Benchmark RH. Suivre la rémunération concurrente, les notes et l'approbation CEO dans le temps pour orienter la stratégie de rétention
  • Intelligence concurrentielle. Cartographier les postes ouverts, les salaires et le sentiment des avis par concurrent et par marché
  • Due diligence M&A. Tirer le sentiment employé agrégé, les signaux de leadership et les fourchettes salariales sur les cibles
  • Sourcing talent. Trouver les entreprises qui recrutent pour un poste précis dans une ville précise, avec estimations salariales intégrées
  • Recherche investisseur. Utiliser la dérive du volume d'avis et l'approbation CEO comme signaux proxy de santé organisationnelle

Notes et limites

  • Données publiques uniquement. Glassdoor a des clauses anti-scraping dans ses CGU. Nous extrayons uniquement les pages publiquement visibles d'avis, emplois et salaires, sans contournement de connexion, sans accès aux données privées
  • Proxy résidentiel recommandé. Glassdoor limite agressivement les IP datacenter. L'actor utilise par défaut Apify Résidentiel avec correspondance pays
  • Le format URL compte. Chaque mode nécessite le modèle d'URL Glassdoor correspondant (Reviews-E{id}, Jobs-E{id}, Salary-E{id}, Interview-Questions-E{id}, EI_IE{id})
