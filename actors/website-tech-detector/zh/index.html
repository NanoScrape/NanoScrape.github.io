您能获得什么

  • 类目：CMS、电商、JavaScript 框架、分析、广告网络、CDN、托管
  • 每项技术：name、category、version、confidence、official_url、icon_url

主要使用场景

  • 销售勘探。找出每一个使用 Shopify、HubSpot 或 Salesforce 的站点用于外联活动
  • 竞争情报。跟踪竞争对手随时间部署的 CMS、分析和广告技术
  • 供应链审计。识别供应商站点上的第三方依赖（CDN、跟踪器、支付网关）
  • ABM 定位。将账户加入外联列表前按技术栈适配度评分
  • 迁移规划。盘点已收购或受审域名组合上的当前技术

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~website-tech-detector/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://shopify.com",
      "https://stripe.com",
      "https://hubspot.com",
      "https://example-store.com",
      "https://corp-site.com"
    ]
  }'
