Teaching Vacancies GOV UK Scraper (DfE)

Extract UK teaching jobs from teaching-vacancies.service.gov.uk, the official DfE board for state schools and academies. Returns title, school, trust, local authority, phase, key stage, subject, salary scale, ECT suitability, closing date and apply URL. Pay-per-result.

What You Can Scrape

  • Official DfE source: every vacancy is verified, published by the school or MAT that hosts it
  • Phase filter: nursery, primary, secondary, 16-19, all-through, and special schools
  • ECT suitability flag: filter directly for roles suitable for Early Career Teachers
  • No login, no captcha: the DfE service is fully public
  • 4-format description: plain text, multi-line, raw HTML, and Markdown
  • Contact extraction: emails and phones parsed from description body (~50-70% fill rate)

What you get

  • title + school_name + trust_name — role title, school name, and MAT when linked
  • phase + key_stage + subject — curriculum level and subject specialism
  • pay_scale + pay_text + pay_min_pence — UK pay scale codes (MPS, UPS, L18-L24) and pence amounts
  • ect_suitable — boolean for Early Career Teacher eligibility
  • closing_at + start_date — ISO deadline and intended start
  • contact_emails + contact_phones — arrays extracted from description text
  • company_website — school's own website when published
  • company_active_jobs — snapshot of other open roles at the same school
