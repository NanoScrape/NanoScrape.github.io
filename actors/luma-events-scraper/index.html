Luma Events Scraper: Public Events by City

The NanoScrape Luma Events Scraper is an Apify actor that extracts the public event lists of Luma city pages. It returns 52 fields per event including title, start and end time, venue and coordinates, organizer calendar, hosts, guest count, ticket price and spots left, priced at $2.50 per 1,000 events, with no API key or monthly subscription required.

Read the public event lists of Luma cities such as San Francisco, London or Berlin and get one record per event: title, start and end time with time zone, venue and address when the host shows them, organizer calendar, public hosts, guest count and ticket details (source platform). Filter by keyword or free events. Pay per result.

Input

Put city names in cities as written in the Luma address (sf, london, berlin, new-york) or as city addresses such as https://luma.com/london. keyword keeps events whose title, calendar, host or venue contains the word, freeOnly keeps free events. maxResults (default 100) is shared across all cities and cities are read in the order given, so with a low limit the first city can fill the whole run. An event found in two cities is returned once. An empty input reads San Francisco.

Input example — free events in Berlin with a keyword

{
  "cities": [
    "berlin"
  ],
  "keyword": "startup",
  "freeOnly": true,
  "maxResults": 50
}

Cost math

Priced at $0.0025 per event saved to the dataset ($2.50 per 1,000): 100 events ≈ $0.25, 1,000 events ≈ $2.50. An event found in two cities is charged once, and an interrupted run continues without charging events twice. The run ends cleanly at your maximum total charge. No monthly subscription, you pay only for what you extract.

FAQ

How much does the luma-events-scraper cost?

Priced at $0.0025 per event saved to the dataset ($2.50 per 1,000). An event that appears in two cities is returned and charged once. No monthly subscription, you only pay for what you extract.

What fields does it return?

52 fields per event: ID, title and link, start and end time with time zone, in-person or online, venue, address, city and coordinates, organizer calendar, public hosts, guest count, ticket price and currency, free or paid, sold-out and spots-left flags, and where the event was found.

How do I find the city name?

Open the city on luma.com and copy the last part of the address, for example london from luma.com/london. You can also paste the full city address.

Are guest names or e-mail addresses included?

No. Guest lists and attendee data are never collected, you get the guest count only. Hosts are the public hosts that Luma shows on the event.

Why are the venue name and address sometimes empty?

Some hosts show the venue only to registered guests. Then the venue name and street address stay empty and you still get the city, the area and an approximate point.

Does it return the long description or the agenda?

No. Only the public event list of a city is read. Event pages are not opened, so the long description, the agenda, tags and the full ticket list are not collected.

Do I need an API key from the source platform?

No. No Luma account and no API key. Give the actor city names and it does the rest.
