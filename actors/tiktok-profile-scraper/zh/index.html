TikTok 个人主页抓取器：18 个字段，无需登录，每 1,000 个主页 $1

通过用户名或 URL 抓取任意公开 TikTok 个人主页。每个主页返回 18 个字段：稳定的 user_id、bio、bio 中的链接、粉丝数、关注数、视频数、点赞数、认证徽章、TikTok Shop 卖家标记及类目、账号创建日期、语言以及高清头像 URL。基于 TikTok 公开 SSR HTML 构建，因此在 API 签名轮换周期（X-Bogus / X-Gnarly）每隔几个月让其他 TikTok 抓取器下线时仍能持续运行。

您可以抓取的内容

  • 身份信息：username、user_id（用户名变更后保持稳定）、sec_uid、display_name、profile_url
  • 简介与链接：bio、bio_link（Linktree、YouTube、商店）、language
  • 受众规模：follower_count、following_count、like_count、video_count
  • 信任信号：verified 徽章、is_private 标记、account_created_at 时间戳
  • 电商：is_seller 标记、commerce_category（TikTok Shop 商业类目）
  • 媒体：avatar_url（签名高清，约 1080x1080）、scraped_at 时间戳

主要使用场景

  • 创作者触达。从 TikTok 账号列表提取 bio_link，找到 Linktree、YouTube 和商店 URL 用于冷启动外联
  • 网红数据库建设。快照 follower_count、video_count 和 verified 状态，在合作洽谈前评估某垂类
  • TikTok Shop 卖家发现。按 is_seller 和 commerce_category 筛选，绘制某垂类全部活跃卖家
  • 粉丝增长追踪。每日重新抓取，并对 follower_count 和 like_count 做时间序列分析
  • 账号年龄信任评分。使用 account_created_at 识别新注册的仿冒账号或低质量机器人
