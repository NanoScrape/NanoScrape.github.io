域名 WHOIS 与 DNS 查询：批量域名情报，每 1,000 域名 $1

为任意域名富化 WHOIS 记录、完整 DNS 和邮箱送达性态势。返回注册商、注册组织、注册日期、到期日期、名称服务器，A / AAAA / MX / TXT / NS / CNAME 记录，SPF / DMARC / DKIM 状态，以及推断的邮箱提供商（Google Workspace、Microsoft 365、Zoho、自建）。为批量而生：输入 10,000 域名，每域名一行返回。适用于 B2B 勘探、安全审计、并购研究和邮件送达性清理。

您能获得什么

  • WHOIS：registrar、registrant_org、creation_date、expiry_date、updated_at、registrant_country、status_codes[]
  • DNS A/AAAA：ipv4_addresses[]、ipv6_addresses[]、cname_target
  • 邮件记录：mx_records[]、primary_mx、email_provider（Google、Microsoft 365、Zoho）
  • 安全记录：spf_record、has_spf、dmarc_record、dmarc_policy、dkim_selectors[]
  • 其他 DNS：ns_records[]、txt_records[]、soa_record、has_dnssec

主要使用场景

  • B2B 勘探。用邮箱提供商、注册商年龄和母公司富化 5 万潜客
  • 安全审计。在组合中识别 SPF / DMARC 弱或缺失的域名
  • 并购研究。盘点目标公司完整域名资产，含别名和 ccTLD
  • 邮件送达性清理。在外联活动前验证发件域名具备 SPF + DMARC + DKIM
  • 品牌监控。追踪仿冒域名注册及其托管基础设施
