Ce que vous obtenez

  • WHOIS : registrar, registrant_org, creation_date, expiry_date, updated_at, registrant_country, status_codes[]
  • DNS A/AAAA : ipv4_addresses[], ipv6_addresses[], cname_target
  • Enregistrements mail : mx_records[], primary_mx, email_provider (Google, Microsoft 365, Zoho)
  • Enregistrements sécurité : spf_record, has_spf, dmarc_record, dmarc_policy, dkim_selectors[]
  • Autres DNS : ns_records[], txt_records[], soa_record, has_dnssec

Cas d'usage principaux

  • Prospection B2B. Enrichir 50 000 leads avec fournisseur email, ancienneté du registrar et organisation mère
  • Audits de sécurité. Identifier les domaines avec SPF / DMARC faibles ou absents sur un portefeuille
  • Recherche M&A. Inventorier le patrimoine de domaines complet d'une cible incluant alias et ccTLDs
  • Nettoyage de délivrabilité email. Vérifier que les domaines expéditeurs ont SPF + DMARC + DKIM avant campagnes outbound
  • Surveillance de marque. Suivre les enregistrements de domaines sosies et leur infrastructure d'hébergement
