您可以抓取的内容

  • 职位详情：标题、id、完整描述（文本 + HTML）、类目、employment_type、发布日期、申请 URL
  • 薪资情报：salary_min、salary_max、salary_currency、salary_text
  • 地理：countries（来自列表徽章）、region（Anywhere、US Only、Europe）
  • 公司信息：公司名称、logo、WeWorkRemotely 上的公司主页 URL
  • 雇主增强：company_hq_location、company_website、total_jobs_posted
  • 元数据：来源 URL、搜索查询、scraped_at 时间戳

主要使用场景

  • 远程人才寻源。按全职 vs 合同过滤，将结构化记录推入 ATS
  • 按地区做薪资基准。结合 salary_min、salary_max 与 countries，按市场绘制薪酬区间
  • 远程友好公司清单建设。用 company_hq_location 与 total_jobs_posted 识别长期招聘远程岗位的公司
  • 垂类回填。将 description_html 导入垂类招聘板，按 Programming 或 Design 过滤
