What you get

  • Core SEO: title, meta_description, canonical_url, robots_meta, viewport, language
  • Open Graph: og_title, og_description, og_image, og_type, og_url, og_site_name
  • Twitter Cards: twitter_card, twitter_title, twitter_description, twitter_image
  • Structured data: all Schema.org JSON-LD blocks parsed and typed
  • Page structure: headings (H1-H6), word_count, image_count, link_count, alt_coverage
  • Scoring: seo_score (0-100), warnings[] (missing canonical, duplicate H1, etc.)

Primary use cases

  • SEO audits. Scan every URL on a site for missing titles, descriptions, canonicals, and OG tags
  • Content QA. Verify newly published articles include all required structured data and headings
  • Structured-data validation. Bulk-validate Schema.org Product, Article, FAQ, and Recipe markup
  • Competitive analysis. Compare title and description patterns across a competitor's top-ranked pages
  • Migration QA. Confirm canonicals, hreflang, and OG tags survived a site relaunch
