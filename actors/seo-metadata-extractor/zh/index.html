SEO 元数据提取器：一次调用完成批量 SEO 审计，每 1,000 URL $1

通过一次调用从任意 URL 提取每一个页面 SEO 信号。返回 title、meta description、canonical URL、hreflang 替代、robots 指令、Open Graph 标签、Twitter Cards、所有 Schema.org JSON-LD 块、H1-H6 大纲、内外链计数、带 alt 覆盖率的图片计数，以及 0-100 SEO 评分。为批量而生：输入 10,000 URL，每页一行返回。适用于 SEO 审计、内容 QA、结构化数据验证和竞争分析。

您能获得什么

  • 核心 SEO：title、meta_description、canonical_url、robots_meta、viewport、language
  • Open Graph：og_title、og_description、og_image、og_type、og_url、og_site_name
  • Twitter Cards：twitter_card、twitter_title、twitter_description、twitter_image
  • 结构化数据：所有 Schema.org JSON-LD 块已解析并分类
  • 页面结构：headings（H1-H6）、word_count、image_count、link_count、alt_coverage
  • 评分：seo_score（0-100）、warnings[]（缺失 canonical、重复 H1 等）

主要使用场景

  • SEO 审计。扫描站点每一个 URL 查找缺失的标题、描述、canonical 和 OG 标签
  • 内容 QA。验证新发布文章包含所有必需的结构化数据和标题
  • 结构化数据验证。批量验证 Schema.org Product、Article、FAQ 和 Recipe 标记
  • 竞争分析。比较竞争对手排名靠前页面的 title 和 description 模式
  • 迁移 QA。确认 canonical、hreflang 和 OG 标签在站点改版后保留

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~seo-metadata-extractor/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://example.com/product-a",
      "https://example.com/blog/post-1",
      "https://example.com/about",
      "https://example.com/pricing",
      "https://example.com/contact"
    ],
    "extractJsonLd": true,
    "extractHeadings": true
  }'
