SEO-Metadaten-Extractor: Bulk-SEO-Audit in einem Aufruf, $1 pro 1.000 URLs

Jedes On-Page-SEO-Signal aus einer URL in einem Aufruf extrahieren. Liefert Title, Meta-Description, Canonical-URL, Hreflang-Alternates, Robots-Direktiven, Open Graph Tags, Twitter Cards, alle Schema.org-JSON-LD-Blöcke, H1-H6-Outline, interne/externe Link-Counts, Image-Counts mit Alt-Coverage und einen 0-100 SEO-Score. Für Bulk gebaut: 10.000 URLs rein, eine Zeile pro Seite raus. Ideal für SEO-Audits, Content-QA, Structured-Data-Validierung und Competitive Analysis.

Was Sie erhalten

  • Core SEO: title, meta_description, canonical_url, robots_meta, viewport, language
  • Open Graph: og_title, og_description, og_image, og_type, og_url, og_site_name
  • Twitter Cards: twitter_card, twitter_title, twitter_description, twitter_image
  • Structured Data: alle Schema.org-JSON-LD-Blöcke geparst und typisiert
  • Seitenstruktur: headings (H1-H6), word_count, image_count, link_count, alt_coverage
  • Scoring: seo_score (0-100), warnings[] (fehlende Canonical, doppelte H1, etc.)

Wichtige Anwendungsfälle

  • SEO-Audits. Jede URL einer Site auf fehlende Titles, Descriptions, Canonicals und OG-Tags scannen
  • Content-QA. Verifizieren, dass neu veröffentlichte Artikel alle erforderlichen Structured Data und Überschriften enthalten
  • Structured-Data-Validierung. Schema.org Product, Article, FAQ und Recipe Markup bulk-validieren
  • Competitive Analysis. Title- und Description-Muster über die Top-rankenden Seiten eines Wettbewerbers vergleichen
  • Migrations-QA. Bestätigen, dass Canonicals, Hreflang und OG-Tags einen Site-Relaunch überstanden haben

API-Beispiel

# Einen Lauf über die Apify-API starten
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~seo-metadata-extractor/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://example.com/product-a",
      "https://example.com/blog/post-1",
      "https://example.com/about",
      "https://example.com/pricing",
      "https://example.com/contact"
    ],
    "extractJsonLd": true,
    "extractHeadings": true
  }'
