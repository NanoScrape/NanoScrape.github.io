SEC EDGAR Filings Scraper: 10-K, 10-Q, 8-K and Company Data

The NanoScrape SEC EDGAR Filings Scraper is an Apify actor that extracts filing records from the public EDGAR interfaces of the U.S. Securities and Exchange Commission by ticker, CIK, company name or full-text search. It returns 43 fields per filing including accession number, form type, filing and report dates, 8-K items, file size, XBRL flags, filing and document links, and the company profile with industry code, addresses, phone, fiscal year end and exchanges, priced at $0.50 per 1,000 filings, with no API key or monthly subscription required.

Input

Put tickers (AAPL), CIK numbers (320193) or company names in companies; a name uses the best match in the SEC company list. searchQuery searches the text of filings from 2001 on, for example "going concern" in quotes for an exact phrase; with companies given, the search is limited to them. formTypes keeps only these forms, such as 10-K, 8-K or S-1; a form matches exactly, so list 10-K/A too for amendments. dateFrom and dateTo limit the filing date. maxResults (default 100) caps the filings of the run, shared equally between companies. includeOlderFilings also reads the older filing pages of each company. An empty input runs a small sample.

Input example — annual, quarterly and 8-K filings of two companies in 2026

{
  "companies": [
    "AAPL",
    "MSFT"
  ],
  "formTypes": [
    "10-K",
    "10-Q",
    "8-K"
  ],
  "dateFrom": "2026-01-01",
  "maxResults": 100
}

FAQ

How much does the sec-edgar-filings-scraper cost?

$0.0005 per filing delivered ($0.50 per 1,000 filings), with the company profile included. A run that finds nothing costs nothing. Apify's $5/month free tier covers the first runs. No monthly subscription — you only pay for what you extract.

What fields does it return?

43 fields per filing: accession number, CIK, company name, tickers and exchanges, form type, filing, report and acceptance dates, act, file and film number, 8-K items, size, XBRL flags, main document name and description, filing and document links, industry code, entity type, filer category, state of incorporation, fiscal year end, business and mailing address, phone, EIN, LEI and websites where filed, plus the matching document for full-text searches.

Does it download the filing documents?

No. It returns filing metadata and links to the filing page and main document on sec.gov. It does not download or parse the documents.

Why does 10-K not return 10-K/A?

Form types match exactly. Add 10-K/A to formTypes to get amendments as well.

How far back does it go?

Company lookups read the recent filings list (at least one year, usually the latest 1,000); switch on includeOlderFilings for older pages. Full-text search covers filings from 2001 on.

Do I need an API key?

No. The data comes from the public EDGAR interfaces, and the actor stays below the request limits of the SEC fair access policy.

How fresh is the data?

Every run pulls live data at execution time. Set up a schedule (daily/hourly/weekly cron) in the Apify console to keep your dataset current automatically.
