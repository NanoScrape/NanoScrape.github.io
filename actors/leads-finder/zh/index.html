Leads Finder：来自 Google + Yelp 的 B2B 潜客列表

从 Google 搜索结果与 Yelp 生成 B2B 与本地潜客。返回公司名、网站、邮箱、电话、地址、类别与客户评分。可选自动邮箱提取，会爬取每家公司主页与联系页。Apollo.io 替代，无需登录或 API key。

每条潜客可得

  • 身份：公司名、类别、描述、来源（google 或 yelp）、search_query
  • 联系：网站 URL、实时从主页提取的邮箱、电话
  • 位置：地址、城市、州/省、国家
  • 信任信号：评分（1-5 星）、review_count
  • 社媒：SERP 摘要中存在时返回 LinkedIn 公司 URL
  • 溯源：SERP 页的 source_url、scraped_at 时间戳

主要用例

  • 冷外联潜客列表。为出站活动构建一份带邮箱与电话的纽约数字营销机构列表
  • 本地商业情报。映射一座城市中每位水管工、牙医或餐馆，含评分与评论数
  • CRM 管线扩充。输入搜索查询，输出已预扩充含邮箱的潜客
  • Apollo.io 替代。无订阅、无 credit 限制、无登录。仅为保留的潜客付费
  • 竞品研究。发现在您细分市场与地理范围运营的每家企业
  • 合作伙伴发现。按服务类别寻找潜在分销商、集成商或联盟伙伴

API 示例

# Find B2B leads from Google and Yelp in one run
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~leads-finder/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "queries": ["digital marketing agency", "web design company"],
    "location": "New York, NY",
    "sources": ["google", "yelp"],
    "maxLeadsPerQuery": 50,
    "extractEmails": true
  }'

# Or use with AI agents via MCP:
