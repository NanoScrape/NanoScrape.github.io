The NanoScrape Jobgether Scraper is an Apify actor that extracts remote job offers from jobgether.com. It returns 60 fields per job including title, company, allowed countries, employment type, seniority, salary range when shown, skills, posting date and apply URL, with the full description on request, priced at $0.10 per 1,000 jobs, with no API key or monthly subscription required.

Scrape remote job offers from Jobgether by role, skill, location, company or Jobgether address and get title, company, the places the job can be worked from, employment type, seniority, salary range when shown, skills, roles, posting date and the public apply link (source platform). Turn on the offer page option for the full description, role summary, qualifications and responsibilities. Pay per result.

Input

Every field is optional. searchQueries takes roles, skills or topics such as python, data or Account Executive; a keyword becomes a Jobgether page name, so a keyword the site has no page for gives 0 rows. startUrls takes Jobgether addresses such as https://jobgether.com/remote-jobs/data-analyst, locations takes location slugs (germany, united-states, europe, anywhere) and companies takes company slugs such as grafanalabs. Each source is its own page. maxResultsPerQuery (default 50, up to 1000) and maxResults (0 for no limit) cap the run; the site shows at most 10 pages of 50 offers per source. includeDetails (default off) reads each offer page for the full text and extra fields. An offer is returned once per run. A run with no input returns 20 offers for the keyword python.

Input example — Python and data analyst jobs, Germany, with offer page details

{
  "searchQueries": [

  "includeDetails": true,

}

Cost math

Priced at $0.0001 per job saved to the dataset ($0.10 per 1,000): 100 jobs ≈ $0.01, 1,000 jobs ≈ $0.10. The offer page details (full description, qualifications, responsibilities) are part of the same job and not charged separately. A job is charged once, even when several keywords, locations or companies list it, and the run ends cleanly at your maximum total charge. No monthly subscription, you pay only for what you extract.

FAQ

How much does the jobgether-jobs-scraper cost?

Priced at $0.0001 per job saved to the dataset ($0.10 per 1,000). Offer page details are not charged separately, and a job is charged once per run. No monthly subscription, you only pay for what you extract.

What fields does it return?

60 fields per job: ID, title, company with industry and size, places the job can be worked from, remote type, employment type, seniority, salary range when shown, skills, roles, posting date and apply URL. With includeDetails on you also get the full description, role summary, qualifications, responsibilities, applicant countries and valid-through date.

Why does a keyword return nothing?

Jobgether has pages for roles, skills, locations and companies. A keyword with no page returns 0 rows and the run ends normally. Try a shorter word, a role such as data-analyst, or the address of a page you found on the site.

Does the keyword search the offer text?

No. A keyword opens the Jobgether page with that name, such as a role (data) or a skill (python). Use several keywords to cover a topic.

Is there a salary for every offer?

No. Many offers show none, then the salary fields are null. The site does not state whether a figure is per year or per hour, so the actor does not either.

How many offers can I get?

Each source lists 50 offers per page and reports at most 10 pages, about 500 offers per source. Use several keywords, locations or companies to get more.

Do I need an API key from the source platform?

No. No Jobgether account and no API key. Give the actor keywords, locations or companies and it does the rest.
