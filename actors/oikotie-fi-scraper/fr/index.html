Ce que vous pouvez extraire

  • Prix : price (formate "295 000 EUR"), price_numeric (nombre parse), permet un calcul neliohinta propre (EUR/m2)
  • Configuration : rooms (compteur entier), room_configuration (layout finlandais comme "3h+k+s"), area_sqm, lot_area_sqm, floor, floor_count
  • Batiment : building_type (Kerrostalo immeuble, Rivitalo maison en bande, Omakotitalo maison individuelle, Paritalo maison jumelee), building_year
  • Localisation : address, city, district (par exemple Toolo, Kallio, Punavuori), latitude, longitude
  • Description : description complete en finnois (kuvaus)
  • Courtier : broker_name (Kiinteistomaailma, OP Koti, Huoneistokeskus, ...), realtor_name (agent individuel)
  • Medias : image_url
  • Metadonnees : published_at, source_url, scraped_at
