Wayback Machine URLs Scraper: archivierte URL-Listen für jede Domain

Listen Sie die Captures auf, die die Wayback Machine des Internet Archive für eine Domain oder URL speichert. Jede Zeile ist ein Capture mit Zeitpunkt, Original-Adresse, Statuscode, Dateityp, Größe und einem Link, der die archivierte Kopie öffnet. Kein Konto, kein API-Schlüssel.

Was Sie bekommen

  • Capture: urlkey, Zeitstempel (YYYYMMDDhhmmss, UTC) und capturedAt in ISO 8601
  • Adresse: die erfasste Original-URL und der Link zur archivierten Kopie
  • Antwort: Statuscode, Dateityp (mimetype) und Größe in Byte
  • Inhalt: Hash (digest); gleiche Hashes bedeuten gleichen Inhalt
  • Herkunft: der Eintrag aus Ihrer Eingabe, zu dem der Capture gefunden wurde

Typische Anwendungsfälle

  • Relaunch und Migration: alte Seiten einer Website vor einem Umbau finden
  • Weiterleitungen: Liste früherer URLs für Redirects oder die Prüfung toter Links aufbauen
  • Dateien sammeln: alle PDF- oder Bilddateien einer Domain im Archiv auflisten
  • Änderungen verfolgen: eine Zeile pro geänderter Version einer Seite
  • Recherche: wie eine Website in einem bestimmten Jahr aussah

Eingabe

urls nimmt Domains (apify.com) oder vollständige URLs (https://apify.com/blog), der Reihe nach abgearbeitet. matchType ist domain (Standard, die Domain mit Subdomains), host, prefix oder exact. from und to begrenzen das Capture-Datum auf ein Jahr (2020) oder ein Datum (20200131). statusFilter (Standard 200) nimmt einen Code, ein Muster wie 2.., !404 zum Ausschließen oder any; mimeTypeFilter behält einen Dateityp wie application/pdf oder image/.*. collapse ist urlkey (Standard, eine Zeile pro URL), digest (neue Zeile nur bei geändertem Inhalt) oder none (jeder Capture). maxResults (Standard 1000, bis 1.000.000) zählt alle Einträge zusammen; maxResultsPerUrl verteilt das Budget auf die Einträge. Ohne Eingabe liefert der Actor eine Probe mit 100 Captures für apify.com.

Beispiel-Eingabe

{
  "urls": [
    "https://apify.com/pricing"
  ],
  "matchType": "exact",
  "from": "2023",
  "to": "2023",
  "collapse": "digest"
}

Was das kostet

0,002 $ pro gelieferter Capture, also 2,00 $ pro 1.000 Captures. Beispiele: 100 Captures kosten etwa 0,20 $, 1.000 Captures etwa 2,00 $. Bei collapse auf none zahlen Sie jeden Capture einer Seite; halten Sie Läufe mit from, to und maxResults klein. Ein Lauf ohne Treffer wird nicht berechnet. Kein Monatsabo.

Hinweise

Hinweis: Der Actor listet Captures auf und lädt die archivierten Seiten nicht herunter. Bitte nutzen Sie das Archiv maßvoll und gemäß seinen Nutzungsbedingungen.
