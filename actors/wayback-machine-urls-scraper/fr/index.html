Wayback Machine URLs Scraper : listes d'URL archivées pour tout domaine

Listez les captures que la Wayback Machine de l'Internet Archive conserve pour un domaine ou une URL. Chaque ligne est une capture avec sa date, son adresse d'origine, son code HTTP, son type de fichier, sa taille et un lien qui ouvre la copie archivée. Sans compte, sans clé API.

Ce que vous obtenez

  • Capture : urlkey, horodatage (YYYYMMDDhhmmss, UTC) et capturedAt en ISO 8601
  • Adresse : l'URL d'origine capturée et le lien vers la copie archivée
  • Réponse : code HTTP, type de fichier (mimetype) et taille en octets
  • Contenu : empreinte (digest) ; deux empreintes identiques signifient un contenu identique
  • Origine : l'entrée de votre saisie pour laquelle la capture a été trouvée

Cas d'usage

  • Refonte et migration : retrouver les anciennes pages d'un site avant une refonte
  • Redirections : dresser la liste des URL passées pour des redirections ou le contrôle des liens morts
  • Collecte de fichiers : lister tous les PDF ou images que l'archive conserve pour un domaine
  • Suivi des changements : une ligne par version modifiée d'une page
  • Recherche : voir à quoi ressemblait un site une année donnée

Entrée

urls accepte des domaines (apify.com) ou des URL complètes (https://apify.com/blog), traités dans l'ordre. matchType vaut domain (par défaut, le domaine et ses sous-domaines), host, prefix ou exact. from et to limitent la date des captures à une année (2020) ou une date (20200131). statusFilter (200 par défaut) accepte un code, un motif comme 2.., !404 pour exclure ou any ; mimeTypeFilter garde un type de fichier comme application/pdf ou image/.*. collapse vaut urlkey (par défaut, une ligne par URL), digest (nouvelle ligne seulement si le contenu change) ou none (chaque capture). maxResults (1000 par défaut, jusqu'à 1 000 000) compte toutes les entrées ensemble ; maxResultsPerUrl répartit le budget entre les entrées. Sans entrée, l'actor renvoie un échantillon de 100 captures pour apify.com.

Exemple d'entrée

{
  "urls": [
    "https://apify.com/pricing"
  ],
  "matchType": "exact",
  "from": "2023",
  "to": "2023",
  "collapse": "digest"
}

Combien ça coûte

0,002 $ par capture livrée, soit 2,00 $ pour 1 000 captures. Exemples : 100 captures coûtent environ 0,20 $, 1 000 captures environ 2,00 $. Avec collapse sur none, vous payez chaque capture d'une page ; gardez les runs petits avec from, to et maxResults. Un run sans résultat n'est pas facturé. Sans abonnement mensuel.

Remarques

Remarque : l'actor liste les captures et ne télécharge pas les pages archivées. Merci d'utiliser l'archive avec modération et conformément à ses conditions d'utilisation.
