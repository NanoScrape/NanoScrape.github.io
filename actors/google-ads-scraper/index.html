Google Ads Transparency Scraper

The NanoScrape Google Ads Scraper is an Apify actor that extracts structured web data from Google Ads. It returns 25 fields per result including description, advertiser_name, ad_format, first_shown_date, last_shown_date, priced at $1/1k ad, with no API key or monthly subscription required.

Search Google's public Ads Transparency Center without login or API key. Look up a brand name, domain or advertiser ID and get every ad creative with advertiser, format, shown dates and preview. Pay-per-result.

Use cases

  • Competitor research — see which creatives a competitor's advertiser account has run, and since when
