Email-Verifier und Bulk-Email-Validator, $1 pro 1.000 Emails

Jede Email-Adresse mit Fünf-Stufen-Verifikation validieren: Syntax-Check, MX-Lookup, SMTP-Handshake, Catch-All-Erkennung und Disposable- / Role-Based-Flagging. Liefert ein Verdict (valid / invalid / risky / unknown), einen 0-100 Confidence-Score, den MX-Provider und Reason Codes. Für Bulk gebaut: 100.000-Zeilen-Liste rein, eine saubere Roster für Outreach raus. Ideal für Cold-Email-Hygiene, Lead-List-Cleansing, Signup-Form-Schutz und CRM-Deliverability-Cleanup.

Was Sie erhalten

  • Verdict: status (valid / invalid / risky / unknown), confidence (0-100), is_deliverable
  • Syntax-Checks: is_valid_format, is_ascii_only, local_part, domain
  • MX-Schicht: mx_found, mx_provider (Google, Microsoft 365, Zoho, etc.), mx_records[]
  • SMTP-Schicht: smtp_check, smtp_response, is_catch_all
  • Risk-Flags: is_disposable, is_role_based (info@, sales@), is_free_provider (gmail, yahoo)

Wichtige Anwendungsfälle

  • Cold-Email-Hygiene. Eine 50.000-Zeilen-Prospekt-Liste vor dem Launch einer Outbound-Sequenz reinigen, um Sender-Reputation zu schützen
  • Lead-List-Cleansing. Disposable-, Role-Based- und unzustellbare Adressen aus importierten Listen entfernen
  • Signup-Form-Schutz. Emails server-seitig validieren, bevor Accounts angelegt werden, um Bot-Signups zu reduzieren
  • CRM-Deliverability-Cleanup. Ein CRM quartalsweise re-verifizieren, um veraltete Adressen vor Bounces zu flaggen
  • Sales-Tool-Qualitätskontrolle. Emails anderer Tools verifizieren, bevor sie zu Sequenzen hinzugefügt werden

API-Beispiel

# Einen Lauf über die Apify-API starten
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~email-verifier/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "emails": [
      "user@example.com",
      "info@company.com",
      "ceo@startup.io",
      "noreply@spamdomain.test",
      "valid.lead@enterprise.co"
    ],
    "smtpCheck": true,
    "detectCatchAll": true
  }'
