邮箱验证器与批量邮箱验证，每 1,000 邮箱 $1

通过五阶段验证对任意邮箱进行验证：语法检查、MX 查询、SMTP 握手、catch-all 检测，以及一次性邮箱 / 角色邮箱标记。返回判定（valid / invalid / risky / unknown）、0-100 置信度评分、MX 提供商和原因码。为批量而生：输入 10 万行列表，返回可直接用于外联的干净名单。适用于冷邮件清理、潜客名单清洗、注册表单保护和 CRM 送达性清理。

您能获得什么

  • 判定：status（valid / invalid / risky / unknown）、confidence（0-100）、is_deliverable
  • 语法检查：is_valid_format、is_ascii_only、local_part、domain
  • MX 层：mx_found、mx_provider（Google、Microsoft 365、Zoho 等）、mx_records[]
  • SMTP 层：smtp_check、smtp_response、is_catch_all
  • 风险标记：is_disposable、is_role_based（info@、sales@）、is_free_provider（gmail、yahoo）

主要使用场景

  • 冷邮件清理。在启动外联序列前清理 5 万行潜客列表以保护发件人信誉
  • 潜客名单清洗。从导入列表中剥离一次性、角色邮箱和不可投递的地址
  • 注册表单保护。在创建账号前服务端验证邮箱，减少机器人注册
  • CRM 送达性清理。每季度重新验证 CRM 以在反弹前标记过时地址
  • 销售工具质量控制。将其他工具返回的邮箱加入序列前进行验证

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~email-verifier/runs?token=YOUR_TOKEN" \
 -H "Content-Type: application/json" \
 -d '{
 "emails": [
 "user@example.com",
 "info@company.com",
 "ceo@startup.io",
 "noreply@spamdomain.test",
 "valid.lead@enterprise.co"
 ],
 "smtpCheck": true,
 "detectCatchAll": true
 }'
