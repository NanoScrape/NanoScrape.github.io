Ce que vous obtenez

  • Verdict : status (valid / invalid / risky / unknown), confidence (0-100), is_deliverable
  • Contrôles de syntaxe : is_valid_format, is_ascii_only, local_part, domain
  • Couche MX : mx_found, mx_provider (Google, Microsoft 365, Zoho, etc.), mx_records[]
  • Couche SMTP : smtp_check, smtp_response, is_catch_all
  • Marqueurs de risque : is_disposable, is_role_based (info@, sales@), is_free_provider (gmail, yahoo)

Cas d'usage principaux

  • Hygiène d'email à froid. Nettoyer une liste de 50 000 prospects avant de lancer une séquence outbound pour protéger la réputation expéditeur
  • Nettoyage de listes leads. Retirer adresses jetables, role-based et non délivrables des listes importées
  • Protection de formulaires d'inscription. Valider les emails côté serveur avant création de compte pour réduire les inscriptions de bots
  • Nettoyage de délivrabilité CRM. Revérifier un CRM trimestriellement pour marquer les adresses obsolètes avant qu'elles ne rebondissent
  • Contrôle qualité outils de vente. Vérifier les emails fournis par d'autres outils avant de les ajouter aux séquences
