您可以抓取的内容

  • 职位详情：标题、唯一 id、完整描述（文本 + HTML）、标签、发布日期、申请 URL
  • 薪资情报：salary_min、salary_max、salary_currency、salary_text（远程薪资基准的金矿）
  • 公司信息：公司名称、公司 logo URL

  • 元数据：来源 URL、找到该职位的搜索查询、scraped_at 时间戳

主要使用场景

  • 远程人才寻源。拉取所有工程或设计职位，推送到 ATS 用于主动招聘
  • 按时区做薪资基准。聚合美、欧、亚太时区远程职位的 salary_min 与 salary_max

  • 垂类招聘板回填。用 tags 过滤 senior、Python、blockchain 或任意垂类，导入自有产品
