Frequently asked

How is a NanoScrape actor different from a Playwright / browser scraper?

Most NanoScrape actors are HTTP-only Go programs: 128 MB RAM, sub-second cold start, 10–50× cheaper per result than a Chromium-based scraper. For sites without JavaScript-only content or a hard anti-bot wall, that's a pure win. When a site does require a real browser, we ship a browser-tier actor instead — priced accordingly — and we migrate to HTTP-only Go as soon as we crack the protection.

How do I run these from n8n, Make, Zapier or Python?

Every actor page has a Run block with copy-paste code for cURL, Node.js SDK, Python SDK, Java, C#, plus visual-tool platforms (n8n, Make, Zapier, Pipedream, Bubble). The Apify MCP endpoint (mcp.apify.com/actors/{slug}) makes any actor callable from Claude Desktop, Cursor, VS Code Copilot, LangChain, LlamaIndex, and any MCP-compatible agent.

How fresh is the catalog?

This page rebuilds every night from the live Apify inventory. Any actor promoted to public today shows up tomorrow morning; any actor deprecated is removed. The card counts also update daily — no manual maintenance.
