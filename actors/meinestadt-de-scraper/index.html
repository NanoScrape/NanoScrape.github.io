What You Get

  • title, company, location, canton — German state code (BW, BY, BE, etc.) auto-detected from city name
  • salary_text / salary range — parsed from structured job data where employers provide it (e.g. '33,982 EUR - 47,036 EUR/Jahr')
  • requirements and company_benefits — extracted as clean arrays, not buried in HTML
  • company_description — the about-the-company text section from detail pages
  • company_logo_url — displayed as image preview in the Apify dataset viewer
  • employment_type / workload_min / workload_max / remote_option — full work-schedule metadata
  • apply_url / apply_email — both application channels extracted for direct outreach
  • search_query tracking — each result carries the keyword that found it for multi-query attribution

Who Should Use This

German regional job aggregators need MeineStadt.de because it covers community-level postings in smaller cities and towns that national boards like StepStone and Indeed miss. With 900,000+ active listings spanning every German Bundesland, this is the widest regional job coverage in Germany in a single actor. Staffing agencies and HR software companies use the multi-keyword search with automatic deduplication to scan multiple care, trade, or tech categories in one run, then route each result by employment_type and workload. Salary benchmark tools extract structured salary ranges where available and normalize them to EUR alongside Bundesland codes for regional compensation reports. Recruitment analytics platforms use requirements and company_benefits arrays as direct model features without additional parsing.
