Input — search query, sort, and detail depth

Every run starts from one or more Spanish search queries and returns SERP-tier data by default (title, company, location, salary hint, posted date). Toggle includeJobDetails to fetch the full job description, requirements and benefits per posting; toggle includeCompanyDetails to enrich company data (rating, industry, HQ, employee count, social URLs).

Input example (JSON)

{
  "searchQueries": ["desarrollador"],
  "sortBy": "newest",
  "maxResults": 5,
  "maxResultsPerQuery": 5,
  "includeJobDetails": false,
  "includeCompanyDetails": false
}
