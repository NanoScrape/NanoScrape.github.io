Google Trends Scraper

Cost math

Priced at $0.0015 per keyword row ($1.50 per 1,000) and $0.0005 per trending search. The first runs land inside Apify's $5/mo free-tier credit — pay only for what you extract, no monthly subscription.

Input

mode is keywords (default) for keyword trends or trending for the current trending searches. Put search terms in keywords; each gets its own row per geo, or set compareKeywords to compare up to 5 keywords on one scale in one row. geo takes country codes such as US or DE or regions such as US-CA, each with its own rows; empty is worldwide. timeframe is one of now 1-H to today 5-y or all (since 2004), or a date range. category and property (news, images, youtube, shopping) narrow the measurement. timeline, regions and relatedQueries switch the parts of each row on or off. maxItems caps the rows of the run. An empty input runs a small sample.
