Input

Leave the input empty of keywords to scrape the whole portal, which has about 40-100 open positions at any time; an empty input {} returns a small demo of 5 jobs. searchQueries takes French keywords such as infirmier, comptable or juriste, each run as a separate search, and startUrls takes direct offres-emploi.vd.ch job URLs for still-alive re-checks. category filters on the Etat de Vaud category (for example Secteur administratif) and needs includeJobDetails. sortBy is newest (default), oldest, relevance or title. maxResults (100 when empty, up to 500) and maxResultsPerQuery cap the run.

Input example — two French keywords with full details

{
  "searchQueries": [
    "infirmier",
    "comptable"
  ],
  "sortBy": "newest",
  "maxResults": 100,
  "includeJobDetails": true
}

Cost math

Priced at $0.001 per job from the listing ($1.00 per 1,000). With includeJobDetails on (the default), each job whose detail page loads costs $0.002 instead ($2.00 per 1,000); if a detail page can't be loaded, that job is saved from listing data at $0.001. Jobs dropped by the category filter are not charged, and the run stops cleanly at your maximum cost per run. The first runs land inside Apify's $5/mo free-tier credit — pay only for what you extract, no monthly subscription.

FAQ

How much does the vd-ch-emploi-scraper cost?

Priced at $0.001 per job from the listing ($1.00 per 1,000). With includeJobDetails on (the default), each job whose detail page loads costs $0.002 instead ($2.00 per 1,000); if a detail page can't be loaded, that job is saved from listing data at $0.001. Apify's $5/month free tier covers the first runs. No monthly subscription — you only pay for what you extract.

What fields does it return?

48 fields per job: IDs and URLs, title, department, location and work address, posting and end dates, contract type, activity rate with parsed min and max, cantonal salary class, category, the French description as HTML, text and Markdown, separate Missions and Profil blocks, contacts found in the posting and a job description document link when there is one.

How many jobs does the portal have?

About 40-100 open positions at any time, so one unfiltered run captures the whole portal. The employer is always the Etat de Vaud.

Is salary_class a salary?

No. It is the Etat de Vaud salary class (Classe salariale) under the cantonal salary grid, not an amount.

Is scraping this site legal?

Scraping publicly available data is generally permitted in most jurisdictions, but GDPR and the Swiss data protection act apply to any personal data you collect, such as contact details in a posting. Review your local rules and consult a lawyer for commercial use.

Do I need an API key from the source platform?

No. No login and no API key. A full run of the portal finishes in well under a minute.

How fresh is the data?

Every run pulls live data at execution time. Set up a schedule (daily/hourly/weekly cron) in the Apify console to keep your dataset current automatically.
