可以抓取的内容

  • 身份信息：company_name、法律形式、year_founded、kompass_id、source_url
  • 联系方式：网站、电话、邮箱、含邮编的完整地址、GPS 坐标
  • 规模信号：employee_count（区间，如 "20 至 49"）、revenue_range、supplier_type
  • 商业信息：product_categories、服务、出口市场、贸易活动
  • 信任信号：ISO 与行业认证、Logo URL
  • 地理覆盖：支持全部 70+ 国家域名（de.kompass.com、fr.kompass.com、gb.kompass.com 等）

主要使用场景

  • B2B 销售开发。按行业构建分国家的线索列表，再以邮箱和电话补充用于外呼活动
  • 供应商寻源。按 supplier_type 与认证筛选，在 70+ 市场中入围合格制造商
  • 市场规模评估。按 NACE 类目和国家统计企业数，估算进入市场前的 TAM
  • 合作伙伴发现。为渠道项目映射目标地区的分销商和经销商
  • 竞争情报。追踪垂直行业新进入者和营收区间的长期变化

注意与限制

  • DataDome 防护。Kompass 使用 DataDome。本抓取器使用 Apify 住宅代理并匹配国家。若首次运行返回数据稀薄，请重试：新的住宅 IP 通常在重试时即可通过挑战
  • 字段覆盖因国家而异。部分 Kompass 国家站点公开发布营收和员工数，另一些仅在详情页提供。设置 includeDetails: true 可获得最深覆盖
  • 邮箱为尽力而为。Kompass 并非对所有企业都公开邮箱。可与我们的 Website Contact Extractor 配合使用以填补缺口
