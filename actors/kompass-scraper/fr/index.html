Ce que vous pouvez extraire

  • Identité : company_name, forme juridique, year_founded, kompass_id, source_url
  • Contact : site web, téléphone, e-mail, adresse complète avec code postal, coordonnées GPS
  • Signaux de taille : employee_count (par tranches, ex. "20 à 49"), revenue_range, supplier_type
  • Commerce : product_categories, services, marchés d'export, activité commerciale
  • Confiance : certifications ISO et sectorielles, URL du logo
  • Géographie : fonctionne avec tous les 70+ domaines pays (de.kompass.com, fr.kompass.com, gb.kompass.com, ...)

Principaux cas d'usage

  • Prospection B2B. Construire des listes de leads par pays et par secteur, puis enrichir avec e-mail et téléphone pour des campagnes outbound

Notes et limites

  • Protection . Kompass utilise . Le scraper utilise le proxy résidentiel Apify avec correspondance pays. Si le premier run renvoie peu de données, relancez : une IP résidentielle fraîche passe généralement le challenge au second essai
  • La couverture varie selon le pays. Certains sites Kompass publient le chiffre d'affaires et l'effectif publiquement, d'autres seulement sur les pages détail. Activez includeDetails: true pour la couverture la plus complète
  • L'e-mail est best-effort. Kompass ne publie pas d'e-mail pour toutes les entreprises. Combinez avec notre Website Contact Extractor pour combler la lacune
