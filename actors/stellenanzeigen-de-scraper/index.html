What You Get

  • title, company, location — with German Bundesland code (BW, BY, BE, NW, etc.) auto-detected from city name
  • salary_text and structured salary range — parsed from JSON-LD JobPosting schema and description text
  • contact_email / contact_phone — extracted from job description bodies; useful for direct recruiter outreach
  • company_logo_url — company logo from search results and detail pages, displayed as image preview in dataset viewer
  • employment_type — Vollzeit, Teilzeit, Minijob, Ausbildung, Praktikum, Befristet, Freelance normalized
  • remote_option — remote / hybrid / onsite when indicated in the listing
  • job_status — online / expired / removed for still-alive monitoring in direct URL mode
  • search_query tracking — each result carries the keyword that found it for multi-keyword attribution and cost reporting

Who Should Use This

German job aggregators and labour analytics platforms add Stellenanzeigen.de to their pipeline because it sits in Germany's Top 3 by listing volume alongside StepStone and Monster, meaning it captures employers and roles not mirrored on the other two. Contact prospecting teams extract contact_email and contact_phone from job descriptions to build recruiter outreach lists without a separate email-scraping step. Bundesland-level market researchers use the auto-detected state code to produce per-Bundesland hiring trend reports for all 16 German states without any manual location tagging. The ultra-low 128 MB footprint and HTTP-only approach make it one of the cheapest German job scrapers to run at scale: no browser instance, no Chromium memory overhead.
