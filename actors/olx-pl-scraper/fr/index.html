OLX.pl Scraper : n°1 des petites annonces en Pologne

Extrayez les petites annonces d'olx.pl, la plus grande place de marché en ligne de Pologne. L'actor utilise l'API REST publique d'OLX pour retourner titre, description complète, prix en PLN ou EUR, état, ville et région, coordonnées GPS, nom et type de vendeur (privé ou professionnel), toutes les URLs d'images, date de publication et URL source. Recherchez par mot-clé, affinez par ville polonaise (warszawa, krakow, wroclaw) ou par ID de catégorie, et exécutez plusieurs requêtes en parallèle. La pagination est automatique.

Ce que vous pouvez extraire

  • Toutes catégories : téléphones, électronique, mode, immobilier (nieruchomosci), voitures, emploi, services
  • Recherche : mot-clé + slug ville optionnel (warszawa, krakow, wroclaw) + ID catégorie optionnel
  • API REST : appels directs au point d'entrée public d'OLX, pas de parsing HTML
  • Tri : filter_float_price:asc, filter_float_price:desc, created_at:desc
  • Multi-recherche : plusieurs requêtes dans une exécution, avec plafonds par requête
  • Distinction vendeur : flag privé vs professionnel préservé

Cas d'usage principaux

  • Arbitrage téléphones d'occasion. Surveiller iPhone 15, Samsung Galaxy S24 ou Pixel 8 sous un plafond PLN à Varsovie, Cracovie ou Wroclaw
  • Veille prix de l'occasion. Suivre les prix moyens en PLN des laptops, vélos ou PlayStations en Pologne
  • Surveillance concurrence revendeurs. Snapshot quotidien d'un vendeur professionnel pour repérer les changements de prix
  • Arbitrage transfrontalier CEE. Comparer les annonces polonaises aux équivalents Bazos.sk ou Bazos.cz sur les marchés voisins
  • Cartographie du marché de l'emploi. Récupérer les postes ouverts dans n'importe quelle ville polonaise par catégorie
