您可以抓取的内容

  • 所有类目：手机、电子产品、时尚、房产 (nieruchomosci)、汽车、招聘、服务
  • 搜索：关键词 + 可选城市 slug (warszawa、krakow、wroclaw) + 可选类目 ID
  • REST API：直接命中 OLX 公开 listings 端点，无 HTML 解析
  • 排序：filter_float_price:asc、filter_float_price:desc、created_at:desc
  • 多搜索：一次运行多个查询，含按查询的结果上限
  • 卖家区分：保留私人 vs 商家标志

主要使用场景

  • 二手手机套利。监控华沙、克拉科夫或弗罗茨瓦夫 PLN 上限以下的 iPhone 15、Samsung Galaxy S24 或 Pixel 8
  • 二手价格情报。追踪波兰各地笔记本、自行车或 PlayStation 的平均 PLN 价格
  • 经销商竞品监控。每日快照商家门店，发现价格变化
  • 中欧跨境套利。将波兰广告与邻近市场 Bazos.sk 或 Bazos.cz 的对等商品比较
  • 就业市场映射。按类目获取任意波兰城市的开放岗位
