您可以抓取的内容

  • 卖家档案：sellerName、businessName、营业地址（街道、城市、州/省、邮编、国家）
  • 按时段统计的评分：ratingsAvg、ratingsCount、30天 / 90天 / 12个月 / 累计的好评率
  • 政策：returnPolicySummary、shippingPolicySummary、about、sellerSince
  • 卖家目录商品：asin、title、price、stars、reviews、position、isPrime、isFulfilledByAmazon
  • 一个 dataset 包含两种行类型：档案行与商品行，可通过 type 字段筛选

主要使用场景

  • 卖家研究。找到与您同类目竞争的卖家，查看其评分和政策
  • 目录审计。抓取某卖家提供的每一款商品，进行 SKU 级别的竞争分析
  • 信任信号评估。对比不同时段的评分，对第三方卖家进行风险筛查
  • 合作伙伴拓展。在邻近类目中寻找评分优秀的卖家
