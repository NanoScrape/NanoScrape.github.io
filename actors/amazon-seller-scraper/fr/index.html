Amazon Seller Scraper : boutique vendeur plus catalogue produit complet

Scrapez les boutiques de vendeurs Amazon sur 20 marchés. Retourne le profil vendeur complet (nom, adresse professionnelle, notes par période, politiques de retour et de livraison, options de contact) ET le catalogue produit complet du vendeur. La plupart des concurrents fournissent l'un ou l'autre. Nous fournissons les deux.

Ce que vous pouvez extraire

  • Profil vendeur : sellerName, businessName, adresse professionnelle (rue, ville, région, code postal, pays)
  • Notes par période : ratingsAvg, ratingsCount, % positifs 30j / 90j / 12mois / à vie
  • Politiques : returnPolicySummary, shippingPolicySummary, about, sellerSince
  • Produits du catalogue vendeur : asin, title, price, stars, reviews, position, isPrime, isFulfilledByAmazon
  • Deux types de lignes dans un seul dataset : lignes profil plus lignes produit, filtrables via le champ type

Cas d'usage principaux

  • Recherche de vendeurs. Trouvez les concurrents vendant dans votre catégorie, consultez leurs notes et politiques
  • Audit de catalogue. Récupérez chaque produit qu'un vendeur propose pour une analyse concurrentielle au niveau SKU
  • Évaluation des signaux de confiance. Comparez les notes sur plusieurs périodes pour filtrer les risques chez les vendeurs tiers
  • Prospection de partenariats. Identifiez des vendeurs bien notés dans des catégories adjacentes
