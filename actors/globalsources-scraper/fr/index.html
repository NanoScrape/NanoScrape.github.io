Ce que vous pouvez extraire

  • Identité : company_name, description, year_founded, supplier_type, logo_url
  • Contact : site web, téléphone, e-mail si disponible, adresse complète
  • Géographie : ville, province, pays, country_iso_code
  • Signaux de taille : employee_count, fourchette annual_revenue
  • Stratégie d'extraction duale : API JSON interne plus fallback de scraping HTML pour une couverture maximale

Principaux cas d'usage

  • Sourcing fournisseurs asiatiques. Compléter la couverture Made-in-China avec des exportateurs de Hong Kong, Taïwan, Inde et Vietnam
  • Préparation de salons. Construire des listes d'exposants avant les salons GlobalSources Electronics et Gifts à Hong Kong
  • Découverte OEM/ODM. Filtrer sur supplier_type et tranche de revenus pour shortlister des partenaires de fabrication viables
  • Vérification multi-source. Recouper le même fournisseur sur GlobalSources et Made-in-China pour détecter les incohérences
  • Diversification géographique. Identifier des alternatives hors Chine au Vietnam, en Inde et à Taïwan pour les chaînes sensibles aux tarifs douaniers

Notes et limites

  • Protection Imperva/Incapsula. GlobalSources utilise un challenge JavaScript reese84. Le proxy résidentiel est fortement recommandé. Augmentez maxSessionRetries si le premier essai rencontre beaucoup d'IPs bloquées
  • Extraction duale. Le scraper essaie d'abord l'API aggregate-search interne (JSON structuré), puis bascule sur le scraping HTML si l'API limite le débit
  • La couverture varie. Téléphone et e-mail ne sont pas exposés pour tous les fournisseurs. Combinez avec Website Contact Extractor pour des données plus complètes
