可以抓取的内容

  • 身份信息：company_name、描述、year_founded、supplier_type、logo_url
  • 联系方式：网站、电话、邮箱（如有）、完整地址
  • 地理：城市、省份、国家、country_iso_code
  • 规模信号：employee_count、annual_revenue 区间
  • 双重抓取策略：内部 JSON API 加 HTML 抓取兜底，最大化字段覆盖

主要使用场景

  • 亚洲供应商寻源。以香港、台湾、印度、越南出口商补充 Made-in-China 覆盖
  • 展会准备。在香港 GlobalSources 电子与礼品展前构建参展商清单
  • OEM/ODM 发现。按 supplier_type 与营收区间筛选，挑选可行的制造合作伙伴
  • 多源核验。在 GlobalSources 与 Made-in-China 交叉核对同一供应商，发现不一致
  • 地理多元化。为关税敏感的供应链识别越南、印度、台湾等非中国大陆替代来源

注意与限制

  • Imperva/Incapsula 防护。GlobalSources 使用 reese84 JavaScript 挑战。强烈建议使用住宅代理。如首次尝试遇到大量被拦 IP，请提高 maxSessionRetries
  • 双重抓取。抓取器优先尝试内部聚合搜索 API（结构化 JSON），若 API 限速则回落到 HTML 抓取
  • 字段覆盖不一。电话与邮箱并非每个供应商都公开。可与 Website Contact Extractor 配合以获取更完整数据
