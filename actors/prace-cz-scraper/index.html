Prace.cz Scraper: Czech Republic Jobs with CZK Salary and Contract Type

Scrape job listings from Prace.cz, Czech Republic's largest generalist job board (part of AlmaCareer group). Returns title, company, Czech administrative region, district, contract type in Czech (Hlavni pracovni pomer / Prace na dohodu / Zivnostensky list), CZK salary range, experience level, and full description. HTTP-only, no browser. $3.00 per 1,000 jobs.

What You Get

  • title, company_name, company_website, company_logo_url — full company identity from Teamio CDN
  • region / district — Czech administrative region (e.g. Karlovarsky, Jihomoravsky) and district for geo-routing
  • contract_type_cz — Czech employment contract type in native terminology: Hlavni pracovni pomer, Prace na dohodu, Zivnostensky list
  • salary_min / salary_max / salary_currency / salary_period — structured CZK salary parsed from JSON-LD JobPosting schema
  • employment_type / working_hours / experience_level — normalized work-schedule metadata
  • description / description_full / description_html / description_md — four description formats: snippet, plain text, raw HTML, and Markdown
  • contact_emails / contact_phones / contact_urls / apply_url — all application channels from the detail page
  • remoteOnly filter — return only remote-eligible positions at the input level without post-processing

Who Should Use This

Czech HR tech platforms and Central European job aggregators need Prace.cz because it is the largest job board in the Czech Republic under the AlmaCareer group (which also operates Profesia.sk in Slovakia and Jobs.cz as sister platforms). Compensation analytics tools value the structured CZK salary in monthly terms from JSON-LD data, making it the most reliable salary source in Czech job data. The contract_type_cz field is essential for the Czech labor market because Prace na dohodu (work-agreement contract) and Zivnostensky list (trade license / freelance) are common arrangements with distinct tax and legal implications that downstream systems need to differentiate. Remote work research platforms use the remoteOnly filter to pull only remote-eligible Czech positions without any post-processing.
