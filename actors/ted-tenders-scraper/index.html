Input

Put words or phrases in keywords, one search each; a notice found by several keywords is delivered once. countries takes ISO codes of the buyer country such as DE, FR or AT. cpvCodes takes CPV codes such as 72000000 (IT services); a code also matches the more specific codes below it. noticeTypes is contract, award, prior-information or modification. publishedFrom and publishedTo limit the publication date. activeOnly keeps only notices whose submission deadline has not passed. language (default EN) sets the language of title and description. expertQuery adds a condition in TED expert search syntax. maxResults (default 100) caps the notices of the run. Results come newest first. An empty input runs a small sample search.

Input example — open software tenders from buyers in Germany and Austria

{
  "keywords": [
    "software"
  ],
  "countries": [
    "DE",
    "AT"
  ],
  "noticeTypes": [
    "contract"
  ],
  "activeOnly": true,
  "maxResults": 100
}

FAQ

How much does the ted-tenders-scraper cost?

$0.001 per notice delivered ($1.00 per 1,000 notices). A run that finds nothing costs nothing. Apify's $5/month free tier covers the first runs. No monthly subscription — you only pay for what you extract.

What fields does it return?

42 fields per notice: publication number and link, title, procedure title, description, notice, form and procedure type, contract nature, publication date, deadline, buyer name, country, city, email, phone, website and type, CPV codes, place of performance, estimated and awarded value with currency, winners and their countries, lots, duration, framework and EU-funding flags, languages, and links to the notice as PDF, XML and HTML.

Why are some fields empty?

TED notices differ by form and age. Award notices have no submission deadline, and many buyers do not publish an estimated value.

Which notices are covered?

Notices published on TED, the EU journal for public procurement, including buyers in EU and EEA countries and others that publish there.

Does it download the tender documents?

No. It returns the public notice data with links to the notice as PDF, XML and HTML. Tender files attached by the buyer are not downloaded.

How many notices can one search return?

TED returns at most 15,000 results per search. Narrow large searches with dates, countries or CPV codes.

How fresh is the data?

Every run pulls live data at execution time. Set up a schedule (daily/hourly/weekly cron) in the Apify console to keep your dataset current automatically.
