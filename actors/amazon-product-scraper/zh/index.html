您可以抓取的内容

  • 核心标识：asin、url、marketplace、title、brand、manufacturer
  • 价格和库存：price、listPrice、currency、inStock、inStockText
  • 评分和社交证明：stars、reviewsCount、starsBreakdown、monthlyPurchaseVolume、answeredQuestions、aiReviewsSummary、topReviews（最多 8 条）
  • 媒体：thumbnailImage、highResolutionImages、galleryThumbnails、videosCount
  • 内容：features、description、aPlusContent、breadCrumbs、bestsellerRanks、attributes
  • 徽章和配送：isAmazonChoice、isPrime、isBestSeller、delivery、fastestDelivery、seller、shipsFrom、condition、returnPolicy
  • 变体：variantAsins、variantAttributes、variantDetails、isMultipack、multipackCount、originalAsin

主要使用场景

  • 动态定价。每日获取 SKU 目录的当前价格和原价
  • 库存监控。跟踪 inStock 和 delivery 以触发补货提醒
  • 目录数据增强。为商品 Feed 提取 features、attributes 和高分辨率图片
  • 竞争情报。跨竞品 ASIN 对比 stars、reviewsCount 和 monthlyPurchaseVolume
  • 变体发现。使用 variantAsins 枚举父级列表下的同级 SKU
  • 跨市场定价。同一 ASIN 在 .com、.de、.co.uk 上的套利分析

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~amazon-product-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "startUrls": [{"url": "https://www.amazon.com/dp/B09B8V1LZ3"}],
    "asins": ["B0BDHWDR12", "B00HZV9WTM"],
    "country": "US",
    "scrapeReviewSample": true
  }'

# 或通过 MCP 与 AI 代理配合使用：
# https://mcp.apify.com?tools=santamaria-automations/amazon-product-scraper
