NHS Jobs Scraper - UK Healthcare Jobs

The NanoScrape Nhs Jobs Scraper is an Apify actor that extracts structured web data from Nhs Jobs. It returns 52 fields per result including title, company, location, company_name, company_website, priced at $5/1k result, with no API key or monthly subscription required.

Scrape live UK healthcare jobs from every NHS trust via the official NHS Jobs public XML API. No API key needed. Returns job title, trust, location, pay band (min/max GBP), contract type, hours, closing date, and full description (text, HTML, Markdown). Pay-per-result.
