您可以抓取的内容

  • 职位详情：标题、id、完整描述（文本 + HTML）、类目、标签、job_type（全职、兼职、合同、自由职业）、发布日期、申请 URL
  • 薪资情报：salary_min、salary_max、salary_currency、salary_text
  • 所需地区：candidate_location（例如 "Worldwide"、"USA Only"、"Europe"）
  • 公司信息：公司名称、公司 logo URL
  • 雇主增强：company_website、company_tagline、open_positions_count、company_profile_url
  • 元数据：来源 URL、搜索查询、scraped_at 时间戳

主要使用场景

  • 远程人才寻源。按类目过滤（software-dev、design、marketing），将结构化记录推入招聘 CRM
  • 薪资基准。聚合 salary_min 与 salary_max，制定有竞争力的远程职位薪酬
  • 远程友好公司清单建设。用雇主增强字段区分全球招聘与地区限制公司
  • 垂类 ATS 回填。将 description_html 导入自有招聘板，只展示与受众匹配的类目

API 示例

# 通过 Apify API 启动运行

  -H "Content-Type: application/json" \
  -d '{
    "searchUrls": ["https://remotive.com/remote-jobs/software-dev"],
    "includeCompanyInfo": true,
    "maxResults": 100
  }'
