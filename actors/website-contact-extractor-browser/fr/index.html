Website Contact Extractor (Browser) : sites d'entreprise JS

Extraire les contacts (nom, poste, email, téléphone) des sites d'entreprise rendus en JavaScript (React, Vue, Angular SPA) avec Playwright et IA. Compagnon navigateur de Website Contact Extractor HTTP-only : gère les pages équipe, contact, à propos et mentions légales qui renvoient du HTML vide sans exécution JavaScript. Même format d'entrée, même sortie, validation anti-hallucination contre le HTML source. Auto-chaîné quand l'actor HTTP marque une entreprise avec js_rendering_suspected.

Quand utiliser cet actor

  • Pages équipe/contact rendues en JS : React, Vue, Angular et autres frameworks SPA
  • Réponses HTML vides : sites dont la page contact est rendue côté client
  • Entreprises marquées par l'actor HTTP : auto-chaîné via enablePlaywrightFallback
  • Pages de détail des membres : rendu en deux phases capture les profils individuels
  • Exigence anti-hallucination : contacts validés contre le HTML source, pas inventés par le LLM

Fonctionnement

  • Découverte des liens depuis la page d'accueil via HTTP (rapide)
  • Phase 1 : Playwright rend les pages principales (équipe, contact, à propos, mentions légales)
  • Phase 2 : Playwright rend les pages de détail des membres
  • Extraction LLM via Gemini Flash, Groq ou OpenRouter
  • Validation anti-hallucination contre le HTML source
  • Déduplication inter-entreprises pour attraper les noms inventés par le LLM
