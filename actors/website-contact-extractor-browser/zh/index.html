网站联系人提取器（浏览器版）：JS 重型公司站点

使用 Playwright 与 AI 从 JavaScript 渲染的公司站点（React、Vue、Angular SPA）提取联系人（姓名、职位、邮箱、电话）。HTTP-only Website Contact Extractor 的浏览器版伴侣：处理在无 JavaScript 执行时返回空 HTML 的团队、联系、关于和法律声明页。相同输入格式、相同输出，对源 HTML 进行防幻觉校验。当 HTTP actor 将公司标记为 js_rendering_suspected 时自动链式触发。

何时使用此 Actor

  • JS 渲染团队/联系页：React、Vue、Angular 等 SPA 框架
  • 空 HTML 响应：联系页客户端渲染的站点
  • HTTP actor 标记的公司：通过 enablePlaywrightFallback 自动链式
  • 团队详情页：两阶段渲染捕获每位成员档案
  • 防幻觉要求：联系人按源 HTML 校验，非 LLM 凭空生成

工作原理

  • 从主页发现链接（HTTP，快速）
  • 第 1 阶段：Playwright 渲染主页面（团队、联系、关于、法律声明）
  • 第 2 阶段：Playwright 渲染团队成员详情页
  • LLM 提取使用 Gemini Flash、Groq 或 OpenRouter
  • 防幻觉校验对源 HTML 验证
  • 跨公司去重过滤 LLM 凭空生成的姓名
