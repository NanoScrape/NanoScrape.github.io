您可以抓取的内容

  • 8 个亚太国家： AU、NZ、SG、MY、ID、PH、HK、TH
  • 薪资数据： salary_min、salary_max、salary_currency (AUD、NZD、SGD、MYR、IDR、PHP、HKD、THB)
  • 联系数据： Seek 在职位中暴露的联系邮箱与电话
  • 公司档案： company_industry、company_size、company_description、company_perks、company_profile_url
  • 质量标记： classifications、sub_classification、雇主筛选问题、job_alive 检查

主要使用场景

  • 亚太招聘通道。 通过一次搜索覆盖悉尼、新加坡、吉隆坡、马尼拉的资深工程师
  • 东盟薪资基准。 对比 MYR、IDR、PHP 中的 salary_min，统一 JobStreet 各市场薪酬
  • 直达雇主外联。 在职位提供时抓取联系邮箱与电话，用于高转化候选人外联
  • 职位新鲜度监控。 每周重新抓取，使用 job_alive 将已关闭岗位从 ATS 流水中剔除

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~seek-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "country": "au",
    "searchUrls": ["https://au.seek.com/software-engineer-jobs"],
    "maxResults": 100,
    "includeJobDetails": true
  }'

# 或通过 MCP 与 AI 代理配合使用：
# https://mcp.apify.com?tools=santamaria-automations/seek-scraper
