What you get

  • apply_email: direct application email address extracted from the posting - most German job scrapers only return the apply URL
  • contact_salutation / contact_firstname / contact_lastname / contact_phone: named hiring manager contact with phone when included
  • requirements: experience level, job field, and hierarchy extracted as a structured array (e.g. ["Berufseinsteiger", "IT", "Fachkraft"])
  • canton: German Bundesland code (BW, BY, BE, etc.) for every listing
  • remote_option: remote, hybrid, or onsite - inferred from the job metadata
  • expires_at: posting expiration date in ISO 8601 format - consistent on Jobware listings
  • company_url / company_logo_url: employer website and logo from the Jobware API
  • company_benefits: soft skills and perks array ("Weiterbildungsmoeglichkeiten", "Flexible Arbeitszeiten", etc.)
