Ce que vous pouvez extraire

  • Favicons standards — /favicon.ico, link[rel="icon"] dans toutes les tailles
  • Icônes Apple touch — icônes haute résolution pour appareils iOS
  • Images Open Graph — balises og:image pour le partage social
  • Manifeste web app — icônes définies dans manifest.json / site.webmanifest
  • Formats multiples — détection ICO, PNG, SVG, WEBP
  • Traitement en masse — traitez des milliers de domaines en une seule exécution

Cas d'utilisation

  • Enrichissement CRM — ajoutez des logos d'entreprise à vos listes de contacts
  • Veille de marque — collectez et suivez les assets visuels de marque à grande échelle
  • Annuaires — peuplez vos annuaires d'entreprises avec des logos
  • Analyse concurrentielle — collectez les assets de marque concurrents
  • Interfaces dashboard — enrichissez tableaux de bord et rapports avec les favicons

Exemple API

# Lancer une exécution via l'API Apify
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~favicon-extractor/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://google.com",
      "https://github.com",
      "https://stripe.com"
    ]
  }'
