可提取的数据

  • 标准Favicon -- /favicon.ico、所有尺寸的link[rel="icon"]
  • Apple触摸图标 -- iOS设备的高分辨率图标
  • Open Graph图片 -- 用于社交分享的og:image元标签
  • Web应用清单 -- manifest.json / site.webmanifest中定义的图标
  • 多种格式 -- ICO、PNG、SVG、WEBP检测
  • 批量处理 -- 单次运行处理数千个域名

主要用例

  • CRM数据丰富 -- 为潜在客户列表和联系人数据库添加公司Logo
  • 品牌监控 -- 大规模收集和追踪品牌视觉资产
  • 目录构建 -- 为企业目录填充公司Logo
  • 竞争分析 -- 收集竞争对手品牌资产用于市场研究
  • 仪表板UI -- 为仪表板和报告添加公司Favicon

API示例

# 通过Apify API启动一次运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~favicon-extractor/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://google.com",
      "https://github.com",
      "https://stripe.com"
    ]
  }'

# 或通过MCP与AI代理一起使用：
# https://mcp.apify.com?tools=santamaria-automations/favicon-extractor
