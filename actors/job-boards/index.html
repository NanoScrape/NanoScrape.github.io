NanoScrape publishes 89 job board scrapers on the Apify marketplace, each returning structured JSON for job listings. Every actor is a lightweight HTTP-only Go program — no browser, no monthly fee, pay per result.

Flagship actors in this category: Indeed, Linkedin, Stepstone. All actors run on Apify's cloud with datacenter proxy rotation by default; residential proxy is available on the actors that need it. Cold start is under 1 second and typical memory footprint is 128 MB.

Use the cards below to open any actor's detail page — every page has a real input example, a real output example (from a live smoke run), the full field catalog, and a cost math table. Ready to integrate: n8n, Make, Zapier, Python/Node.js SDKs, and the Apify MCP endpoint for AI agents (Claude, ChatGPT, Cursor, LangChain).

Frequently asked

How many job board scrapers does NanoScrape publish?

89 actors as of the latest daily sync. New actors are added continuously and old ones deprecated in place; the full list on this page is regenerated from the live Apify inventory every night.

How much do the job board scrapers cost?

Every actor is priced pay-per-result on Apify — most range from $0.001 to $0.02 per result depending on whether detail-page enrichment is included. Apify's $5/month free tier covers roughly the first 100k SERP results across NanoScrape actors.

Do I need an API key from the source site to use these job board scrapers?

No. Every NanoScrape actor reads public web pages over HTTP with datacenter proxies. No API key, no OAuth, no rate-limit management on your side. You only need an Apify token to trigger the actor and receive the dataset.
