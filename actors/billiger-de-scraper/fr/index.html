Ce que vous pouvez scraper

  • Identité produit : name, source_platform, product_image_url
  • Prix : best_price, price_currency, price_count (nombre d'offres marchands)
  • Preuve sociale : rating, review_count
  • Mode détail : brand, ean, specs structurées (stockage, couleur, processeur, etc.)
  • Modes d'entrée : searchQuery (mot-clé) ou categoryUrl (collage direct)
  • Aperçu image : les images produit s'affichent dans la vue tableau du dataset

Cas d'usage principaux

  • Suivi tarifaire. Suivre quotidiennement les prix concurrents sur le e-commerce allemand
  • Repricing. Injecter best_price dans des outils de repricing marketplace
  • Étude de marché. Analyser les tendances tarifaires par catégorie et marque à grande échelle
  • Scan de marge dropshipping. Filtrer par price_count pour repérer les produits avec une concurrence marchand saine
  • Enrichissement catalogue. Récupérer EAN, marque et specs pour l'hygiène de la base produit
