RSS 阅读器：大规模监控任意订阅源，每 1,000 订阅源 $0.50

从任意订阅源 URL 解析 RSS 2.0、Atom 1.0 和 JSON Feed。返回每个条目的标题、作者、链接、发布日期、内容、摘要、类目、附件和内嵌图片。按日期范围或类目过滤。为监控而生：按小时调度以喂入新闻聚合器、告警管道或内容数据库。适用于新闻监控、播客索引、博客追踪和品牌提及告警。

您能获得什么

  • 每条目：title、link、author、published_at、updated_at、content_html、summary
  • 分类：categories[]、tags[]、language
  • 媒体：enclosures[]（播客、附件）、inline_images[]、featured_image
  • 订阅源元数据：feed_title、feed_description、feed_link、feed_updated_at、total_items
  • 过滤：max_age_days、since_date、category_filter、keyword_filter

主要使用场景

  • 新闻监控。将数百个行业源聚合到单一订阅源提及管道
  • 播客索引。从播客目录提取每个剧集及其元数据和音频 URL
  • 博客追踪。每天 diff 竞争对手订阅源以检测新文章和主题
  • 品牌提及告警。按关键词过滤订阅源并触发 Slack 或 webhook 通知
  • 内容数据库填充。从发行商 RSS 存档回填编辑数据库
