eFinancialCareers Scraper

The NanoScrape Efinancialcareers Scraper is an Apify actor that extracts job listings from efinancialcareers.com. It returns 57 fields per result including title, company, location, city, title_normalized, priced at $5/1k result, with no API key or monthly subscription required.

Scrape finance and banking jobs from eFinancialCareers (US and UK) by keyword and city (source platform). Returns title, company, salary min/max, sectors, seniority, work arrangement, apply URL and dates. Detail mode adds description, skills, reference, company profile and recruiter contacts.
