What You Can Scrape

  • Company identity — name, LinkedIn slug, universal name, website URL, LinkedIn profile URL
  • Size signals — employee count (exact and range), follower count on LinkedIn
  • Classification — industry, company type (public, private, non-profit, etc.), founded year
  • Location — headquarters city, country, postal code, full formatted address
  • Description and positioning — full company description and up to 10 specialties
  • Domain validation — the actor cross-checks the company's listed website domain so you can safely join LinkedIn data with your own records

Primary Use Cases

  • Lead enrichment — bulk-enrich a CRM export with headcount, industry, and HQ location from LinkedIn
  • ICP scoring — filter a prospect list by company size range or industry vertical before outreach
  • Market research — map the competitive landscape by pulling all companies in a niche and their specialties
  • News monitoring — track headcount changes over time as a hiring / growth signal
  • Data pipeline enrichment — pair with Google Maps Scraper to add LinkedIn context to local business records

How It Works

The actor calls LinkedIn's public guest API endpoint (/organization-guest/company/{slug}), which is available without authentication and returns the same structured JSON that populates public company pages. This means no cookie management, no session handling, and no risk of account bans. The actor validates the returned company's website domain against your input list so mismatched profiles (e.g., a company with the same slug name in a different region) are flagged and excluded.

How It's Priced

One flat rate of $0.005 per company ($5 per 1,000) regardless of field depth. A minimum run charge of $0.001 applies. Zero surprises, zero add-ons.
