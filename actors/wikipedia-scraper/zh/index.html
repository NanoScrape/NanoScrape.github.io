维基百科抓取器：文章、摘要和元数据，每 1,000 文章 $0.50

通过官方 MediaWiki API 按标题、URL 或 Wikidata ID 提取维基百科文章。返回文章标题、摘要（首段）、纯文本全文、缩略图、首图、所有类目、地理坐标（适用时）、Wikidata Q-ID、过去 30 天页面浏览量，以及其他语言的引用。支持 12+ 语言，包括英语、德语、法语、西班牙语、中文和日语。适用于 AI 训练数据、知识图谱富化、RAG 数据摄入和参考数据库。

您能获得什么

  • 身份：title、page_id、wikidata_id（Q-ID）、canonical_url、language
  • 内容：summary（首段）、content（完整纯文本）、sections[]、word_count
  • 视觉：thumbnail_url、lead_image_url、image_count
  • 分类：categories[]、interwiki_links[]（其他语言版本）
  • 地理 + 热度：coordinates（地理类文章的 lat/lon）、pageviews_30d、edit_count、last_edited_at

主要使用场景

  • AI 训练数据。跨主题和语言构建用于 LLM 微调的干净、结构化语料
  • 知识图谱富化。将公司、人物或地点实体解析到 Wikidata Q-ID 并提取规范描述
  • RAG 数据摄入。将维基百科内容作为权威参考锚定送入向量数据库
  • 多语言参考数据库。以 12+ 语言提取同一篇文章用于平行文本项目
  • 主题监控。追踪 edit_count 和 last_edited_at 以检测公众兴趣激增

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~wikipedia-scraper/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "queries": [
      "Stripe (公司)",
      "OpenAI",
      "埃菲尔铁塔",
      "阿尔伯特·爱因斯坦",
      "Transformer (机器学习模型)"
    ],
    "language": "zh",
    "extractFullContent": true,
    "includePageviews": true
  }'

# 或通过 MCP 与 AI 代理配合使用：
# https://mcp.apify.com?tools=santamaria-automations/wikipedia-scraper
