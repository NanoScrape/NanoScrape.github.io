图片元数据提取器：EXIF、GPS、相机数据，每 1,000 图片 $1

从任意 JPEG、TIFF、HEIC、PNG 或 WebP URL 提取 EXIF、GPS 坐标、相机参数和 IPTC 关键词。返回尺寸、相机厂商和型号、镜头、光圈、快门速度、ISO、GPS 经纬度、版权和 IPTC 关键词。为批量而生：输入 10,000 图片 URL，返回结构化数据行。适用于 OSINT 调查、照片取证、资产编目和版权审计。

您能获得什么

  • 图片基础：width、height、format、color_space、bit_depth、file_size_bytes、mime_type
  • EXIF 相机：camera_make、camera_model、lens_model、aperture、shutter_speed、iso、focal_length
  • EXIF 时间：date_taken、date_digitized、date_modified、timezone_offset
  • GPS：gps_latitude、gps_longitude、gps_altitude、gps_direction、location_country、location_city
  • 权利与标签：copyright、artist、software、iptc_keywords、iptc_caption

主要使用场景

  • OSINT 调查。通过 GPS EXIF 对公开 Telegram、Twitter 或新闻来源的照片进行地理定位
  • 照片取证。检测编辑软件、原始拍摄设备和篡改痕迹
  • 版权审计。跨图片目录批量检查版权、作者和许可字段
  • 资产编目。按相机、日期、位置和 IPTC 关键词索引照片库
  • 房产验证。通过 GPS 确认房源照片在所声称的房产位置拍摄

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~image-metadata-extractor/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "imageUrls": [
      "https://example.com/photo-1.jpg",
      "https://example.com/scene-2.heic",
      "https://example.com/wedding-3.tiff"
    ],
    "extractGps": true,
    "extractIptc": true
  }'

# 或通过 MCP 与 AI 代理配合使用：
