When to use this actor

  • JS-rendered career pages: React, Vue, Angular and other modern SPA frameworks
  • Empty HTML responses: career pages that ship a skeleton without JS execution
  • Companies flagged by the HTTP actor: auto-triggered via enablePlaywrightFallback
  • Sites requiring text-content wait: Playwright waits for network idle plus text presence
  • ATS-backed careers: Personio, Greenhouse, Lever, Softgarden, Ashby and 14 more systems detected

How it works

  • Playwright renders the full page, waiting for network idle plus visible text content
  • Career page discovery from homepage navigation (same logic as the HTTP actor)
  • ATS detection for 19 systems so the right scrape strategy is picked per company
  • LLM extraction using Gemini Flash, Groq or OpenRouter with anti-hallucination checks
  • Validation with per-job confidence scoring and cross-page deduplication
  • Pagination follow-up for multi-page listing pages

API example

# Run the browser job extractor on a list of JS-heavy company sites
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~website-job-extractor-browser/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "companies": [
      {
        "company_id": "abc-123",
        "company_name": "TechCorp AG",
        "website_url": "https://techcorp.ch"
      }
    ],
    "llmProvider": "gemini",
    "geminiApiKey": "YOUR_GEMINI_KEY"
  }'
