网站职位提取器（浏览器版）：JS 重型站点的招聘页

使用 Playwright 与 AI 从 JavaScript 渲染的招聘页（React、Vue、Angular SPA）提取职位列表。HTTP-only Website Job Extractor 的浏览器版伴侣：处理在无 JavaScript 执行时返回空 HTML 的 28% 站点。相同输入格式、相同输出、相同置信度评分。当 HTTP actor 将公司标记为 js_rendering_suspected 时自动链式触发。

何时使用此 Actor

  • JS 渲染招聘页：React、Vue、Angular 等现代 SPA 框架
  • 空 HTML 响应：未执行 JS 时仅返回骨架的招聘页
  • HTTP actor 标记的公司：通过 enablePlaywrightFallback 自动触发
  • 需要等待文本内容的站点：Playwright 等待 network idle 与文本存在
  • 基于 ATS 的招聘：识别 Personio、Greenhouse、Lever、Softgarden、Ashby 等 19 个系统

工作原理

  • Playwright 完整渲染页面，等待 network idle 与可见文本内容
  • 从主页导航发现招聘页（与 HTTP actor 相同逻辑）
  • ATS 识别覆盖 19 个系统，按公司选择正确的抓取策略
  • LLM 提取使用 Gemini Flash、Groq 或 OpenRouter，含防幻觉检查
  • 校验逐职位置信度评分与跨页去重
  • 分页跟进处理多页列表

API 示例

# Run the browser job extractor on a list of JS-heavy company sites
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~website-job-extractor-browser/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "companies": [
      {
        "company_id": "abc-123",
        "company_name": "TechCorp AG",
        "website_url": "https://techcorp.ch"
      }
    ],
    "llmProvider": "gemini",
    "geminiApiKey": "YOUR_GEMINI_KEY"
  }'
