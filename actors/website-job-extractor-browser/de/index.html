Website Job Extractor (Browser): Karriere-Seiten auf JS-lastigen Sites

Job-Listings aus JavaScript-gerenderten Karriere-Seiten (React, Vue, Angular SPAs) per Playwright plus KI extrahieren. Browser-basierte Ergänzung zum HTTP-only Website Job Extractor: deckt die 28% der Sites ab, die ohne JavaScript-Ausführung leeres HTML liefern. Gleiches Input-Format, gleiche Ausgabe, gleicher Confidence Score. Auto-chained, wenn der HTTP-Actor ein Unternehmen mit js_rendering_suspected markiert.

Wann diesen Actor nutzen

  • JS-gerenderte Karriere-Seiten: React, Vue, Angular und andere moderne SPA-Frameworks
  • Leere HTML-Antworten: Karriere-Seiten, die ohne JS-Ausführung nur ein Skeleton liefern
  • Vom HTTP-Actor markierte Unternehmen: Auto-Trigger via enablePlaywrightFallback
  • Sites, die auf Text-Inhalte warten müssen: Playwright wartet auf Network Idle plus Text-Präsenz
  • ATS-gestützte Karrieren: Personio, Greenhouse, Lever, Softgarden, Ashby und 14 weitere Systeme erkannt

So funktioniert es

  • Playwright rendert die vollständige Seite, wartet auf Network Idle plus sichtbaren Text-Inhalt
  • Karriere-Seiten-Erkennung aus der Homepage-Navigation (gleiche Logik wie HTTP-Actor)
  • ATS-Erkennung für 19 Systeme, damit die richtige Scrape-Strategie pro Unternehmen gewählt wird
  • LLM-Extraktion mit Gemini Flash, Groq oder OpenRouter, plus Anti-Halluzinations-Checks
  • Validierung mit Confidence Score pro Job und Cross-Page-Deduplizierung
  • Paginierungs-Follow-up für mehrseitige Listings

API-Beispiel

# Run the browser job extractor on a list of JS-heavy company sites
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~website-job-extractor-browser/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "companies": [
      {
        "company_id": "abc-123",
        "company_name": "TechCorp AG",
        "website_url": "https://techcorp.ch"
      }
    ],
    "llmProvider": "gemini",
    "geminiApiKey": "YOUR_GEMINI_KEY"
  }'

# Or use with AI agents via MCP:
# https://mcp.apify.com?tools=santamaria-automations/website-job-extractor-browser
