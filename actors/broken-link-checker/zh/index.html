坏链检查器：查找 404 和死链，每 1,000 URL $1

爬取任意网站或 URL 列表以检测坏链及确切失败模式。返回 HTTP 状态码、错误类别（4xx、5xx、DNS、超时、SSL、重定向环）、响应时间、来源页面、链接锚文本和完整重定向链。可配置爬取深度、链接类型过滤（内部/外部/资源）和并发。为批量而生：输入 10 万 URL，或用起始域名种子让其发现一切。适用于 SEO 维护、迁移 QA、内容审计和链接卫生监控。

您能获得什么

  • 每链接判定：status_code、error_category、is_broken、response_time_ms
  • 上下文：source_page、anchor_text、link_type（内部/外部/图片/脚本）、rel 属性
  • 重定向链：final_url、redirect_count、redirect_chain[]、has_redirect_loop
  • 错误详情：error_message、ssl_error、dns_error、timeout_ms_exceeded
  • 爬取控制：max_depth、follow_external、include_assets、max_links_per_page

主要使用场景

  • SEO 维护。每月运行一次爬取，在 404 和错误外链损害排名前发现它们
  • 迁移 QA。站点改版后验证每个内外链仍解析为 200
  • 内容审计。识别旧文章中的死链以便下线或替换
  • 链接卫生监控。当高流量外链开始返回 5xx 或跳转到站外时告警
  • 供应商门户 QA。持续测试面向客户的门户中损坏的下载和资源 URL

API 示例

# 通过 Apify API 启动运行
curl -X POST "https://api.apify.com/v2/acts/santamaria-automations~broken-link-checker/runs?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "startUrls": [
      "https://example.com",
      "https://docs.example.com"
    ],
    "maxDepth": 3,
    "followExternal": true,
    "includeAssets": false,
    "maxLinksPerPage": 200
  }'
