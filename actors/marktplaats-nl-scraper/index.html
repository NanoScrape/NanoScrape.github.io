Marktplaats.nl Scraper: Netherlands' #1 Classifieds (10M+ listings)

Scrape classified listings from marktplaats.nl, the Netherlands' largest online marketplace with 10M+ active listings. Returns title, full description, price in EUR (converted from cents), price type (FIXED, MIN_BID, SEE_DESCRIPTION), city, country, GPS coordinates, category, seller name and numeric ID, primary image and all image URLs, posted date and source URL. The actor uses the site's internal JSON API directly, so no HTML parsing is needed. Paste any marktplaats.nl search URL and the actor handles pagination.

What you can scrape

  • All categories: cars (auto-s), bikes, computers, phones, furniture, fashion, real estate, jobs
  • Search: any marktplaats.nl URL with filters (category, postcode range, price, condition, seller type)
  • JSON API: direct hits to the internal endpoint, no HTML parsing, much faster than scraping
  • GPS coordinates: full latitude and longitude on every listing
  • Multi-search: paste several URLs in one run for parallel processing
  • Seller ID: numeric seller_id enables cross-listing aggregation per seller

Primary use cases

  • Used car arbitrage. Watch Opel, VW or Peugeot listings under a price ceiling in Amsterdam, Rotterdam or Utrecht
  • Second-hand price intel. Track average EUR prices for iPhones, MacBooks or fietsen across the Dutch market over time
  • Seller portfolio analysis. Group listings by seller_id to map a power-seller's full inventory
  • Cross-border arbitrage. Compare Dutch listings against Belgian or German equivalents on neighbouring marketplaces
  • Lead generation. Extract phone-shop or used-electronics resellers active across multiple Dutch cities
